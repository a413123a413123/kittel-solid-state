①主要內容與研究問題

本章用差排理論解釋晶體固體的塑性力學性質（塑性為不可逆變形，彈性為可逆）。核心問題是：為什麼純單晶如此容易塑性變形？完美晶體彈性極限應變的理論估計可比觀測到的最低值高 10³ 到 10⁴ 倍（10² 倍較常見）。章節先用 Frenkel 的方法估計完美晶體的理論剪切強度，發現與實驗值差距巨大，只能靠缺陷解釋；接著引入差排（刃差排、螺旋差排、Burgers 向量），推導差排的應力場與彈性能、差排間的作用力，再處理低角度晶界（差排陣列，間距 D = b/θ）、差排密度與 Frank–Read 源的增殖機制，然後討論合金強化的四種機制，最後是差排對晶體生長的控制作用（螺旋生長）、whisker 與材料硬度。

②核心物理概念

  • Frenkel 用簡單模型估計完美晶體的理論剪切強度：若 a ≈ d，理想臨界剪應力約為剪切模數的 1/6；Mackenzie 進一步修正後約為 G/30，對應約 2 度的臨界剪切應變角。實驗彈性極限遠低於此。
  • 塑性變形靠滑移（slip）發生：晶體的一部分整體滑過相鄰部分，滑移面與滑移方向都高度各向異性（fcc 滑移方向為 ⟨110⟩，bcc 為 ⟨111⟩），滑移向量必須等於晶格平移向量。
  • 滑移遵守 Schmid 臨界剪應力定律：當對應的剪應力分量達到臨界值時，沿該滑移面與方向發生滑移。另一種塑性模式是孿晶（twinning），常見於 hcp 與 bcc。
  • 刃差排是已滑移區與未滑移區的邊界，位置由擠入上半晶體的額外半原子面終端標示；其運動類比於地毯上皺褶的傳遞——皺褶比整張地毯容易移動。移動差排所需的外加應力很小，鍵結力非高度方向性時低於 10⁵ dyn/cm²。
  • 螺旋差排的邊界平行於滑移方向（刃差排則垂直），可視為用刀部分切開晶體再沿切口邊緣剪切一個原子間距；它把連續的原子面轉成螺旋面。
  • Burgers 向量 b 由「切開—位移—補料或去料—重新接合」的一般構造定義；b 必須等於晶格向量，否則重新接合無法維持晶體性。螺旋差排的 b 平行差排線，刃差排的 b 垂直差排線且位於滑移面內。
  • 差排的彈性能都含 ln(R/r₀) 因子；r₀ 取 Burgers 向量大小或晶格常數量級，R 不能超過晶體尺寸，但因為進入對數項，R/r₀ 的值影響不大。
  • Burgers 提出低角度晶界由差排陣列組成：純傾斜（pure tilt）晶界是間距 D = b/θ 的刃差排陣列；Vogel 等人以蝕坑計數量測 D 並由 θ = b/D 算得的傾角與 x 射線直接量測吻合。純傾斜晶界在適當應力下會整體垂直移動，由陣列中各差排協同滑移完成。
  • 差排密度從最好的 Ge、Si 晶體的 10² cm⁻² 以下，到重度變形金屬的 10¹¹–10¹² cm⁻²；塑性變形使密度從約 10⁸ 增至 10¹¹ cm⁻²，代表差排在變形中增殖。兩端被釘住的差排段稱為 Frank–Read 源，可在單一滑移面上產生大量同心差排環；雙交叉滑移是最常見的來源。
  • 提高合金降伏強度的四種重要方式：機械阻擋差排運動（析出第二相粒子）、溶質原子釘住差排（溶質雲）、短程有序阻礙差排運動、以及提高差排密度造成糾結（加工硬化）。第五種是把差排全部移除（whisker）。
  • 所有強化機制在擴散變得可觀的溫度都開始失效，導致隨時間變化的變形即潛變（creep）；尋找高溫合金就是尋找低擴散率。但強合金的核心問題不是強度而是延性，因為破壞常以斷裂發生。
  • 低過飽和度（約 1%）下晶體生長速率遠快於理想晶體的計算值；若存在螺旋差排就永遠不必成核新的單層，晶體沿不連續處以螺旋方式生長，若生長速率與方向無關則圖樣為 Archimedes 螺線 r = aθ。
  • Whisker（細髮狀晶體）在高過飽和度下生長，可能只含一根軸向螺旋差排，因此具有接近理論完美晶體的彈性性質；Herring 與 Galt 觀測到半徑約 10⁻⁴ cm 的錫 whisker 降伏應變約 10⁻²，對應剪應力約 10⁻² G，約為塊材錫的 1000 倍。

③重要模型與公式

完美晶體的理論臨界剪應力（Frenkel 估計）

σ = (Ga/2πd) sin(2πx/a) , σ_c = Ga/2πd

(2), (3) 　p.599

G 為適當的剪切模數，d 為面間距，a 為剪切方向上的原子間距，x 為位移；小應變時化為 σ = Gx/d（式 1）。若 a ≈ d 則 σ_c ≈ G/2π，即剪切模數的 1/6

螺旋差排的剪應力場

σ = G e = G b / (2π r)

(4) 　p.605

周長 2πr 的殼被剪切了 b，故剪應變 e = b/2πr；b 為 Burgers 向量大小，r 為到差排線的距離。此式在差排線鄰近區域不成立（應變太大）

螺旋差排單位長度的彈性能

E_S = (G b² / 4π) ln(R / r₀)

(5) 　p.606

由 dE_s = ½Ge² dV = (Gb²/4π) dr/r 積分而得；R 與 r₀ 分別為 r 的上下限，r₀ 約為 b 或晶格常數，R 不超過晶體尺寸

刃差排的應力場（等向彈性連續體）

σ_rr = σ_θθ = −[G b / 2π(1 − ν)] · (sin θ)/r ; σ_rθ = [G b / 2π(1 − ν)] · (cos θ)/r

(6) 　p.606

σ_rr、σ_θθ 為徑向與圓周方向的拉應力，σ_rθ 為剪應力；ν 為 Poisson 比，多數晶體 ν ≅ 0.3

刃差排單位長度的應變能

E_e = [G b² / 4π(1 − ν)] ln(R / r₀)

(7) 　p.606

與螺旋差排式 (5) 相比多了 1/(1−ν) 因子；ν 為 Poisson 比

刃差排間的作用力（滑移方向分量）

F = b σ_xy = [G b² / 2π(1 − ν)] · (sin 4θ) / (4y)

(9) 　p.606

位於原點的刃差排施於位置 (y, θ) 處同類差排的單位長度作用力；由 σ_xy = [Gb/2π(1−ν)]·x(x²−y²)/(x²+y²)²（式 8）與 F = bσ（習題 3）得到

低角度純傾斜晶界的差排間距

D = b / θ

p.607

D 為刃差排陣列的間距，b 為差排的 Burgers 向量，θ 為兩晶粒繞共同 [001] 軸的小角度相對旋轉；Vogel 等人以蝕坑計數量測 D，由 θ = b/D 算得的角度與 x 射線量測吻合

析出粒子強化：迫使差排穿過間距 L 粒子所需的應力

σ / G = b / L

(10) 　p.614

L 為滑移面上粒子的間距，b 為 Burgers 向量，G 為剪切模數；L 愈小降伏應力愈高。析出完成後 L 最小、強度最大，高溫久置後粒子粗化使 L 增大、強度下降

④本章最重要的結論

純晶體觀測到的臨界剪應力遠低於 Frenkel 對完美晶體的理論估計（理想值約 G/2π，修正後約 G/30），這個差距只能用差排這種線缺陷的運動來解釋——差排通過晶體等價於一部分晶體的滑移位移，而移動差排所需的應力極小。差排的應力場隨 1/r 衰減、彈性能正比於 Gb² 並含 ln(R/r₀) 因子；低角度晶界就是間距 D = b/θ 的差排陣列，此模型已由電子顯微鏡、蝕坑計數與 x 射線量測證實。反過來，一切合金強化機制（析出粒子、溶質雲、短程有序、加工硬化）本質上都是阻礙差排運動，可把降伏強度提高到 10⁻³ G 至 10⁻² G；而完全沒有差排的 whisker 則可達到接近理論完美晶體的強度。
