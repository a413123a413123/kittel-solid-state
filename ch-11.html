①主要內容與研究問題

本章處理「未進入磁有序」的磁性：自由原子與離子在外加磁場下的抗磁與順磁反應。書中一開始即指出磁性與量子力學不可分割，因為嚴格古典的熱平衡系統即使在磁場中也不會顯示磁矩。自由原子磁矩有三個來源：電子自旋、電子繞核的軌道角動量、以及外加磁場所誘發的軌道磁矩變化；前兩者給出順磁貢獻，第三者給出抗磁貢獻。章內依序建立 Langevin 抗磁公式、抗磁的量子（微擾）推導、Brillouin 函數與 Curie 定律、稀土與鐵族離子的有效磁子數、晶場劈裂與軌道角動量凍結（quenching）、Van Vleck 溫度無關順磁性、等熵去磁冷卻，最後以 Pauli 傳導電子順磁性作結。核心問題是：什麼決定 χ 的正負號、大小與溫度依賴？

②核心物理概念

  • 磁化率定義 χ = M/B；χ<0 稱抗磁、χ>0 稱順磁；莫耳磁化率寫作 χ_M。
  • 抗磁性源自電荷部分屏蔽外加磁場的傾向；Larmor 定理指出磁場只是在原運動上疊加一個進動，該進動電流產生與外場反向的磁矩。
  • 抗磁磁化率只與電子分布的 ⟨r²⟩ 有關，與溫度無關（Langevin 結果），對惰性氣體與離子實核（ion core）近似成立。
  • 順磁性出現在：奇數電子系統、內殼層未填滿的自由原子與離子（過渡族、稀土、錒系）、少數偶電子化合物（如 O₂）、以及金屬。
  • 磁矩 μ = γℏJ = −gμ_B J；自由原子的 g 由 Landé 公式給出，磁場中有 2J+1 個等間距能階。
  • Brillouin 函數描述任意 J 的磁化，其高溫極限給出 Curie 定律 χ = C/T，並定義有效磁子數 p = g[J(J+1)]^{1/2}。
  • Hund 規則決定基態：S 最大、在該 S 下 L 最大、殼層未過半時 J = |L−S|、過半時 J = L+S。
  • 鐵族離子的 3d 殼層是最外層，會受到強而不均勻的晶場，使 L–S 耦合被破壞、L_z 平均為零（軌道角動量凍結），故實驗 p 值接近純自旋值 2[S(S+1)]^{1/2}。
  • 等熵（絕熱）去磁：固定溫度下磁場降低自旋熵，撤場時熵由晶格流入自旋系統，達到 T₂ = T₁(B_Δ/B)；核去磁可再低約 100 倍（Cu 曾達 1.2×10⁻⁶ K）。
  • 傳導電子只有費米面附近約 T/T_F 比例的電子能翻轉，故 Pauli 自旋順磁性與溫度無關；Landau 抗磁再抵掉其中 1/3。

③重要模型與公式

Larmor 進動角頻率（抗磁的古典基礎）

ω = eB/2mc （CGS）; ω = eB/2m （SI）

(2) 　p.300

e 電子電荷，m 電子質量，B 外加磁場，c 光速。此為磁場中電子繞核運動額外疊加的進動頻率，須遠低於原中心場運動頻率才成立。

Langevin 抗磁磁化率

χ = Nμ/B = −NZe²⟨r²⟩ / 6mc² （CGS）; χ = μ₀Nμ/B = −μ₀NZe²⟨r²⟩ / 6m （SI）

(5) 　p.301

N 每單位體積原子數，Z 原子序（電子數），⟨r²⟩ = ⟨x²⟩+⟨y²⟩+⟨z²⟩ 為電子到原子核的均方距離。書中同時由式 (4) 的 μ = −(Ze²B/4mc²)⟨ρ²⟩ 與球對稱關係 ⟨ρ²⟩ = (2/3)⟨r²⟩ 得到。

Landé g 因子（自由原子的譜線劈裂因子）

g = 1 + [J(J+1) + S(S+1) − L(L+1)] / [2J(J+1)]

(13) 　p.302

J 總角動量量子數，S 總自旋，L 總軌道角動量。g 定義為 gμ_B ≡ −γℏ；電子自旋的 g = 2.0023，通常取 2.00。

磁場中的 Zeeman 能階

U = −μ·B = m_J g μ_B B

(14) 　p.303

m_J 為方位量子數，取值 J, J−1, …, −J；μ_B = eℏ/2mc（CGS）= eℏ/2m（SI）為 Bohr 磁子。單一自旋無軌道矩時 m_J = ±1/2、g = 2，得 U = ±μ_B B。

Curie–Brillouin 定律（任意 J 的磁化）

M = N g J μ_B B_J(x), x = g J μ_B B / k_B T; B_J(x) = [(2J+1)/2J]·ctnh[(2J+1)x/2J] − (1/2J)·ctnh(x/2J)

(19) 在 p.303；Brillouin 函數本體 (20) 在次頁 　p.303

B_J 為 Brillouin 函數，N 為單位體積離子數。J = 1/2 時退化為式 (17) 的 M = Nμ tanh(μB/k_BT)。

Curie 定律與有效磁子數

M/B = N J(J+1) g² μ_B² / 3k_B T = N p² μ_B² / 3k_B T = C/T, p ≡ g[J(J+1)]^{1/2}

(22), (23) 　p.304

C 為 Curie 常數，p 為有效 Bohr 磁子數。此為 x = μB/k_BT ≪ 1 的展開結果（ctnh x = 1/x + x/3 − x³/45 + …）。

等熵去磁所達最終溫度

T₂ = T₁ (B_Δ / B)

(41) 　p.314

B 為初始外加磁場，T₁ 為初始溫度，B_Δ 為對應局域交互作用的有效內場。書中 Cu 核去磁實驗擬合出 T₂ = T₁(3.1/B)（B 以高斯計），即 B_Δ = 3.1 gauss。

Pauli 傳導電子自旋順磁性（含 Landau 修正）

M = μ²D(ε_F)B = 3Nμ²B / 2k_B T_F → χ = 3Nμ²/2ε_F; 含 Landau 抗磁後 M = N μ_B² B / k_B T_F

(45), (46) 　p.317

D(ε_F) 為費米能處的軌道態密度（= 3N/2ε_F），T_F 為費米溫度，μ = μ_B。Landau 證明自由電子波函數受磁場修正會產生等於順磁矩 −1/3 的抗磁矩，故總磁化為 Pauli 值的 2/3。

④本章最重要的結論

抗磁性是普遍存在的誘發效應，其大小僅由電子分布的 ⟨r²⟩ 決定且與溫度無關（Langevin 結果）；順磁性則來自未填滿殼層的永久磁矩，其磁化由 Brillouin 函數描述，高溫下服從 Curie 定律 χ = C/T。稀土離子的 4f 殼層深埋於 5s5p 之內，實驗有效磁子數與 Landé/Hund 預測相符；鐵族離子的 3d 為最外層，晶場凍結軌道角動量，故實驗值接近純自旋值。金屬中的傳導電子因 Fermi–Dirac 統計，只有費米面附近 T/T_F 比例的電子能翻轉，因而給出與溫度無關的 Pauli 順磁性 χ = 3Nμ²/2ε_F。 但書中同時指出（p.306）實驗磁子數與此計算仍有不符之處，並非全然吻合。

⑤與前後章的關係　（我的判讀）

用 Ch6 的 D(ε_F) 導出傳導電子的 Pauli 順磁；建立的交換與 Hund 規則框架是 Ch12 鐵磁交換場的前置。等熵去磁一節提供了到達極低溫的實驗手段。

⑥與熱容 Cth 的關聯程度　（我的判讀）

無明顯關聯

無明顯關聯。但 Pauli 順磁 χ = 3Nμ²/2ε_F 的推導與 Ch6 的電子熱容同源——都源自「只有 ε_F 附近 ~k_BT 的電子能響應」。Ch6 推導卡住時，這裡是同一物理的另一個面向。
