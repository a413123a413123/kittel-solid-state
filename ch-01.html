①主要內容與研究問題

本章處理「晶體是什麼、如何用數學描述晶體的週期性」。書中從晶體由相同建構單元（building blocks）連續堆疊而成的成長圖像出發，建立 lattice（晶格）＋ basis（基）＝ crystal structure 的核心框架，並定義 primitive translation vectors 與 primitive cell。接著討論晶格可容許的旋轉對稱（1、2、3、4、6 次軸，五次軸不可能），推出二維 5 種、三維 14 種 Bravais lattice。再引入 Miller 指標系統標定晶面，最後逐一檢視 NaCl、CsCl、hcp、diamond、cubic ZnS 五種基本結構，並談 STM 直接成像與 random stacking／polytypism 等非理想結構。

②核心物理概念

  • 晶體＝lattice（數學點集）＋ basis（附著在每個晶格點上的原子群），兩者分開描述是全章的骨架。
  • primitive translation vectors a₁, a₂, a₃ 定義晶軸；任兩個看起來相同的點必滿足整數平移關係 (1)，此時晶格稱為 primitive。
  • primitive cell 是最小體積的晶胞，每個 primitive cell 恰含一個晶格點；選法不唯一，Wigner-Seitz cell 是其中一種對稱的選法。
  • 晶格只能有 1、2、3、4、6 次旋轉軸；五次對稱與平移週期性不相容（正五邊形無法鋪滿平面）。
  • 二維有 5 種 Bravais lattice（oblique 加四種特殊晶格）；三維點群要求 14 種晶格型態，歸為 7 大晶系。
  • 立方系有 sc、bcc、fcc 三種晶格；conventional cell 中 bcc 含 2 個、fcc 含 4 個晶格點，只有 sc 的 conventional cell 本身就是 primitive cell。
  • 晶面指標 (hkl)：取軸截距（以晶格常數為單位）的倒數，再化為最小整數比；立方晶中 [hkl] 方向垂直於 (hkl) 面，但其他晶系不然。
  • diamond structure 空間晶格為 fcc、基有兩個相同原子（000 與 ¼¼¼），填充率僅 0.34；cubic ZnS 為 diamond 的兩套 fcc 分別放 Zn 與 S，失去反演對稱。

③重要模型與公式

晶格平移對稱條件（定義 lattice）

r′ = r + u₁a₁ + u₂a₂ + u₃a₃

(1) 　p.4

r 為觀察點，r′ 為平移後的等價點；u₁, u₂, u₃ 為任意整數（arbitrary integers）；a₁, a₂, a₃ 為三個平移向量（primitive translation vectors）

基中第 j 個原子中心相對晶格點的位置

rⱼ = xⱼa₁ + yⱼa₂ + zⱼa₃ , 0 ≤ xⱼ, yⱼ, zⱼ ≤ 1

(2) 　p.5

rⱼ 為基中原子 j 的中心相對於所屬晶格點的位置向量；xⱼ, yⱼ, zⱼ 為以軸長為單位的分數座標

primitive cell 的體積（平行六面體體積）

V_c = |a₁ · a₂ × a₃|

(3) 　p.6

V_c 為以 a₁, a₂, a₃ 為稜的平行六面體體積；書中稱此為 elementary vector analysis 的結果

bcc 晶格的 primitive translation vectors

a₁ = ½a(x̂ + ŷ − ẑ) ; a₂ = ½a(−x̂ + ŷ + ẑ) ; a₃ = ½a(x̂ − ŷ + ẑ)

p.10

a 為 conventional cube 的邊長；x̂, ŷ, ẑ 為 Cartesian unit vectors。此 primitive cell 為邊長 ½a√3 的菱面體，相鄰稜夾角 109°28′

fcc 晶格的 primitive translation vectors

a₁ = ½a(x̂ + ŷ) ; a₂ = ½a(ŷ + ẑ) ; a₃ = ½a(ẑ + x̂)

p.11

a 為 conventional cube 邊長；這三個向量連接原點的晶格點與各面心，軸間夾角為 60°

三種立方晶格的最近鄰距離（Table 2）

sc: a ; bcc: 3^(1/2)a/2 = 0.866a ; fcc: a/2^(1/2) = 0.707a

p.10

a 為 conventional cell 邊長。對應最近鄰數分別為 6、8、12；每個 conventional cell 的晶格點數為 1、2、4

晶格平移算符（SUMMARY）

T = u₁a₁ + u₂a₂ + u₃a₃

p.22

T 為 lattice translation operator；u₁, u₂, u₃ 為整數；a₁, a₂, a₃ 為晶軸（crystal axes）

理想 hcp 結構的 c/a 比

c/a = (8/3)^(1/2) = 1.633

p.22

a 為基面內的晶格參數，c 為堆疊軸方向的晶格參數；若 c/a 明顯大於此值，可視為緊密堆積面之間鬆散堆疊

④本章最重要的結論

晶體結構完全由「晶格 ＋ 基」兩件事決定：晶格是滿足 T = u₁a₁ + u₂a₂ + u₃a₃ 的數學點集，基是附在每個晶格點上、組成與取向都相同的原子群。平移週期性強烈限制了可能的對稱性——旋轉軸只能是 1、2、3、4、6 次，因此二維僅有 5 種、三維僅有 14 種 Bravais lattice。實用上以 conventional cell 與 Miller 指標 (hkl) 描述結構與晶面，書中選 NaCl、CsCl、hcp、diamond、cubic ZnS 五種結構作為「general interest」的示例（p.13），其中 fcc 與 hcp 的填充率皆為 0.74（最密），diamond 結構則只有 0.34。

⑤與前後章的關係　（我的判讀）

開卷章，不依賴任何前章。它建立的「晶格＋基」與原胞概念是 Ch2 倒晶格的直接輸入（倒晶格基向量由 a₁,a₂,a₃ 定義），也是 Ch4–5 聲子模式計數的空間基礎——每原胞的原子數決定色散關係有幾支分支。往後 Ch19（非晶）與 Ch22（合金）都是在打破本章的週期性前提。
