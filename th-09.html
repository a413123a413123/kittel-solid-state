09

非諧性、熱膨脹及 Cp、Cv 的差異

溫區定位：高溫區　T ≫ θ　·　趨近 Dulong–Petit 飽和

①物理意義與直觀解釋　（我寫的教學說明）

到目前為止的所有推導都建立在簡諧近似上：原子間位能是位移的二次式，U ∝ x²。這個近似極其好用，但它有三個與實驗矛盾的後果——沒有熱膨脹（位能對稱，平均位置不隨振幅改變）、聲子之間不會碰撞（簡正模式彼此獨立，熱導率會是無限大）、以及彈性常數與溫度無關。

真實的原子間位能是不對稱的：壓縮時排斥急遽上升、拉伸時吸引緩慢趨零。把這個非諧項放回去，上述三件事就都對了。

熱膨脹：因為位能不對稱，振幅越大平均位置越往外偏——溫度升高，晶格常數變大。Kittel 明確指出最低階的熱膨脹只涉及位能中的非對稱項，對稱的四次項不貢獻。

Cp 與 Cv 的差異：定壓加熱時晶體會膨脹並對外做功，所以 C_p > C_v，差額 C_p − C_v = 9α²BVT（α 為線膨脹係數、B 為體積模數、V 為體積）。注意這個差額正比於 α²——而 α 本身來自非諧性。所以「C_p 與 C_v 的差」與「熱膨脹」是同一個物理的兩張臉：簡諧晶體既不膨脹，Cp 也等於 Cv。

實務上要記住兩件事：(1) 理論算的是 C_v，實驗量的是 C_p（定容量測要把樣品鎖死，極難）；(2) 固體中兩者差異通常很小、常可忽略，且 T → 0 時 C_v → C_p（因為差額正比於 T，也因為 α 隨溫度下降）。所以低溫熱容的文獻不區分兩者是合理的，高溫精密工作則必須區分。

②重要公式與符號定義　（書中）

非諧位能與古典熱膨脹

U(x) = cx² − gx³ − fx⁴ ； ⟨x⟩ = (3g/4c²) k_B T

(38), (40) 　Ch5 p.120

x 為偏離絕對零度平衡間距的位移；c、g、f 皆為正；gx³ 項代表原子互斥的非對稱性，fx⁴ 項代表大振幅下振動的軟化。最低階的熱膨脹只牽涉反對稱項 gx³

③推導所使用的假設　（書中）

  • 書中預設「熱容」指定容積熱容 C_V ≡ (∂U/∂T)_V，並明講它比實驗實際量到的定壓熱容 C_p 更基本（p.107）
  • C_p 與 C_V 之差由一條熱力學關係給出：C_p − C_V = 9α²BVT，其中 α 為線膨脹係數（temperature coefficient of linear expansion）、V 為體積、B 為體積模量（p.107 腳註 1）
  • 推得 C_p → C_V 的低溫極限時，假設 α 與 B 為常數（p.107 腳註 1）
  • 諧和（harmonic）理論假設晶格位能只保留原子間位移的二次項；書中把非諧效應定義為「高於二次項」的部分（p.119–120）
  • 熱膨脹推導取一維古典振子，位能寫成 U(x) = cx² − gx³ − fx⁴，且 c、g、f 皆為正；x 是相對絕對零度平衡間距的位移。gx³ 代表原子互斥的不對稱性，fx⁴ 代表大振幅時振動的軟化（p.120）
  • 以 Boltzmann 分布對 x 加權求 ⟨x⟩；並假設非諧項的能量遠小於 k_BT，故把 exp(βgx³+βfx⁴) 展開為 1+βgx³+βfx⁴+…，而指數中的 cx² 項保留不展開（p.120–121）

④適用條件與限制　（書中）

  • C_p 與 C_V 的分數差在固體中通常很小，常常可以忽略——這是書中對「用 C_V 代替 C_p」的唯一辯護（p.107）
  • 僅在 α 與 B 可視為常數時，才能說 T → 0 時 C_p → C_V（p.107）
  • 諧和理論的五項推論在真實晶體中「沒有一項被精確滿足」；偏差歸因於忽略了非諧項（p.119–120）
  • 熱膨脹結果 ⟨x⟩ = 3g k_BT/(4c²) 只在古典區（classical region）成立（p.120–121）
  • U(x) 在 x = 0 的極小並非絕對極小；只有小振幅時這個形式才是原子間位能的適當表示（p.120）
  • 最低階的熱膨脹不涉及對稱項 fx⁴，只涉及反對稱項 gx³；膨脹係數在 T → 0 時消失（p.121）
  • 非諧耦合對熱阻的理論預測「聲子平均自由程 ℓ ∝ 1/T」只適用於高溫（p.123）

⑤高溫與低溫行為　（書中）

高溫　T ≫ θ

諧和理論的推論之一就是「熱容在高溫 T > θ_D 時變成常數」，而書中明講真實晶體並不精確滿足此推論（p.119–120）。古典區的平均位移 ⟨x⟩ = 3g k_BT/(4c²)，即熱膨脹隨溫度線性增加（p.120–121）。高溫時所有聲子模態都被激發（k_BT > ℏω_max），被激發聲子總數 ∝ T，碰撞頻率隨可碰撞聲子數增加，故非諧耦合理論預測 ℓ ∝ 1/T、晶格熱阻 ∝ T，與許多實驗吻合（p.123, p.126）。注意：書中並未針對高溫另行討論 C_p − C_V 的大小，只給了 9α²BVT 這條式子與「固體中分數差通常很小」的通則（p.107）。

低溫　T ≪ θ

T → 0 時 C_p → C_V（前提是 α 與 B 為常數），這是書中唯一明講的低溫 C_p/C_V 陳述（p.107）。熱膨脹方面，固體氬的晶格常數量測（Fig. 15）中曲線斜率正比於熱膨脹係數；書中明講「膨脹係數在 T → 0 時消失」，並指向 Problem 5（p.121）。與非諧性相關的低溫熱傳：能發生 umklapp 的高能聲子數大致隨 exp(−θ/2T) 變化，指數形式與實驗吻合；再低溫時 U 過程失效、尺寸效應主導，K ≈ CvD，而其中唯一隨溫度變的是熱容 C ∝ T³，故低溫熱導率隨 T³ 變化（p.126–127）。

【延伸知識】書中沒有處理的部分

（1）C_p − C_V = 9α²BVT 只出現在 p.107 的一條腳註，書中沒有推導它，也沒有給任何材料 C_p/C_V 的實測比值或表格。（2）Grüneisen 常數 γ 只出現在第 5 章 Problem 5（p.129，且標為「somewhat difficult」），正文完全沒有 Grüneisen 關係；書中沒有寫出 α = γC_V/(3BV) 這種常見形式，Problem 5 給的是 Δ = γU(T)/B。（3）書中沒有討論非諧性對熱容本身的修正（例如高溫下 C_V 超過 3Nk_B 的線性 T 修正項），非諧性只被用來解釋熱膨脹與熱阻。（4）沒有半導體／矽／薄膜材料的 C_p 與 C_V 差異的具體數據。（5）元件層級的熱容 C_th [J/K] 與熱阻 R_th [K/W] 全書都沒有：第 5 章只給材料層級的熱導率 K [W cm⁻¹K⁻¹] 與單位體積熱容 C [J cm⁻³K⁻¹]（p.122 Table 2），完全沒有自加熱、熱時間常數、暫態熱響應、或幾何相依的熱阻網路。書中唯一碰到幾何的是低溫尺寸效應 K ≈ CvD（p.126），且那是熱導率而非熱阻。
