①主要內容與研究問題

本章以「自由電子費米氣」（受包立原理約束的自由電子氣）為模型，解釋金屬的物理性質。書中先在一維求解無限位能井中的電子軌域與費米能，再推廣到三維週期性邊界條件下的平面波軌域、費米球與態密度。全章最核心的問題是電子熱容：古典統計預測每個自由電子貢獻 (3/2)k_B，但實測的電子熱容在室溫下不到該值的 0.01，書中明言這是早期電子論最大的困難。後半以費米球在 k 空間的位移處理電導率與歐姆定律、Matthiessen 規則、umklapp 散射，再處理磁場中的運動（霍爾效應）與金屬熱導率，最後導出 Wiedemann-Franz 定律與 Lorenz 數。

②核心物理概念

  • 自由電子費米氣＝受包立不相容原理約束的自由電子氣；價電子成為傳導電子，離子實只佔約 15% 體積（鹼金屬）。
  • orbital（軌域）指單電子波方程的解；N 電子系統的近似量子態由 N 個電子分佔 N 個不同軌域構成，僅在電子間無交互作用時為精確。
  • 費米能 ε_F 定義為 N 電子系統基態中最高被佔據能階的能量；絕對零度時化學勢 μ 等於 ε_F。
  • 三維基態中被佔據的軌域填滿 k 空間中半徑 k_F 的費米球，k_F 只取決於電子濃度 N/V。
  • 加熱時並非每個電子都獲得 ~k_BT 的能量，只有費米能階附近 k_BT 能量範圍內的電子能被熱激發，因此電子熱容遠小於古典值。
  • 電子熱容正比於 T，與晶格的 T³ 項合成 C = γT + AT³；γ 稱為 Sommerfeld 參數。
  • 實測 γ 與自由電子值的比值定義熱有效質量 m_th/m，偏離 1 來自週期位能、電子-聲子交互作用、電子-電子交互作用三種效應；重費米子化合物的 γ 可高出常見值二至三個數量級。
  • 電導率由費米球在定常態下的位移給出（σ = ne²τ/m）；電阻在室溫由聲子散射主導、在液氦溫度由雜質與缺陷主導，低溫電阻主要來自 umklapp 散射。
  • 霍爾係數 R_H = E_y/(j_x B)，自由電子模型給 R_H = −1/nec；Al、In、Be、As 出現正號，需能帶理論（電洞）才能解釋。

③重要模型與公式

費米-狄拉克分布函數（軌域被佔據的機率）

f(ε) = 1 / (exp[(ε − μ)/k_B T] + 1)

(5) 　p.136

ε 為軌域能量；μ 為化學勢（隨溫度變化，需使總粒子數等於 N）；k_B 為波茲曼常數；T 為溫度。絕對零度時 μ = ε_F。

三維費米波向量（僅取決於電子濃度）

k_F = (3π²N/V)^(1/3)

(16) 　p.138

k_F 為費米面上波向量的大小；N 為電子數；V 為體積。由 2·(4πk_F³/3)/(2π/L)³ = V k_F³/3π² = N 得到，左側因子 2 來自兩個自旋值。

費米能與電子濃度的關係

ε_F = (ℏ²/2m)(3π²N/V)^(2/3)

(17) 　p.140

ℏ 為約化普朗克常數；m 為電子質量；N/V 為電子濃度。費米溫度定義為 T_F ≡ ε_F/k_B（與電子氣的實際溫度無關）。

三維自由電子氣的態密度

D(ε) ≡ dN/dε = (V/2π²)(2m/ℏ²)^(3/2) · ε^(1/2)

(20) 　p.140

D(ε) 為單位能量範圍內的軌域數（嚴格說是單粒子態密度／軌域密度）；由總軌域數 N = (V/3π²)(2mε/ℏ²)^(3/2) 對 ε 微分而得。

態密度的簡化式（比較 (19) 與 (20)）

D(ε) ≡ dN/dε = 3N/2ε

(21) 　p.141

在 ε 處成立；在費米能處 D(ε_F) = 3N/2ε_F = 3N/2k_B T_F，即費米能處單位能量的軌域數約等於總傳導電子數除以費米能。

電子熱容的一般積分式

C_el = dU/dT = ∫₀^∞ dε (ε − ε_F) (df/dT) D(ε)

(28) 　p.142

ΔU = U(T) − U(0) 為 N 個電子由 0 加熱到 T 的總能量增量；f(ε) 為費米-狄拉克函數，是 (27) 式中唯一與溫度相關的項；D(ε) 為單位能量範圍的軌域數。

低溫電子熱容（Sommerfeld 展開結果）

C_el = (1/3) π² D(ε_F) k_B² T

(34) 　p.144

適用於 k_B T ≪ ε_F；推導中令 τ ≡ k_B T、x ≡ (ε − ε_F)/τ，並用 ∫₋∞^∞ dx x²eˣ/(eˣ+1)² = π²/3。

自由電子氣的電子熱容（以費米溫度表示）

C_el = (1/2) π² N k_B T / T_F

(36) 　p.144

由 (34) 代入 D(ε_F) = 3N/2ε_F = 3N/2k_B T_F 得到；k_B T_F ≡ ε_F。C_el 正比於 T，室溫下比古典值 (3/2)Nk_B 小約 0.01 或更少（T_F ~ 5×10⁴ K）。

金屬低溫總熱容的實驗作圖式（電子項＋聲子項）

C = γT + AT³ ，作圖用 C/T = γ + AT²

(37) 　p.145

適用於遠低於德拜溫度 θ 與費米溫度 T_F；γ 為 Sommerfeld 參數（電子項係數），A 為聲子項係數，兩者皆為材料特徵常數。以 C/T 對 T² 作圖應得斜率 A、截距 γ 的直線。

熱有效質量（由觀測 γ 與自由電子 γ 之比定義）

m_th/m ≡ γ(observed) / γ(free)

(38) 　p.145

m_th 為熱有效質量，m 為電子質量。此形式自然出現是因為 ε_F 反比於電子質量，故 γ ∝ m。偏離 1 源自傳導電子與週期位能、與聲子、與其他電子的交互作用。

歐姆定律與電導率（自由電子）

j = nqv = ne²τE/m ，σ = ne²τ/m ，ρ = m/ne²τ

(42) 在 p.147；(43)(44) 在 p.148 　p.147

j 為電流密度；n 為單位體積內電荷 q = −e 的電子數；τ 為碰撞時間；E 為電場；σ 為電導率；ρ 為電阻率。定常態下費米球位移 δk = −eEτ/ℏ，增量速度 v = ℏδk/m = −eEτ/m。

Wiedemann-Franz 定律與 Lorenz 數

K/σ = (π²/3)(k_B/e)² T ，L ≡ K/σT = (π²/3)(k_B/e)² = 2.45×10⁻⁸ watt-ohm/deg²

(57) 在 p.156；(58)(59) 在次頁 　p.156

K 為電子熱導率（由 K = (1/3)Cvℓ 與 (36) 得 K_el = π² n k_B² T τ/3m）；σ 為電導率；L 為 Lorenz 數。此結果與 n 和 m 皆無關，實驗值（0°C 與 100°C）與之符合良好。

④本章最重要的結論

自由電子費米氣模型加上包立原理與費米-狄拉克統計，正確解出了古典理論失敗的電子熱容問題：只有費米面附近 k_BT 範圍內的電子能被熱激發，因此電子熱容線性正比於溫度，C_el = (1/3)π²D(ε_F)k_B²T = (1/2)π²Nk_BT/T_F，室溫下僅為古典值的 1% 量級。實驗上以 C/T 對 T² 作圖分離出電子項 γ 與聲子項 A，而 γ(觀測)/γ(自由電子) 定義的熱有效質量比反映了週期位能、電子-聲子與電子-電子交互作用；重費米子化合物的 γ 可高出二至三個數量級。同一模型也給出歐姆定律 σ = ne²τ/m 與 Wiedemann-Franz 定律 K/σT = (π²/3)(k_B/e)²，後者不含 n 與 m，在金屬理論史上支持了「電子氣同時攜帶電荷與能量」的圖像。但霍爾係數在 Al、In、Be、As 出現正號，是自由電子模型無法解釋、必須交給第 7–9 章能帶理論的關鍵失敗。
