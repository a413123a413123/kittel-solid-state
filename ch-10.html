①主要內容與研究問題

本章處理超導性：先做實驗綜述——零電阻、臨界磁場 H_c(T)、Meissner 效應、熵與熱容的下降、能隙的存在、微波與紅外性質、以及同位素效應；再做理論綜述——由熱力學導出超導態的穩定化自由能、以 London 方程解釋 Meissner 效應並定義穿透深度、引入同調長度、介紹 BCS 理論的具體成就、環中磁通量子化、持續電流的壽命估算、第二類超導體與渦旋態、單粒子穿隧與 Josephson 效應，最後簡述高溫超導體。

②核心物理概念

  • 超導態不只是零電阻：塊材在弱磁場中表現為完美反磁性，B = 0（Meissner 效應），此結果無法僅由 ρ = 0 推得。
  • 臨界磁場 H_c(T) 隨溫度上升而下降，在 T_c 為零；零磁場下的正常—超導轉變是二級相變，無潛熱但熱容有不連續。
  • 超導態熵較低，代表電子比正常態更有序；超導態電子熱容呈 exp(−E_g/2k_BT) 形式，指向能隙的存在。
  • 同位素效應 M^α T_c = 常數顯示晶格振動與電子—晶格交互作用深涉超導性；原始 BCS 模型給 α = 1/2，但庫侖交互作用會改變此關係。
  • London 方程把電流密度直接正比於向量位 A，並導出磁場自表面呈指數衰減，衰減尺度即 London 穿透深度 λ_L。
  • 同調長度 ξ 是超導電子濃度不能急遽變化的最短距離；λ/ξ ≡ κ 決定超導體屬第一類（ξ > λ）或第二類（ξ < λ）。
  • BCS 基態由 k↑ 與 −k↓ 的 Cooper 對組成，這些對具有玻色子屬性，並使有效電荷為 2e，導致磁通量子為 2πℏc/2e。
  • Josephson 效應：無外加電壓時直流超電流 J = J₀ sin δ 可跨越弱連結；外加直流電壓 V 則產生頻率 ω = 2eV/ℏ 的射頻振盪電流，1 μV 對應 483.6 MHz。

③重要模型與公式

Meissner 效應（長細試樣）

B = B_a + 4πM = 0 ，即 M/B_a = −1/4π [CGS]

(1) 　p.263

B_a 為外加磁場；M 為對應試樣內超導電流的磁化強度；SI 為 B = B_a + μ₀M = 0，M/B_a = −1/μ₀

同位素效應

M^α T_c = constant

(2) 　p.269

M 為同位素質量；α 為實驗指數（Hg 為 0.50±0.03，Zn 0.45，Ru 與 Zr 為 0.00）

超導態的穩定化自由能密度

ΔF ≡ F_N(0) − F_S(0) = B_ac² / 8π [CGS]

(9) 　p.272

F_N、F_S 為正常態與超導態自由能密度；B_ac 為臨界外加磁場（CGS 中 H_c ≡ B_ac）。鋁在絕對零度 B_ac = 105 G，ΔF = 439 erg cm⁻³

London 方程

j = −(c/4πλ_L²) A ；curl j = −(c/4πλ_L²) B [CGS]

(10) j=−(c/4πλ_L²)A；curl j 形式為獨立編號的 (11) 　p.274

j 為超導電流密度；A 為 London 規範（div A = 0）下的向量位；SI 為 j = −A/(μ₀λ_L²)。與 curl B = 4πj/c 結合得 ∇²B = B/λ_L²（式 13）

London 穿透深度

λ_L = (m c² / 4π n q²)^{1/2} [CGS]

(14a) 　p.275

n 為電荷 q、質量 m 的粒子濃度；SI 為 λ_L = (ε₀ m c² / n q²)^{1/2}。場的衰減為 B(x) = B(0) exp(−x/λ_L)（式 14）

BCS 的轉變溫度判據

T_c = 1.14 θ exp[−1 / U D(ε_F)]

(18) 　p.278

θ 為德拜溫度；U 為吸引性電子—晶格—電子交互作用；D(ε_F) 為費米能階處單一自旋的軌域態密度；適用於 U D(ε_F) ≪ 1

超導環中的磁通量子

Φ = (2πℏc/q) s ，q = −2e ⇒ Φ₀ = 2πℏc/2e ≅ 2.0678×10⁻⁷ gauss·cm²

(27) 　p.281

s 為整數；q = 2e 為電子對電荷（由實驗確定）；SI 為 Φ₀ = 2πℏ/2e ≅ 2.0678×10⁻¹⁵ T·m²。此量子稱為 fluxoid 或 fluxon

直流 Josephson 效應

J = J₀ sin δ = J₀ sin(θ₂ − θ₁)

(47) 　p.290

δ = θ₂ − θ₁ 為接面兩側 Cooper 對機率幅的相位差；J₀ 正比於穿隧轉移交互作用 T，是接面在零電壓下所能通過的最大電流

④本章最重要的結論

超導態是一個由 Cooper 對（k↑, −k↓）構成、與最低激發態之間隔著能隙 E_g 的有序基態。其電磁行為的核心是 Meissner 效應 B = 0，可由 London 方程 j ∝ −A 直接導出，並給出磁場自表面按 exp(−x/λ_L) 衰減的穿透深度；配對電荷為 2e 使超導環中的磁通量子化為 Φ₀ = 2πℏc/2e。超導態相對正常態的穩定化自由能密度為 H_c²/8π，臨界磁場因而是該能量差的量度。同調長度 ξ 與穿透深度 λ 的比值 κ = λ/ξ 決定超導體型別：ξ < λ 者為第二類，在 H_c1 與 H_c2 之間進入渦旋態，仍保有超導電性，這正是強場超導磁鐵的基礎。Josephson 弱連結進一步展現宏觀量子相位：零電壓下有 J = J₀ sin δ 的直流超電流，加上直流電壓則產生 ω = 2eV/ℏ 的交流振盪，可用於精確測定 e/ℏ 與製作高靈敏磁強計。
