①主要內容與研究問題

本章處理電子自旋的有序排列：鐵磁、亞鐵磁與反鐵磁。書中先以 Weiss 平均場（分子場、交換場）把自發磁矩問題化約為自洽方程，導出 Curie 溫度與 Curie–Weiss 定律，並把平均場常數 λ 連回 Heisenberg 交換積分 J。接著處理低溫的基本激發——磁振子（magnon），推導色散關係並得到 Bloch T^{3/2} 定律，說明中子散射如何直接量測磁振子譜。之後推廣到亞鐵磁（兩個不等值的反平行次晶格、鐵石榴石 YIG）與反鐵磁（MnO、Néel 溫度、χ⊥ 與 χ∥ 的差異、反鐵磁磁振子）。最後處理巨觀結構問題：為什麼鐵磁體會分成磁疇、Bloch 壁的厚度與能量由何決定、以及矯頑力與磁滯。

②核心物理概念

  • 平均場（分子場／Weiss 場）近似：每個磁性原子感受到正比於磁化的交換場 B_E = λM，鐵中 B_E 可達 10⁷ G ≈ 10³ T，遠大於相鄰磁性離子的真實偶極場（約 10³ G）。
  • 交換場只是交換交互作用的近似表示；真正的機制是 Heisenberg 模型 U = −2J S_i·S_j，J 與相鄰原子電荷分布的重疊有關，其符號決定鐵磁（J>0）或反鐵磁（J<0）。
  • Curie 溫度以上服從 Curie–Weiss 定律 χ = C/(T−T_c)；T_c 以下由自洽方程 m = tanh(m/t) 給出自發磁化，屬二階相變。
  • 平均場在低溫描述不佳：它給出指數型的 ΔM，實驗卻是 T^{3/2}；正確解釋來自自旋波理論。
  • 磁振子是量子化的自旋波，能量 ε_k = (n_k + 1/2)ℏω_k，激發一個磁振子相當於翻轉一個自旋；其熱佈居服從 Planck 分布。
  • 中子同時看到原子核分布與電子磁化分布，故中子繞射可定出磁矩的分布、方向與有序方式；非彈性中子散射（動量與能量守恆）可直接測出磁振子譜。
  • 亞鐵磁：兩個反平行但磁矩不等的次晶格；1/χ 對 T 的曲線呈現特徵彎曲。反鐵磁是 C_A = C_B 的特例，T_N 處 χ 出現尖點（kink）而非發散。
  • 反鐵磁在 T_N 以下的磁化率具方向性：垂直方向 χ⊥ = 1/μ，平行方向在 0 K 時 χ∥(0) = 0，並隨溫度平滑上升至 T_N。
  • 反鐵磁磁振子色散在長波長時線性於 k（ω ≈ ω_ex|ka|），與鐵磁的 ω ∝ k² 截然不同，因此低溫熱容給出 T³ 項。
  • 磁疇源自能量最小化（交換能、異向能、磁能的競爭）；Bloch 壁厚度與壁能由交換能（偏好厚壁）與異向能（偏好薄壁）的平衡決定，鐵中約 300 個晶格常數、壁能約 1 erg/cm²。
  • 矯頑力是鐵磁材料最敏感、可控範圍最廣的性質（跨七個數量級）；直徑小於 10⁻⁵–10⁻⁶ cm 的粒子必為單疇，反磁化只能靠整體轉動，故矯頑力高。

③重要模型與公式

Weiss 交換場（平均場近似）

B_E = λM

(1) 　p.323

M 為單位體積磁矩（磁化），λ 為與溫度無關的平均場常數。此式假設每個自旋感受到所有其他自旋的平均磁化。

Curie–Weiss 定律與 Curie 溫度

χ = C/(T − T_c), T_c = Cλ; λ = T_c/C = 3k_B T_c / [N g² S(S+1) μ_B²]

(3)(4) 在 p.324；(5) λ=T_c/C 在次頁 　p.324

C 為 Curie 常數，T_c 為 Curie 溫度。χ 在 T = Cλ 發散，即出現自發磁化。書中以鐵為例（T_c ≈ 1000 K, g ≈ 2, S ≈ 1）估得 λ ≈ 5000。

Heisenberg 交換交互作用

U = −2J S_i·S_j

(6) 　p.325

J 為交換積分，與原子 i、j 電荷分布的重疊有關；S_i、S_j 為兩原子的電子自旋。

交換積分與 Curie 溫度的平均場關係

J = 3k_B T_c / [2 z S(S+1)]

(7) 　p.325

z 為最近鄰數。書中指出更好的統計近似給出 k_B T_c/zJ = 0.28（sc）、0.325（bcc）、0.346（fcc），對比平均場的 0.500；以 S = 1 表示鐵時，觀測 T_c 對應 J = 11.9 meV。

自發磁化的自洽方程（約化形式）

m = tanh(m/t), m ≡ M/Nμ, t ≡ k_B T / Nμ²λ = T/T_c

(9) 　p.326

m 為約化磁化，t 為約化溫度。由 (8) 的 M = Nμ tanh(μλM/k_BT) 改寫；臨界溫度為 t = 1，即 T_c = Nμ²λ/k_B。

鐵磁磁振子色散關係（一維最近鄰）

ℏω = 4JS(1 − cos ka); ka ≪ 1 時 ℏω ≅ (2JSa²)k²

(22), (23) 　p.332

J 交換積分，S 自旋量子數，a 晶格常數，k 波向量。三維立方晶格為 ℏω = 2JS[z − Σ_δ cos(k·δ)]（式 24），長波長極限同為 ℏω = (2JSa²)k² = Dk²。中子散射測得 D 在 295 K 分別為 Fe 281、Co 500、Ni 364 meV·Å²。

Bloch T^{3/2} 定律（磁振子熱激發造成的磁化下降）

ΔM/M(0) = (0.0587 / S Q) · (k_B T / 2JS)^{3/2}

(30) 　p.334

Q = 1, 2, 4 分別對應 sc、bcc、fcc（每單位晶胞原子數），S 為自旋，J 為交換積分。由磁振子態密度與 Planck 分布積分得到，實驗上 ΔM/M(0) = A T^{3/2}，Ni 的 A = (7.5±0.2)×10⁻⁶ deg^{−3/2}，Fe 為 (3.4±0.2)×10⁻⁶ deg^{−3/2}（式 11, p.327）。

反鐵磁的 Néel 溫度與順磁區磁化率

T_N = μC; χ = 2C / (T + T_N)，實驗形式 χ = 2C/(T + θ)

(39)(40) 在 p.342；(38) T_N=μC 在前一頁 　p.342

C 為單一次晶格的 Curie 常數，μ 為 A–B 次晶格間的平均場常數，θ 為 Curie–Weiss 溫度。書中指出實測 θ/T_N 常明顯偏離 1；若引入次晶格內部的平均場常數 −ε，則 θ/T_N = (μ+ε)/(μ−ε)。

反鐵磁磁振子色散關係

ω = ω_ex |sin ka|, ω_ex ≡ 4|J|S/ℏ

(52) 　p.345

J < 0 為反鐵磁交換積分。ka ≪ 1 時 ω ≅ ω_ex|ka|，即頻率線性於波向量；RbMnF₃ 的中子散射結果證實有很大一段線性區。

Bloch 壁的厚度與單位面積壁能

σ_w ≅ π²JS²/Na² + KNa; N = (π²JS²/Ka³)^{1/2}; σ_w = 2π(KJS²/a)^{1/2}

(56), (58), (59) 　p.350

N 為壁內原子面數，a 晶格常數，K 異向能常數，J 交換積分，S 自旋。第一項為交換能（偏好厚壁），第二項為異向能（限制壁厚）。鐵中 N ≈ 300、σ_w ≈ 1 erg/cm²；(100) 面上 180° 壁的精確計算為 σ_w = 2(2K₁JS²/a)^{1/2}。

④本章最重要的結論

鐵磁性可由 Weiss 平均場（交換場 B_E = λM）成功描述其高溫磁化率（Curie–Weiss 定律）與 T_c 附近的行為，交換場本身則是 Heisenberg 交換交互作用 U = −2J S_i·S_j 的近似表示。但平均場在低溫失效：正確的低溫圖像是量子化的自旋波（磁振子），其 ω ∝ k² 的色散給出實驗證實的 Bloch T^{3/2} 磁化衰減，並可由非彈性中子散射直接量測。把同一套平均場語言推廣到兩個次晶格，即得亞鐵磁（T_c = μ(C_AC_B)^{1/2}）與反鐵磁（T_N = μC、χ = 2C/(T+θ)、反鐵磁磁振子 ω ∝ |sin ka|）。巨觀上，鐵磁體分成磁疇是交換能、異向能與磁能競爭的自然結果；Bloch 壁的厚度 (J/Ka³)^{1/2} 與壁能 (KJ/a)^{1/2} 由交換與異向能的平衡決定，而矯頑力則是可跨七個數量級調控的、最敏感的工程性質。
