①主要內容與研究問題

本章（由 Cornell 大學 Paul McEuen 撰寫）處理在兩個或三個正交方向上被侷限到奈米尺度的固體，也就是準一維（1D）與零維（0D）奈米結構，例如碳奈米管、量子線、導電高分子，以及半導體奈米晶、金屬奈米粒子、微影定義的量子點。核心問題是：當固體的尺寸在一個以上的方向縮小時，電子態與振動態如何被量子化，而這些量子化如何決定光學、電性與熱學性質。章節先介紹奈米結構的成像技術（TEM、光學顯微、STM、AFM），再依序建立 1D 電子結構（1D 子能帶與 van Hove 奇異點）、1D 電輸運（電導量子化、Landauer 公式、共振穿隧、局域化、Büttiker 多端點形式）、0D 電子結構與電輸運（量子化能階、充電能、庫侖振盪、Kondo 效應、Cooper 配對），最後處理量子化振動模與熱容／熱傳導。書中明言此類量子化現象通常在 1–100 奈米尺度才重要。

②核心物理概念

  • 製作奈米結構有兩大路線：top-down 用微影把巨觀材料切到奈米尺度，bottom-up 用生長與自組裝從原子／分子前驅物堆出結構；前者難做小於 50 nm，後者難做大於 50 nm。
  • 奈米粒子表面原子佔比極高（R = 6a ≈ 1 nm 時約一半原子在表面），使內聚能大幅下降，因此奈米粒子的熔點遠低於對應塊材。
  • 1D 線的能量為橫向侷限能階加上沿線的自由色散，總態密度是各 1D 子能帶態密度之和，並在每個子能帶閾值發散為 (ε−ε_ij)^(−1/2)，稱為 van Hove 奇異點。
  • 1D 金屬的費米面只有 ±k_F 兩個點；能量與動量守恆在此等價，使得散射相空間限制較弱，基態被認為不是 Fermi 液體而是 Luttinger 液體。
  • 完美傳輸的單一 1D 通道具有有限電導 2e²/h（電導量子），與電子速度無關；有散射時電導為 Landauer 公式 G = (2e²/h)ℑ。
  • 兩個位障串聯時，若保持相位相干，在共振條件 φ* = 2πn 下透射被大幅增強；對稱位障時共振透射率為 1（共振穿隧）。若相位被破壞而改用機率相加，則得到歐姆定律：接觸電阻加上各位障電阻相加。
  • 只考慮彈性（保相位）散射時，平均電阻隨長度指數成長 ⟨R⟩ ∝ exp(2L/ℓ_e)，這就是局域化；有限溫度下相位相干長度 ℓ_φ 限制了指數段的長度。
  • 金屬點的 addition energy 由充電能主導；半導體點則是充電能與能階間距「同等重要」（p.551 逐字：the charging energy and the level spacing are of comparable importance）。
  • 奈米結構的振動模同樣量子化：薄壁圓柱有縱向模、徑向呼吸模（RBM）與橫向模；RBM 頻率 ω = v_L/R 可用 Raman 光譜量測並反推奈米管半徑。
  • 細長梁的橫向聲子不是剪切而是彎曲（flexural），色散由線性 ω = v_T K 變成二次 ω ∝ K²，且由縱波聲速決定而非橫波聲速。
  • 室溫下侷限方向的振動模能量通常小於 k_BT，因此奈米結構的晶格熱性質接近塊材（∝ T³）；但低溫時侷限方向的模凍結，系統變成 1D 熱系統，熱容與熱導都線性正比於 T。
  • 彈道極限下每個 1D 聲子子能帶的熱導 G_th 只由基本常數與絕對溫度決定，與 1D 電導量子化完全類比。

③重要模型與公式

1D 線的本徵態與色散（橫向量子化 + 沿線平面波）

ε = ε_{i,j} + ℏ²k²/2m ; ψ(x,y,z) = ψ_{i,j}(x,y) e^{ikz}

(13) 　p.528

i, j 為 x,y 平面內本徵態的量子數；k 為 z 方向波向量；m 為有效質量；ε_{i,j} 為橫向能量態

1D 子能帶態密度與 van Hove 奇異點

D_{i,j}(ε) = (dN_{i,j}/dk)(dk/dε) = (2)(2)(L/2πℏ)[m/2(ε−ε_{i,j})]^{1/2} = 4L/hν_{i,j} (ε > ε_{i,j})， = 0 (ε < ε_{i,j})

(15) 　p.528

第一個因子 2 來自自旋簡併，第二個 2 來自 ±k 兩個方向；ν_{i,j} 為動能 ε−ε_{i,j} 的電子在 i,j 子能帶中的速度；L 為線長

單一 1D 通道的淨電流（速度與態密度剛好抵消）

I = Δn q v = D_R(ε) qV/L · qv = (2/hv)·v q²V = (2e²/h) V

(20) 　p.533

Δn 為右行載子的過剩密度；D_R(ε) 為右行載子態密度；V 為兩端電化學位能差 μ₁−μ₂ = qV；q = −e（電子）或 +e（電洞）

電導量子與電阻量子

G_Q = 2e²/h ; R_Q = h/2e² = 12.906 kΩ

(21) 　p.534

e 為基本電荷，h 為 Planck 常數；此值對任意色散的 1D 能帶皆成立

Landauer 公式（兩端點電導）

G(ε_F) = (2e²/h) ℑ(ε_F)

(22) 　p.534

ℑ(ε_F) 為費米能處電子穿過通道的透射機率；多通道時 ℑ(ε_F) = Σ_{i,j} ℑ_{i,j}(ε_F)（式 23）

有限溫度／偏壓下的電流（Landauer 積分形式）

I(ε_F, V, T) = (2e/h) ∫_{−∞}^{∞} dε [ f_L(ε − eV) − f_R(ε) ] ℑ(ε)

(24) 　p.536

f_L、f_R 分別為左、右電極的 Fermi–Dirac 分布；淨電流是左行與右行電流對所有能量積分之差

雙位障串聯的相干透射機率（共振穿隧）

ℑ = |c|² = |t₁|²|t₂|² / [ 1 + |r₁|²|r₂|² − 2|r₁||r₂| cos(φ*) ]， φ* = 2kL + φ_{r1} + φ_{r2}

(29) 　p.536

t_j、r_j 為第 j 個位障的複數透射／反射振幅；L 為兩位障間距；φ = 2kL 為往返累積相位；共振條件為 φ* = 2πn（式 30），對稱位障時 ℑ = 1（式 32）

局域化：電阻隨長度指數成長

⟨R⟩ = (h/2e²) exp(2L/ℓ_e)

(43) 　p.539

ℓ_e 為彈性背向散射長度；L 為導體長度；局域化長度 ξ ~ ℓ_e（準 1D 時 ξ ~ N ℓ_e，N 為佔據的子能帶數）

量子點增加一個電子所需的閘極電壓變化

ΔV_g = (1/αe)( ε_{N+1} − ε_N + e²/C )

(62) 　p.550

α 為閘極電壓對點電位的耦合率；C 為量子點總靜電電容；e²/C 即充電能 U；ε_{N+1} − ε_N 為單粒子能階間距

薄壁圓柱徑向呼吸模（RBM）頻率

ω_RBM = (YV/MR²)^{1/2} = (Y/ρ)^{1/2}/R = v_L/R

(72) 　p.558

Y 為楊氏模數，V 為圓柱體積，M 為質量，ρ 為密度，R 為半徑，v_L ≡ (Y/ρ)^{1/2} 為縱向聲速；奈米管取 v_L = 21 km/s 時 ℏω_RBM = 14 meV / R[nm]

細梁橫向彎曲（flexural）模的二次色散

ω_T = v_L h K² / √12

(76) 　p.559

h 為梁厚度，K 為沿梁軸的波向量，v_L 為縱向聲速；此模的頻率由縱波聲速而非橫波聲速決定，因為其本質是壓縮／伸張

單一 1D 聲學聲子子能帶的熱容（線性正比於 T）

C_V^{(1D)} = 2π² L k_B² T / (3 h v)

(77) 　p.561

L 為長度，v 為聲速（色散 ω = vk），k_B 為 Boltzmann 常數，h 為 Planck 常數；對比 3D 的 T³ 行為，模數隨 K^D 標度故 1D 給出 T

單一 1D 聲子子能帶的彈道熱導（熱導量子）

G_th^{(1D)} = (π² k_B² T / 3h) ℑ

(78) 　p.561

ℑ 為聲子穿過結構的透射機率；完美透射時 G_th 只由基本常數與絕對溫度決定，與電導量子 2e²/h 類比

④本章最重要的結論

當固體在兩或三個方向被侷限到奈米尺度時，電子與振動的激發都被量子化，而這些量子化直接決定材料性質。電性方面，1D 通道的電導由 Landauer 公式 G = (2e²/h)ℑ 給出，完美通道的電導只由基本常數決定；量子干涉進一步造成共振穿隧、局域化與 Aharonov–Bohm 效應，而 0D 量子點加一個電子需要付出 U + Δε 的電化學位能。熱學方面，室溫下奈米結構的晶格熱性質仍近似塊材的 T³ 行為，但低溫時侷限方向的模凍結，系統轉為 1D，熱容與彈道熱導都變成線性正比於 T，且熱導量子 π²k_B²T/3h 只由基本常數與溫度決定。

⑥與熱容 Cth 的關聯程度　（我的判讀）

直接

p.557–562 是全書唯一處理奈米尺度熱性質的地方。p.561 明講：量子化振動模的能量在室溫下通常小於 k_BT（極小結構除外），因此受限方向的模式在室溫仍會被熱激發——這是「結構縮小時熱容儲存能力不消失」的直接依據。p.562 的彈道熱導量子化則是低溫細線實驗，不可直接外推到室溫元件。
