①主要內容與研究問題

本章要解決自由電子模型無法回答的問題：金屬、半金屬、半導體、絕緣體之間的區別，霍爾係數出現正值的原因，以及傳導電子與自由原子價電子的關係。書中指出純金屬電阻率可低至 10⁻¹⁰ ohm-cm，良好絕緣體可高達 10²² ohm-cm，這 10³² 的跨度可能是固體中最寬的物理性質範圍。為此必須把自由電子模型擴充到考慮晶格週期性，最重要的新性質就是能隙的出現。全章依序建立近自由電子模型（能隙起源於布拉格反射與駐波）、布洛赫定理、Kronig-Penney 模型、週期位能中的波方程與中央方程（central equation），最後計算能帶中的軌域數並據以區分金屬與絕緣體。

②核心物理概念

  • 晶體中的電子排列成能帶，其間隔著沒有波狀電子軌域存在的禁區，稱為能隙（energy gap）或能帶隙（band gap），來自傳導電子波與離子實的交互作用。
  • 能隙的物理起源是電子波在晶體中的布拉格反射：在 k = ±nπ/a 處行進波被反射，時間無關的狀態由駐波表示。
  • 兩個駐波 ψ(+) ∝ cos(πx/a) 與 ψ(−) ∝ sin(πx/a) 把電子分別堆積在正離子實上與離子之間，因而有不同的位能期望值，這就是能隙的來源。
  • 布洛赫定理：週期位能下波方程的本徵函數是平面波 exp(ik·r) 乘上一個具晶格週期性的函數 u_k(r)。
  • 晶體動量 ℏk：k 是標記布洛赫函數的指標，也是碰撞過程守恆律（選擇律）中的量，電子吸收波向量 q 的聲子時選擇律為 k + q = k' + G。
  • 中央方程（central equation）把週期位能中的微分波方程換成一組耦合的代數方程，未知數為傅立葉係數 C(k − G)；實務上常只需二到四項就夠。
  • 在區邊界處二分量近似給出 ε = λ ± U，即位能的傅立葉分量 U 在區邊界造出寬度 2U 的能隙；能量對偏離區邊界的波向量 K̃ 呈二次相依。
  • 每個原胞對每個能帶恰貢獻一個獨立的 k 值；計入自旋後每個能帶有 2N 個獨立軌域，N 為原胞數。
  • 晶體只有在每個原胞的價電子數為偶整數時才可能是絕緣體；若能帶重疊，偶數價電子也會給出金屬（如鹼土金屬）。

③重要模型與公式

一維布拉格反射條件（第一布里淵區邊界）

k = ±(1/2)G = ±nπ/a

(4) 　p.165

布拉格條件 (k + G)² = k² 在一維的結果；G = 2πn/a 為倒晶格向量，n 為整數，a 為晶格常數。−π/a 與 π/a 之間的 k 空間區域為第一布里淵區。

區邊界處的兩個駐波

ψ(+) = exp(iπx/a) + exp(−iπx/a) = 2 cos(πx/a) ； ψ(−) = exp(iπx/a) − exp(−iπx/a) = 2i sin(πx/a)

(5) 　p.165

(+)、(−) 依 x → −x 時是否變號而標記；兩者皆由等量的右行波與左行波組成。對應機率密度 ρ(+) ∝ cos²(πx/a) 把電子堆在 x = 0, a, 2a 的正離子上，ρ(−) ∝ sin²(πx/a) 則把電子集中在離子之間。

能隙等於晶體位能的傅立葉分量

E_g = ∫₀¹ dx U(x) [|ψ(+)|² − |ψ(−)|²] = 2∫dx U cos(2πx/a)(cos²(πx/a) − sin²(πx/a)) = U

(6) 　p.167

取晶體位能 U(x) = U cos(2πx/a)；ψ(+) = cos(πx/a)、ψ(−) = sin(πx/a) 在單位長度上歸一化。此為兩駐波態之間的一階能量差。

布洛赫定理（布洛赫函數形式）

ψ_k(r) = u_k(r) exp(ik·r) ， u_k(r) = u_k(r + T)

(7) 　p.167

u_k(r) 具晶格週期性；T 為晶格平移向量。單電子波函數若為此形式即稱布洛赫函數，可分解為行進波之和，也可組成波包描述電子在離子實位能場中自由傳播。

Kronig-Penney 模型（δ 函數位能極限）

(P/Ka) sin Ka + cos Ka = cos ka

(21b) 　p.169

由 b → 0、U₀ → ∞ 且 Q²ba/2 = P 保持有限的極限取得；K 由 ε = ℏ²K²/2m 定義（井內平面波波數），k 為布洛赫指標，a 為晶格常數。方程有解的 K 範圍即允許能帶，其餘為能隙。

中央方程（週期位能中的波方程的代數形式）

(λ_k − ε) C(k) + Σ_G U_G C(k − G) = 0 ， λ_k ≡ ℏ²k²/2m

(27),(28) 　p.172

C(k) 為波函數傅立葉展開 ψ = Σ_k C(k)e^{ikx} 的係數；U_G 為位能 U(x) = Σ_G U_G e^{iGx} 的傅立葉分量；G 為倒晶格向量。原則上有無限多個 C(k − G) 待定，實務上二到四項常已足夠。

區邊界處的兩個能量根（能隙 2U）

ε = λ ± U = (ℏ²/2m)((1/2)G)² ± U ，且 C(−G/2)/C(G/2) = ±1

(47),(48) 　p.178

λ = ℏ²((1/2)G)²/2m 為區邊界處的自由電子動能；U 為位能的傅立葉分量。兩根一個比自由電子動能低 U、一個高 U，故位能 2U cos Gx 在區邊界造出 2U 的能隙；對應波函數 ψ(x) = exp(iGx/2) ± exp(−iGx/2) 即 (5) 式的駐波。

區邊界附近的兩支能帶

ε = (1/2)(λ_{k−G} + λ_k) ± [(1/4)(λ_{k−G} − λ_k)² + U²]^(1/2)

(50) 　p.179

以 ψ(x) = C(k)e^{ikx} + C(k−G)e^{i(k−G)x} 的二分量近似求得；λ_k = ℏ²k²/2m。兩個根各描述一個能帶。以 K̃ ≡ k − (1/2)G 展開後得 ε_K̃(±) = ε(±) + (ℏ²K̃²/2m)(1 ± 2λ/U)，顯示能量對 K̃ 的二次相依。

④本章最重要的結論

晶體中的電子波在布里淵區邊界發生布拉格反射，形成駐波而非行進波；兩個駐波把電荷分別堆積在離子實上與離子之間，位能期望值不同，於是在區邊界張開能隙——書中稱 Fig. 3 是理解能隙起源的關鍵。週期位能下的解必為布洛赫形式 ψ_k(r) = e^{ik·r}u_k(r)，而波方程可改寫成中央方程這組代數方程；在二分量近似下區邊界能隙寬度就等於位能的傅立葉分量所給的 2U。每個能帶含 2N 個軌域（N 為原胞數），因此只有當每個原胞的價電子數為偶整數且能帶不重疊時晶體才是絕緣體；鹼金屬與貴金屬每原胞一個價電子必為金屬，鹼土金屬雖有兩個價電子卻因能帶重疊而成為（不甚好的）金屬，而金剛石、矽、鍺每原胞八個價電子且能帶不重疊，在絕對零度為絕緣體。
