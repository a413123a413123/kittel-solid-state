06

高溫極限與低溫 T³ 定律

溫區定位：低溫區　T ≪ θ　·　θ 的十分之一以下

①物理意義與直觀解釋　（我寫的教學說明）

Debye 積分式沒有初等解析解，但它的**兩個極限**都有，而且這兩個極限就是全部的物理。

**高溫（T ≫ θ）**：所有模式都被激發，量子化不可見，回到 Dulong–Petit 的 3Nk_B。數學上是把積分中的 x = ℏω/k_BT 當小量展開。

**低溫（T ≪ θ）**：積分上限 θ/T → ∞，變成一個可以查表的定積分，結果是 **C ∝ T³**。

T³ 的**物理來源**用數格子就能理解：溫度 T 時只有能量 ℏω ≲ k_BT 的模式會被激發，也就是波向量小於某個「熱波向量」K_T 的那些。在三維 K 空間裡，被激發的模式數正比於半徑 K_T 的球體積，也就是 ∝ K_T³ ∝ T³。每個被激發的模式大約帶 k_BT 的能量，所以 U ∝ T³ · T = T⁴，微分得 **C ∝ T³**。指數 3 直接來自**空間維度**——這也是為什麼二維系統會得到 T²、一維會得到 T。

**適用範圍要記清楚**：Kittel 明講 T³ 律的適用區在 **0.1θ 以下**，不是「T < θ」。在 0.1θ 到 θ 之間是過渡區，兩個極限都不準，只能算完整的 Debye 積分。這一點在解讀實驗數據時很容易搞錯。

②重要公式與符號定義　（書中）

Debye T³ 定律（極低溫極限）

C_V ≅ (12π⁴/5) N k_B (T/θ)³ ≅ 234 N k_B (T/θ)³

(32) 　Ch5 p.114

由把積分上限取為無窮大、並用 ∫₀^∞ dx x³/(eˣ−1) = π⁴/15（式 (31)）得到；實際晶體常需低於 θ/50 才有純 T³ 行為

Debye 模型熱容（完整式）

C_V = 9Nk_B (T/θ)³ ∫₀^{x_D} dx · x⁴ eˣ / (eˣ − 1)²

(30) 　Ch5 p.113

由 U = 9Nk_BT(T/θ)³∫₀^{x_D}dx x³/(eˣ−1)（p.113 明言的式 (26) 中間表達式）對溫度微分；x_D = θ/T；T ≫ θ 時趨近古典值 3Nk_B

③推導所使用的假設　（書中）

  • 晶格熱容來自簡諧振子集合，各聲子模的熱平衡佔據數服從 Planck 分布 ⟨n⟩ = 1/(exp(ℏω/τ) − 1)，τ ≡ k_B T；總能為各模能量之和 U_lat = Σ_K Σ_p ⟨n_{K,p}⟩ℏω_{K,p}（p.107）。
  • 態密度計數採週期性邊界條件，在邊長 L 的立方體內含 N³ 個原胞，K 空間中每 (2π/L)³ 體積有一個允許的 K 值（p.111）。
  • Debye 近似：聲速對每一種偏振都取為常數，「如同古典彈性連續體」，色散關係寫成 ω = vK（p.112）。
  • 為簡便假設聲子速度與偏振無關，故乘以因子 3 得到三個偏振的總和（p.112）。
  • 截止頻率 ω_D 由「聲學聲子模總數等於原胞數 N」決定：ω_D³ = 6π²v³N/V，對應截止波向量 K_D = (6π²N/V)^{1/3}；Debye 模型不允許 K > K_D 的模，K ≤ K_D 的模已用盡單原子晶格的自由度（p.112）。
  • Debye 溫度定義 θ = (ℏv/k_B)(6π²N/V)^{1/3}，並令 x ≡ ℏω/τ、x_D ≡ θ/T（p.112）。
  • 低溫 T³ 定律的推導是把積分上限 x_D 放到無窮大，並用 ∫₀^∞ dx x³/(eˣ−1) = π⁴/15（p.114）。
  • 整章的晶格振動理論在位能上只保留原子位移的二次項，即簡諧理論（p.119）。

④適用條件與限制　（書中）

  • T³ 近似在「足夠低溫」才成立，也就是只有長波長聲學模被熱激發時；這些正是可以用巨觀彈性常數當作彈性連續體處理的模（p.114）。
  • 短波長模（近似對它們失效者）的能量太高，低溫下無法被顯著佔據，所以低溫下可忽略（p.114）。
  • 對真實晶體，T³ 近似成立的溫度相當低；書中明講「可能必須低於 T = θ/50 才能得到相當純的 T³ 行為」（p.114）；圖 7 圖說另註明 T³ 定律的區域在 0.1θ 以下（p.113）。
  • Einstein 模型低溫時 C_V 以 exp(−ℏω/τ) 衰減，與實驗已知的聲子貢獻 T³ 形式不符——後者要由 Debye 模型才能解釋；但 Einstein 模型常被用來近似聲子譜中的光學聲子部分（p.117）。
  • 高溫熱容變成常數是簡諧理論的推論之一（T > θ）；書中明講「在真實晶體中這些推論沒有一項被準確滿足」，偏差歸因於忽略了非簡諧（高於二次）項（p.119–120）。
  • 書中討論的是定容熱容 C_V，而實驗量到的是 C_p；熱力學關係 C_p − C_V = 9α²BVT，其分數差在固體中通常很小、常可忽略，且 T → 0 時 C_V → C_p（p.107 註腳）。
  • Debye 的 D(ω) 只是理想化：真實晶體的頻譜在小 ω 時同樣以 ω² 起始，但在奇異點會出現不連續（Van Hove 奇異性）（p.119）。

⑤高溫與低溫行為　（書中）

高溫　T ≫ θ

在 T ≫ θ 時 Debye 熱容趨近古典值 3Nk_B（p.113）；圖 7 的圖說給出高 T/θ 的漸近值為 24.943 J mol⁻¹ deg⁻¹（p.113）。Einstein 模型的高溫極限同樣是 C_V → 3Nk_B，書中稱之為 Dulong and Petit 值（p.117）。從 Planck 分布看，高溫時某態的佔據數約與溫度成線性（p.106，圖 1 圖說）。簡諧理論的推論之一即「高溫（T > θ）時熱容變成常數」（p.119）。

低溫　T ≪ θ

極低溫時把式 (29) 的積分上限放到無窮大，得 U ≅ 3π⁴Nk_BT⁴/5θ³，以及 C_V ≅ (12π⁴/5)Nk_B(T/θ)³ ≅ 234 Nk_B(T/θ)³，即 Debye T³ 近似（p.114）。書中另給一個簡單論證：低溫下只有 ℏω < k_BT 的模會被顯著激發、每個約帶 k_BT 的古典能量，K 空間中被佔據的比例約為 (K_T/K_D)³ = (T/θ)³，故被激發的模約 3N(T/θ)³ 個，U ~ 3Nk_BT(T/θ)³，C_V ~ 12Nk_B(T/θ)³（p.114–115，圖 10）。實驗上固態氬的低溫熱容對 T³ 作圖與 Debye T³ 定律吻合極佳，θ = 92.0 K（p.115，圖 9）。相對地，Einstein 模型低溫是 exp(−ℏω/τ) 指數衰減，與實驗的 T³ 不符（p.117）。
