路線圖：這一段在第 6 章裡要完成哪三件事我的判讀

第 6 章要用「自由電子費米氣體」這個最簡單的模型，去解釋金屬的熱容、電導、Hall 效應與熱導——章首 p.131 的目錄依序列出了這些小節。本段（p.131–137）是整章的地基，一共做三件事，而且環環相扣。

第一件：論證為什麼可以把價電子當成自由粒子，並指出古典版本錯在哪裡。章首導論（p.133–134）先用鈉的離子實大小說明「離子實只佔晶體體積的一小部分」，接著盤點古典自由電子理論的成績單：Ohm 定律的形式、電導與熱導的關係，這兩項答對了；熱容與磁化率則答錯了。Kittel 在這裡下了一個關鍵判斷：錯的是古典的 Maxwell 分布，不是自由電子模型本身。這句話決定了整章的策略——模型保留，統計換掉。

第二件：在最簡單的幾何（一維盒子）裡，示範「量子化加上 Pauli 原理」如何產生費米能。p.134–135 解一維無限位井，得到能階 ε_n ∝ n²，再依 Pauli 原理把 N 個電子由下往上填，最高填到的能階就是費米能 ε_F。這個一維演練的每一步，下一節（p.137 起）都會原封不動地搬到三維，差別只在於「數整數 n」換成「數 k 空間中的格點」。

第三件：溫度不為零時，占據情形怎麼變。p.136–137 引入費米-狄拉克分布 f(ε)，並指出其中的化學勢 μ 由「總電子數固定」這個條件決定，T → 0 時 μ 就等於 ε_F。Figure 3 取 T_F = 50,000 K，畫出不同溫度下的 f(ε)；這張圖到了 p.142 計算電子熱容時還會再被引用。

讀完這一段，你應該能從零推出 ε_F = (ℏ²/2m)(Nπ/2L)²，說清楚 ε_F 與 μ 的差別，並解釋為什麼「只有費米面附近 k_BT 範圍內的電子會參與熱激發」。後面的電子熱容、Pauli 順磁、Wiedemann–Franz 定律，全都是從這一點長出來的。

自由電子模型的定義，以及 Kittel 自己劃下的適用邊界（p.133）

第 6 章以 H. A. Lorentz 的一句題詞開場，大意是：一個能給出這些成果的理論，裡面必定有很大一部分是真的。（本站判讀）這是一種「有保留的肯定」。

正文第一段給出模型的定義：組成金屬的原子，其價電子變成傳導電子（conduction electrons），在金屬的整個體積內自由運動。Kittel 說，許多金屬的物理性質都可以用這個模型理解，而且不限於簡單金屬。

但他立刻劃出兩條邊界。第一，即使在自由電子模型最適用的金屬裡，傳導電子的電荷分布仍然反映出離子實強烈的靜電位。第二，這個模型對於「本質上取決於傳導電子動力學性質（kinetic properties）」的物理量最有用。至於傳導電子與晶格離子之間的交互作用，留到下一章處理。

（本站判讀）換句話說，這裡的「自由」指的是運動學上的處理方式，並不是宣稱電子感受不到離子。本章把離子的效應整個擱置，第 7 章（能帶）才把它加回來。

鈉：最簡單的金屬，以及 Figure 1（書 p.132）在畫什麼

Kittel 以鹼金屬作為最簡單的金屬，列出鋰、鈉、鉀、銫、銣。以鈉為例：自由鈉原子的價電子處在 3s 態；進入金屬後，這顆電子成為 3s 傳導帶中的傳導電子。所以一個含 N 個原子的一價晶體，會有 N 個傳導電子與 N 個帶正電的離子實。

Na⁺ 離子實含 10 個電子，佔據自由離子的 1s、2s、2p 殼層（組態 1s²2s²2p⁶），而且這些電子的空間分布在金屬中與在自由離子中基本上相同。（本站判讀）這一點很重要：形成金屬時改變的只有最外層那一顆 3s 電子，內殼層不受影響，所以可以把離子實當成一個剛性的正電荷來處理。

接著是整段最具體的數字：離子實只填滿鈉晶體體積的約 15%。依據是：自由 Na⁺ 離子的半徑為 0.98 Å，而金屬中最近鄰距離的一半是 1.83 Å。

Figure 1 的文字描述。這是一張示意圖：灰色矩形底色代表傳導電子之「海」，上面排著兩列、每列三個白色小圓，圓內標「+」，代表 Na⁺ 離子實。圓的直徑遠小於圓與圓之間的距離，用視覺傳達「離子實稀疏地浸在電子海中」。圖說重述了正文已有的兩點：傳導電子來自自由原子的 3s 價電子；在鹼金屬中離子實只佔晶體總體積相對小的一部分（約 15%）。並補充了正文沒有的兩點：在貴金屬（Cu、Ag、Au）中，離子實相對較大，可能彼此接觸；室溫下鹼金屬常見的晶體結構是 bcc，貴金屬是 fcc。

核算「約 15%」：兩種算法之間的落差從哪裡來我的判讀

Kittel 只給了兩個半徑與「約 15%」這個結論，沒有寫出計算過程。以下是本站的核算，目的是讓讀者知道這個數字的精確含意。Kittel 實際採用哪一種算法，原文並未說明。

  1. 已知量（p.133）：Na⁺ 自由離子半徑 r_ion = 0.98 Å；最近鄰距離的一半 r_s ≡ ½d_NN = 1.83 Å，所以 d_NN = 3.66 Å。兩個相鄰離子實表面之間的空隙為 d_NN − 2r_ion = 3.66 − 1.96 = 1.70 Å，略窄於離子實本身的直徑（2r_ion = 1.96 Å），約為其 0.87 倍。Fig. 1 把離子實畫得比實際比例稀疏得多，只是示意。
  2. 算法一（半徑比的三次方）：若把每個原子分到的空間近似成一顆半徑 1.83 Å 的「接觸球」，離子實所佔的分率就是 (r_ion/r_s)³ = (0.98/1.83)³ = (0.5355)³ ≈ 0.154，也就是約 15%，與 Kittel 的數字吻合。
  3. 算法二（用 bcc 的真實原子體積）：鈉是 bcc（Fig. 1 圖說）。第 1 章 Table 2（p.10）給出 bcc 的最近鄰距離 = (√3/2)a，所以 a = 2d_NN/√3 = 7.32/1.732 ≈ 4.23 Å。bcc 慣用晶胞含 2 個原子，每原子體積 V_at = a³/2 ≈ 37.7 Å³。
  4. 離子實體積 V_core = (4π/3)(0.98 Å)³ ≈ 3.94 Å³，所以 V_core/V_at ≈ 3.94/37.7 ≈ 0.104，約 10%。
  5. 兩者為何不同：半徑 1.83 Å 的接觸球在 bcc 排列中只能填滿 68% 的空間（第 1 章 Table 2 的 bcc packing fraction 0.680）。每個原子真正分到的體積比一顆接觸球大 1/0.680 倍，所以算法一高估了離子實的佔比。驗算：0.154 × 0.680 ≈ 0.104，正好是算法二的結果。
  6. 結論：不論取 10% 還是 15%，結論都一樣——離子實只佔晶體體積的一小部分，85–90% 的空間是傳導電子可以自由運動的地方。這就是自由電子模型在鹼金屬上成立的幾何依據。對照 Fig. 1 圖說，貴金屬的離子實較大、可能彼此接觸，其最外層（填滿的 d 殼層）與傳導電子在空間上大量重疊，所以自由電子圖像在貴金屬上就沒那麼乾淨。

古典自由電子理論的成績單：錯在統計，不在模型（p.133）

Kittel 接著回顧歷史：用自由電子的運動來詮釋金屬性質，早在量子力學發明之前就已經發展出來了。這套古典理論有幾項顯著的成功，尤其是推導出 Ohm 定律的形式，以及電導率與熱導率之間的關係。

但古典理論無法解釋傳導電子的熱容與磁化率。緊接著的括號是本段最重要的一句話，其中關鍵的片語是 "not failures of the free electron model"。完整的意思是：這些並不是自由電子模型的失敗，而是古典 Maxwell 分布函數的失敗。

（本站判讀）這個判斷替整章定了方向：模型本身（電子在金屬體積內自由運動）可以保留，要換掉的只有描述電子如何分布在各能量上的統計。本段後半所引入的 Pauli 原理與費米-狄拉克分布，就是用來替換的新統計。

為什麼 Ohm 定律「躲過了」統計的錯誤，熱容與磁化率卻沒有我的判讀

一個「理論」其實有兩層：(i) 模型——電子是在盒中自由運動、彼此不交互作用的粒子；(ii) 統計——溫度 T 下這些粒子怎麼分布在各個能量狀態上。古典理論在第 (ii) 層用的是 Maxwell–Boltzmann 分布。Kittel 說失敗全出在第 (ii) 層，那麼一個自然的問題是：為什麼有些量躲過了這個錯誤，有些沒有？

Ohm 定律的形式。本章後面得到 σ = ne²τ/m（式 (43)，p.156 推 Wiedemann–Franz 定律時引用）。這個式子只含濃度 n、弛豫時間 τ 與質量 m，完全不含「電子如何分布在各能量上」的資訊。電場讓所有電子得到同樣的漂移，漂移對電流的貢獻就是 n 乘上漂移速度，所以不論採用哪一種統計，Ohm 定律的形式都一樣。

熱容。p.141 指出，古典統計力學預言每個自由粒子的熱容為 (3/2)k_B，但室溫下觀測到的電子熱容通常不到這個值的 0.01。早期的研究者（包括 Lorentz）都被這個矛盾困擾：電子在導電時表現得像是可以自由移動，為什麼卻不貢獻熱容？這也讓章首那句 Lorentz 的題詞多了一層意味。熱容問的是「升溫時有多少電子能吸收能量」，這正是分布函數的核心問題。Fermi 統計的答案是：只有能量在 ε_F 附近約 k_BT 範圍內的電子會被激發，比例約為 T/T_F（p.141）。

磁化率。如果傳導電子服從古典統計，它們的自旋磁矩應該像自由順磁離子一樣，貢獻一個與 1/T 成正比的 Curie 型磁化率。但實驗發現，大多數非鐵磁金屬的磁化率與溫度無關。第 11 章 p.316 說明，Pauli 用費米-狄拉克分布修正了這個理論（Pauli 順磁性）。道理和熱容相同：只有費米面附近的電子能夠翻轉自旋。

電導與熱導的關係。古典理論在這一項也「答對」，但其實帶著運氣成分，見下一個區塊。

歸納成一句話：只依賴「有幾顆電子、多久碰撞一次」的量，古典理論能答對形式；依賴「哪些電子能被激發」的量，古典理論必錯。讀完整章後，這個分類標準是最值得帶走的判斷力。

延伸：古典 Lorenz 數——兩個「近百倍誤差」互相抵消的歷史巧合延伸知識

本區塊是本站延伸的內容。Kittel 在本段只說古典理論推出了「電導與熱導的關係」，p.156–157 的 Wiedemann–Franz 小節也只給量子結果，這兩處都沒有寫出古典的係數。這裡把古典算法補出來，讓「古典理論答對了這個關係」這句話有具體的內容。

  1. 共同的出發點：熱導率 K = (1/3)Cvℓ = (1/3)Cv²τ（C 為單位體積熱容，ℓ = vτ；p.156 也從這一式出發）；電導率 σ = ne²τ/m。
  2. 古典代入：每顆電子的熱容為 (3/2)k_B，所以 C = (3/2)nk_B；由能量均分 ½m⟨v²⟩ = (3/2)k_BT 得 ⟨v²⟩ = 3k_BT/m。
  3. K = (1/3) · (3/2)nk_B · (3k_BT/m) · τ = (3/2)nk_B²Tτ/m。
  4. K/σ = [(3/2)nk_B²Tτ/m] / [ne²τ/m] = (3/2)(k_B/e)²T。所以古典 Lorenz 數為 L_cl = (3/2)(k_B/e)² ≈ 1.11×10⁻⁸ W·Ω/K²。n、τ、m 全部消去，K/σ ∝ T 且與金屬種類無關——這就是古典理論答對的「形式」。
  5. 量子結果（p.157 式 (59)）：L = (π²/3)(k_B/e)² = 2.45×10⁻⁸ W·Ω/K²；p.157 Table 5 的實驗值多落在 2.2–2.8×10⁻⁸（W 約 3.0–3.2×10⁻⁸）。古典值只有量子值的 (3/2)/(π²/3) = 9/(2π²) ≈ 0.46 倍。
  6. 為什麼古典值還算接近：古典熱容 (3/2)nk_B 比費米氣體的 (π²/2)nk_B(T/T_F)（p.144 式 (36) 除以體積）大了 3T_F/(π²T) 倍，以 T_F = 5×10⁴ K、室溫計約 50 倍；古典的 ⟨v²⟩ = 3k_BT/m 卻比費米速度的平方 v_F² = 2ε_F/m 小了 (2/3)(T_F/T) 倍，同樣條件下約 110 倍。兩個誤差在乘積 Cv² 中幾乎完全抵消，只剩下 9/(2π²) 這個係數差。
  7. 歷史註記（依 Ashcroft & Mermin《Solid State Physics》第 1 章的記述）：Drude 原始的計算把電導率少算了一個因子 2，結果得到約 2.2×10⁻⁸，與實驗「驚人地」吻合。所以古典理論在這一項的成功，是形式正確，外加數值上的運氣。

另一個古典難題：電子為什麼能直走超過一公分？（p.133–134）

除了熱容與磁化率，古典模型還有一個更深的困難。許多種實驗都清楚顯示，金屬中的傳導電子可以沿直線自由移動許多個原子間距，途中既不被其他傳導電子偏折，也不被原子實偏折。在低溫下的極純樣品中，平均自由程可以長達 10⁸ 個原子間距（超過 1 cm）。Kittel 由此發問：為什麼凝聚態物質對傳導電子如此「透明」？

他的回答分成兩部分。

(a) 關於離子實：排列在週期性晶格上的離子實不會使傳導電子偏折，因為物質波可以在週期結構中自由傳播。這是下一章數學處理的結果。（原文把 periodic 一字以斜體強調。）

(b) 關於其他傳導電子：傳導電子只偶爾才被其他傳導電子散射，這個性質是 Pauli 不相容原理的結果。

在這兩點之後，Kittel 給出本章主角的定義：自由電子費米氣體（free electron Fermi gas）指的是一群服從 Pauli 原理的自由電子所構成的氣體。

校註：文字層把 10⁸ 抽成「10 8」，上標變成了一般數字。由括號中「超過 1 cm」的換算（見下一區塊）可以確認指數是 8。

把 (a)、(b) 接到後面的章節：Bloch 定理與 Pauli 阻塞我的判讀

先驗算數字。以鈉的最近鄰距離 3.66 Å 當作原子間距，10⁸ 個間距是 3.66×10⁸ Å ≈ 3.7 cm，確實「超過 1 cm」。古典直覺認為電子在離子實之間每隔幾 Å 就會撞一次，兩者相差了八個數量級，這就是需要解釋的量級。

(a) 的內容是第 7 章的 Bloch 定理。第 7 章章首的題詞引自 Bloch 本人，大意是：他當初思考的主要問題，是解釋電子如何能從金屬中所有離子旁邊「溜過去」；而透過直接的 Fourier 分析，他發現週期位勢中的波與自由電子的平面波只差一個週期性的調變。這就是 p.167 起的 Bloch 函數。由此推得：在完美週期的晶格中，電子態是穩態，本身沒有散射；電阻只能來自偏離完美週期性的因素，也就是晶格熱振動（聲子）、雜質與缺陷。這也說明了為什麼長平均自由程只出現在「極純」且「低溫」的樣品上：純度壓低雜質散射，低溫壓低聲子散射。

(b) 的定量版本在第 14 章。p.417–419 用相空間論證說明 Pauli 原理怎麼壓低電子–電子碰撞。設一顆能量比費米面高 ε₁ 的電子要與費米海中的電子碰撞：(i) 能當作靶的電子只有費米面內厚度約 ε₁ 的殼層，佔 ε₁/ε_F；(ii) 碰撞後的兩個末態都必須落在費米球外的空位上，又只剩約 ε₁/ε_F 的比例。兩者相乘，碰撞率被壓低 (ε₁/ε_F)² 倍；在熱分布中以 k_BT 取代 ε₁，就得到 (k_BT/ε_F)² 的抑制因子。Kittel 在那裡給出的數字是：室溫下電子–電子碰撞的平均自由程約 10⁻⁴ cm，比電子–聲子碰撞的平均自由程長至少 10 倍；1 K 時超過 10 cm；銦在 2 K 約 30 cm；低溫電阻率中與 T² 成正比的那一項，就是這個機制留下的痕跡。

為什麼 (b) 是本章的主題，(a) 不是。(a) 需要週期位勢，而本章刻意忽略位勢；(b) 只需要 Pauli 原理加上自由電子，這正好是「自由電子費米氣體」定義裡的全部要素。所以 Kittel 在列完兩點之後，立刻用「服從 Pauli 原理的自由電子氣」來定義本章的研究對象。

一維問題的設定：無限位壘之間的一顆電子（p.134）

「ENERGY LEVELS IN ONE DIMENSION」一節的出發點是：考慮一維的自由電子氣，同時納入量子理論與 Pauli 原理。一顆質量為 m 的電子被無限高的位壘限制在長度 L 之內（Fig. 2）。電子的波函數 ψ_n(x) 是 Schrödinger 方程式 ℋψ = εψ 的解。忽略位能時 ℋ = p²/2m，其中 p 是動量；在量子理論中，p 可以用算符 −iℏ d/dx 表示，於是得到式 (1)。式中的 ε_n 是電子處在該 orbital 時的能量。

校註（符號）：本頁的哈密頓量印成花體 ℋ（以算繪影像確認）；同一個花體字符在全書另見於 p.53、55、56、171、289、301、439，上下文也都是哈密頓量。另外，PDF 文字層把算符 −iℏ d/dx 中的 ℏ 抽離成浮出的片段，只剩下「−i d/dx」，本文以影像為準。

一維自由電子的 Schrödinger 方程式

ℋψ_n = −(ℏ²/2m) d²ψ_n/dx² = ε_n ψ_n

(1) 　p.134

ℋ：哈密頓量算符，此處等於 p²/2m；ψ_n(x)：量子數為 n 的單電子波函數（orbital）；m：電子質量；ℏ = h/2π；ε_n：電子處在該 orbital 時的能量。適用區間為 0 < x < L。

出處推導
由 ℋψ = εψ 出發，忽略位能，所以 ℋ = p²/2m；再把動量換成算符 p → −iℏ d/dx，得到 p² = (−iℏ)² d²/dx² = −ℏ² d²/dx²，除以 2m 即得。「忽略位能」的精確含意是：在 0 < x < L 之內位能取為常數零，位能的所有效應都集中在兩端無限高的牆上，改由邊界條件 ψ_n(0) = ψ_n(L) = 0 來表達。離子實的週期位勢在這裡完全被抹平。
極限行為
這是一條二階常係數線性微分方程 ψ'' = −(2mε/ℏ²)ψ。ε > 0 時解是振盪的正弦波；ε < 0 時解是指數型，無法同時在兩端歸零（見下方推導），所以盒中電子沒有負能量態。若把牆移到無窮遠（L → ∞），解退化為平面波 e^{ikx}，對應真正的自由粒子；p.137 起的三維處理改用週期性邊界條件，就是為了直接使用這種行進平面波。若在盒內加入週期位勢 U(x)，方程式就變成第 7 章處理的晶體中電子方程式，能帶與能隙便由此產生。
典型數值
常用組合：以自由電子質量計，ℏ²/2m = 3.81 eV·Å²。本段後面的數值估計都用這個值。

orbital：單電子解與 N 電子精確態的區分（p.134）

Kittel 在這裡特別定義了一個術語：orbital 指的是只有一顆電子的系統，其波動方程式的解。

引入這個詞，是為了區分兩種東西。第一種是 N 顆有交互作用的電子所構成的系統，其波動方程式的精確量子態。第二種是一個近似的量子態，做法是把 N 顆電子分派到 N 個不同的 orbital 上，而每一個 orbital 都是某個單電子波動方程式的解。Kittel 明言：只有在電子之間沒有交互作用時，orbital 模型才是精確的。

（本站判讀）因此，本章之後說「某個 orbital 被占據」或「orbital 的占據機率 f(ε)」（p.136），指的都是在獨立電子近似下，用「哪些單電子態被填了」來描述整個 N 電子系統。式 (1) 的 ψ_n 是一個 orbital，ε_n 是這個 orbital 的能量，而不是整個系統的能量。

orbital 模型能走多遠：Slater 行列式、Fermi 液體，以及與化學用語的差異我的判讀

N 電子態怎麼由 orbital 組成。Kittel 說「把 N 顆電子分派到 N 個不同的 orbital」，這句話在量子力學中的精確寫法是 Slater 行列式：Ψ(x₁,…,x_N) = (1/√N!) det[φ_i(x_j)]。交換任兩顆電子的座標時，行列式變號，這就是費米子的反對稱性；若有兩列相同（兩顆電子放進同一個 orbital），行列式為零。所以在這種寫法裡，Pauli 原理是自動成立的。沒有交互作用時，哈密頓量是各個單電子哈密頓量之和，Slater 行列式就是精確的本徵態，總能量等於所有被占據 orbital 的能量之和。這正是 Kittel 所說「orbital 模型只在無交互作用時精確」的數學內容。

有交互作用時為什麼還能用。真實金屬中的電子彼此有庫侖交互作用，平均間距只有幾 Å，交互作用能與動能同一量級，照理說 orbital 圖像應該崩潰。第 14 章 p.417 給出了答案。Kittel 在那裡區分兩個名詞：無交互作用的費米子系統稱為 Fermi 氣體，有交互作用的同一系統稱為 Fermi 液體。Landau 理論指出，Fermi 液體的低能單粒子激發（稱為準粒子，quasiparticle）與自由電子氣的單粒子激發一對一對應，只是質量等參數被重新標定；例如鹼金屬的有效質量約增加 25%。所以本章的 orbital 語言，在費米面附近的低能物理上仍然成立，只要把參數換成實驗值即可。

與化學中 orbital 的差異。化學裡的 orbital 通常指原子或分子中束縛電子的單電子態（1s、2p、σ、π 等）。Kittel 的用法更廣：任何單電子波動方程式的解都叫 orbital，包括本節盒中的正弦波，以及下一節的平面波。

邊界條件：0 到 L 之間要有整數個半波長（p.134）

無限高位壘所施加的邊界條件是 ψ_n(0) = 0 與 ψ_n(L) = 0。Kittel 指出，只要波函數是正弦型，並且在 0 到 L 之間恰好有整數 n 個半波長，就能滿足這兩個條件，結果寫成式 (2)，其中 A 是常數。

接著他驗證式 (2) 確實是式 (1) 的解，寫出一階導數 dψ_n/dx = A(nπ/L)cos(nπx/L) 與二階導數 d²ψ_n/dx² = −A(nπ/L)² sin(nπx/L)，然後說由此得到能量 ε_n，即式 (3)。

書中的論述順序是「給出正弦解、驗證它、讀出能量」，並沒有說明為什麼只能是正弦解、n 為什麼只取正整數，也沒有給出 A 的值。下面兩個推導區塊把這些補齊。

補：從式 (1) 與邊界條件一步步解出 ψ_n補推導

Kittel 直接寫下正弦解再加以驗證。以下把這個邊界值問題完整解一次。「整數個半波長」的計數，與第 5 章固定端晶格振動的駐波模式在數學上完全同構，差別只在於第 5 章數的是原子位移的模式，這裡數的是電子的波函數。

  1. 盒內（0 < x < L）位能為零，式 (1) 可以改寫成 d²ψ/dx² = −(2mε/ℏ²)ψ。盒外位能無窮大，所以 ψ ≡ 0；由波函數的連續性，ψ 在牆上必須歸零：ψ(0) = ψ(L) = 0。（ψ 的一階導數在牆上可以不連續，這是無限高位壘所允許的。）
  2. 先排除 ε ≤ 0。若 ε < 0，令 κ² = −2mε/ℏ² > 0，通解為 ψ = Ce^{κx} + De^{−κx}。ψ(0) = 0 給出 D = −C，於是 ψ = 2C sinh κx；ψ(L) = 0 要求 sinh κL = 0，但 κL > 0 時 sinh κL > 0，所以只能 C = 0。若 ε = 0，則 ψ = a + bx，兩端歸零給出 a = b = 0。兩種情形都只剩平凡解 ψ ≡ 0，因此盒中電子的能量必定為正。
  3. ε > 0 時，令 k ≡ √(2mε)/ℏ > 0，通解為 ψ = A sin kx + B cos kx。
  4. 左端：ψ(0) = B = 0，所以 ψ = A sin kx。
  5. 右端：ψ(L) = A sin kL = 0。A = 0 是平凡解，所以必須 sin kL = 0，也就是 kL = nπ，k_n = nπ/L。
  6. n 的取值：n = 0 給出 ψ ≡ 0，不是物理態；n 取負整數時 sin(−|n|πx/L) = −sin(|n|πx/L)，兩者只差一個整體正負號（整體相位），描述的是同一個態，不能重複計數。所以 n = 1, 2, 3, …，與書上「n 為任意正整數」（p.135）一致。
  7. 與書上式 (2) 的形式對照：波長 λ_n = 2π/k_n = 2L/n，也就是 ½nλ_n = L，意思是長度 L 內恰好容納 n 個半波長。代回得 2π/λ_n = nπ/L，所以式 (2) 的 A sin(2πx/λ_n) 就是 A sin(nπx/L)。
  8. 歸一化（書上把 A 留作常數）：∫₀ᴸ A² sin²(nπx/L) dx = A²·L/2 = 1，得 A = √(2/L)，與 n 無關。
  9. 正交性：∫₀ᴸ sin(nπx/L) sin(n′πx/L) dx = (L/2)δ_{nn′}。不同 n 的 orbital 彼此正交，所以「把電子分派到不同的 orbital」是一個定義良好的操作。

盒中電子的波函數，與「整數個半波長」條件

ψ_n = A sin(2πx/λ_n) ； ½ nλ_n = L

(2) 　p.134

A：常數（歸一化後為 √(2/L)，書上沒有給出）；λ_n：第 n 個 orbital 的波長；n：正整數，等於 0 到 L 之間的半波長個數；x：位置，0 ≤ x ≤ L。校註：文字層把 ½ 就地抽成「1 2」，算繪影像確認為 ½nλ_n = L。

出處推導
由無限位壘的邊界條件 ψ_n(0) = ψ_n(L) = 0 得出，完整推導見上一區塊。它等價於 ψ_n = A sin(nπx/L)，也就是書中下一行求導數時所用的形式。
極限行為
n = 1 時 λ = 2L，盒內只有半個波，波函數在中央最大、沒有節點，這是基態。第 n 個 orbital 在盒內有 n − 1 個節點（不含兩端），節點數隨能量遞增，這是一維束縛態的普遍規律。n 很大時，波長 2L/n 遠小於 L，波函數在盒內快速振盪，機率密度 |ψ|² = (2/L)sin²(nπx/L) 在粗粒化平均之下趨近均勻的 1/L，回到古典粒子「在盒中各處出現機率相同」的圖像，這就是對應原理。

補：把式 (2) 代回式 (1)——書中兩條導數之後省略的那一行補推導

Kittel 寫出 dψ_n/dx 與 d²ψ_n/dx² 之後，直接說「由此得到」式 (3)，中間的代入與比較係數沒有寫出來。這一步雖然短，卻是驗證本徵方程的標準動作，值得寫清楚。

  1. 取 ψ_n = A sin(nπx/L)。一階導數（書上已給）：dψ_n/dx = A(nπ/L) cos(nπx/L)。
  2. 二階導數（書上已給）：d²ψ_n/dx² = −A(nπ/L)² sin(nπx/L)。
  3. 關鍵的觀察（書上省略）：右邊的 A sin(nπx/L) 正是 ψ_n 本身，所以 d²ψ_n/dx² = −(nπ/L)² ψ_n。二次微分只把原函數乘上一個常數，這就是「ψ_n 是本徵函數」的意思。
  4. 代入式 (1) 的左邊：ℋψ_n = −(ℏ²/2m)·[−(nπ/L)²ψ_n] = (ℏ²/2m)(nπ/L)² ψ_n。
  5. 與式 (1) 右邊的 ε_nψ_n 比較。上式對所有 x 都成立，且 ψ_n 不恆為零，所以係數必須相等：ε_n = (ℏ²/2m)(nπ/L)²，也就是式 (3)。
  6. 換個角度讀式 (3)：令 k_n = nπ/L，則 ε_n = ℏ²k_n²/2m，與自由粒子的色散關係 ε = p²/2m = ℏ²k²/2m 完全相同。盒子並沒有改變能量與波向量的關係，它只把 k 限制成 π/L 的整數倍。
  7. 要注意的一點：sin(k_nx) = [e^{ik_nx} − e^{−ik_nx}]/2i 是動量 +ℏk_n 與 −ℏk_n 兩個態的疊加，所以 ψ_n 是能量本徵態，卻不是動量本徵態；量測動量會以相等的機率得到 ±ℏnπ/L。p.137 起的三維處理改用週期性邊界條件與行進平面波，在那裡 ψ_k 同時是能量與動量的本徵態（p.138 式 (13)）。

一維盒中電子的能階

ε_n = (ℏ²/2m)(nπ/L)²

(3) 　p.134

ε_n：第 n 個 orbital 的能量；n = 1, 2, 3, …；L：盒長；m：電子質量；ℏ：約化 Planck 常數。

出處推導
把式 (2) 代入式 (1)，利用 d²ψ_n/dx² = −(nπ/L)²ψ_n 比較係數而得（見上一區塊）。
極限行為
能量正比於 n²：能階不是等間距的，相鄰間距 ε_{n+1} − ε_n = (2n + 1)ε₁ 隨 n 線性增加；但相對間距 (ε_{n+1} − ε_n)/ε_n ≈ 2/n 隨 n 變小，所以高能處的能階在相對意義上越來越密。能量正比於 1/L²：盒子越小，能階越高、間距越大，這是量子侷限效應最簡單的形式；L → ∞ 時所有間距趨於零，能譜變成準連續，回到自由粒子。基態能量不為零：ε₁ = ℏ²π²/2mL² > 0，這是零點能，與測不準原理一致——位置被限制在 Δx ~ L，動量的不確定度 Δp ~ ℏπ/L，對應的動能約為 (Δp)²/2m。與色散關係的關係：ε_n = ℏ²k_n²/2m，k_n = nπ/L，能階就是自由粒子拋物線 ε(k) 在 k = π/L 整數倍處的取樣。
典型數值
以 ℏ²/2m = 3.81 eV·Å²（自由電子質量）計算，ε₁ = 3.81 × π²/L² ≈ 37.6 eV·Å²/L²（L 以 Å 為單位）。L = 1 cm（10⁸ Å）：ε₁ ≈ 3.8×10⁻¹⁵ eV，完全無法察覺。L = 10 nm：ε₁ ≈ 3.8 meV，約為液氦溫度下 k_BT（4.2 K 時約 0.36 meV）的 10 倍。L = 1 nm：ε₁ ≈ 0.38 eV，已是室溫（300 K）k_BT ≈ 25.9 meV 的約 15 倍。可見盒子尺寸從公分縮到奈米時，量子化才從「數學上存在」變成「實驗上重要」。

補：圖說的 (h²/2m)(n/2L)² 與式 (3) 的 (ℏ²/2m)(nπ/L)² 是同一個量補推導

正文式 (3) 用 ℏ，Fig. 2 的圖說卻用 h 寫成 (h²/2m)(n/2L)²，而同一張圖的縱軸單位又用 ℏ 寫成 (ℏ²/2m)(π/L)²。第一次讀很容易以為兩式差了 π² 或 4 之類的因子。以下用兩種方法證明它們完全相等。

  1. 代數證法：h = 2πℏ，所以 h² = 4π²ℏ²。
  2. (h²/2m)(n/2L)² = (4π²ℏ²/2m)·(n²/4L²) = (ℏ²/2m)·(4π²n²/4L²) = (ℏ²/2m)(nπ/L)²。分子與分母的 4 對消，正是式 (3)。
  3. 物理證法（de Broglie 關係）：由式 (2)，λ_n = 2L/n。de Broglie 關係 p = h/λ 給出動量大小 p_n = h/λ_n = hn/2L，於是動能 ε_n = p_n²/2m = (h²/2m)(n/2L)²。圖說的寫法其實就是「動量 = h/波長」的直接結果，所以自然用 h 而不是 ℏ。
  4. 同一個量用 ℏ 表示：p_n = ℏk_n，k_n = 2π/λ_n = nπ/L，所以 ε_n = (ℏ²/2m)(nπ/L)²。用 ℏ 時的自然變數是波向量 k，用 h 時的自然變數是 1/λ。
  5. 縱軸單位的意義：取 ε₁ = (ℏ²/2m)(π/L)² 為單位，則 ε_n/ε₁ = n²，所以三條能階落在 1、4、9，圖中的刻度就是這樣來的。
  6. 數值上的提醒：h²/2m 與 ℏ²/2m 相差 4π² ≈ 39.5 倍。以自由電子質量計，ℏ²/2m ≈ 3.81 eV·Å²，h²/2m ≈ 150.4 eV·Å²。在數值計算中把兩者混用，結果會差約 40 倍，這是本節最常見的數值錯誤。

Pauli 原理、量子數 (n, m_s) 與自旋（p.134–135）

現在要把 N 顆電子放到這條線上。依據 Pauli 不相容原理，沒有兩顆電子能擁有完全相同的一組量子數；換句話說，每個 orbital 最多只能被一顆電子占據。Kittel 強調，這一點適用於原子、分子與固體中的電子。

在一維固體中，傳導電子 orbital 的量子數是 n 與 m_s：n 是任意正整數，磁量子數 m_s = ±½，對應兩種自旋取向。因此，由同一個量子數 n 標記的一對 orbital 可以容納兩顆電子，一顆自旋向上、一顆自旋向下。

請留意 Kittel 的計數單位：orbital 由 (n, m_s) 一起標記，所以同一個 n 其實是兩個 orbital，而不是「一個 orbital 裝兩顆電子」。這個用字在後面算態密度時決定了因子 2 的來源：p.138 式 (15) 左邊的因子 2，就是每個 k 允許兩種自旋。

校註：文字層把 m_s = ±½ 抽成「ms =±,」，½ 則掉成浮出的「1 2」，漂到頁末式 (4) 之後。本頁算繪影像確認為 m_s = ±½。

填表背後的物理：基態能量、第一激發態，以及一維的簡併度為何只有 2我的判讀

基態總能。以 ε₁ = (ℏ²/2m)(π/L)² 為單位，六電子基態的總能是 2 × (1 + 4 + 9) ε₁ = 28ε₁。這是 orbital 模型下的總能：沒有交互作用時，N 電子態的能量就是所有被占據 orbital 能量的總和。

為什麼「由下往上填」就是基態。在沒有交互作用、每個 orbital 最多一顆電子的限制下，要讓總能最小，唯一的辦法是把電子放進能量最低的 N 個 orbital。任何其他排法，都至少有一顆電子在較高的 orbital、同時有一個較低的 orbital 空著，把那顆電子往下移就能降低能量。這個論證只用到 Pauli 原理，與維度無關；到了三維，就變成「填滿一顆費米球」（p.138）。

第一激發態。把最上層（n = 3）的一顆電子提升到 n = 4，能量增加 ε₄ − ε₃ = (16 − 9)ε₁ = 7ε₁。注意，激發只能發生在最上層附近：想把 n = 1 的電子提到 n = 2 是不行的，因為 n = 2 已經填滿，Pauli 原理禁止。這已經是本章後面所有熱性質的核心機制——深處的電子被 Pauli 原理「凍結」，只有頂端附近的電子能被激發。

N 為偶數或奇數。Kittel 假設 N 為偶數，這樣最上層 n_F 恰好填滿兩種自旋，基態是唯一的。若 N 為奇數，最上層只有一顆電子，它可以自旋向上或向下，基態為二重簡併，此時 n_F = (N + 1)/2。對巨觀的 N 來說，這個差別可以忽略。

一維的簡併度只有 2。一維盒中每個能量只對應一個 n，簡併只來自自旋。到了三維的立方盒（p.137 式 (7)），能量取決於 n_x² + n_y² + n_z²，不同的整數三元組可以給出相同的能量，例如 (1,1,2)、(1,2,1)、(2,1,1)，簡併度因此大幅增加。能階的簡併結構由維度與對稱性決定，這個觀念在第 7 章以後的能帶與態密度中會反覆出現。

補：從填表到式 (4)——2n_F = N、奇數 N，以及 ε_F 只依賴線密度補推導

Kittel 用一句「條件 2n_F = N 決定 n_F」就直接寫出式 (4)。這裡把邏輯補齊，並指出式 (4) 最重要的一個性質：它是強度量。

  1. 定義 n_F（p.135）：從 n = 1 開始往上填，直到 N 顆電子全部放完，最上面被填到的能階記為 n_F。
  2. 計數：每個 n 容納 2 顆電子（自旋簡併），填滿 n = 1, 2, …, n_F 共用掉 2n_F 顆。N 為偶數時恰好 2n_F = N，即 n_F = N/2。以六電子為例，n_F = 3，與填表一致。
  3. 費米能的定義（p.135）：ε_F 是 N 電子系統基態中，最上面那個被填滿能階的能量。所以把 n = n_F 代入式 (3)：ε_F = (ℏ²/2m)(n_Fπ/L)²。
  4. 代入 n_F = N/2：ε_F = (ℏ²/2m)(Nπ/2L)²，這就是式 (4) 的第二個等號。
  5. 費米波向量：由 ε = ℏ²k²/2m 可以定義 k_F ≡ n_Fπ/L = πN/2L = (π/2)(N/L)。
  6. 強度量：式 (4) 中 N 與 L 只以比值 N/L（線密度 n₁）出現，ε_F = (ℏ²/2m)(πn₁/2)²。樣品長度加倍、電子數也加倍時，ε_F 不變。所以 ε_F 是材料的性質，而不是樣品大小的性質；三維的 ε_F = (ℏ²/2m)(3π²N/V)^{2/3}（p.140 式 (17)）同樣只依賴 N/V。
  7. N 為奇數時：n_F = (N + 1)/2，ε_F = (ℏ²/2m)[(N + 1)π/2L]²，與式 (4) 的相對差約為 2/N，對巨觀系統可以忽略。
  8. 一個容易被忽略的比較：k_F = (π/2)n₁，所以費米波長 λ_F = 2π/k_F = 4/n₁，等於平均電子間距的 4 倍。一個費米波長內有 4 顆電子，也就是每半個波長 2 顆（自旋上下各一），這正是「每個 n 對應一對 orbital」的另一種說法。

補：一維態密度與基態平均能量——為三維的式 (19)–(21) 暖身補推導

Kittel 在一維小節沒有寫出態密度，到三維小節（p.140–141）才引入 D(ε)。但一維版本只要兩行就能算完，而且它 ε^(−1/2) 的特殊形狀，正是 Fig. 8（p.144）中一維化學勢隨溫度「往上走」的原因。先在這裡備好。

  1. 能量 ≤ ε 的 orbital 數：ε_n ≤ ε 等價於 n ≤ (L/π)√(2mε)/ℏ。N 很大時，把整數的個數近似為連續量，再乘上自旋因子 2：N(ε) = (2L/πℏ)√(2mε)。
  2. 檢查：令 N(ε_F) = N，解出 ε_F = (ℏ²/2m)(πN/2L)²，正是式 (4)。
  3. 態密度：D(ε) ≡ dN/dε = (L/πℏ)√(2m) · ε^(−1/2) = (L/πℏ)√(2m/ε)。
  4. 在費米能處的值：由 N ∝ ε_F^(1/2) 得 D(ε_F) = N/(2ε_F)。對照三維 p.141 式 (21) 的 D(ε_F) = 3N/2ε_F；一般 d 維為 D(ε_F) = dN/(2ε_F)，因為 N ∝ ε_F^(d/2)。
  5. 形狀：一維 D(ε) ∝ ε^(−1/2)，在 ε → 0 時發散，並隨能量遞減；三維 D(ε) ∝ ε^(1/2)（p.140 式 (20)），隨能量遞增；二維為常數（p.157 習題 3 的註）。這個單調性的差異決定了升溫時 μ 的走向（見本段後面的 μ(T) 展開）。
  6. 基態總能（精確的離散和）：E₀ = 2ε₁ Σ_{n=1}^{n_F} n² = 2ε₁ · n_F(n_F + 1)(2n_F + 1)/6。N = 6（n_F = 3）時，E₀ = 2ε₁ · 3·4·7/6 = 28ε₁，與逐項相加的結果一致。
  7. 基態總能（大 N 的連續近似）：E₀ = ∫₀^{ε_F} εD(ε)dε = (L/πℏ)√(2m) · (2/3)ε_F^(3/2) = Nε_F/3，所以每顆電子的平均能量為 ε_F/3。對照三維 p.157 習題 1 的 U₀ = (3/5)Nε_F；一般 d 維為 [d/(d + 2)]Nε_F。
  8. 小 N 時的偏差：N = 6 時，連續近似給出 Nε_F/3 = 6 × 9ε₁/3 = 18ε₁，比精確值 28ε₁ 小很多。所以把求和換成積分，只有在 N 很大時才合法。

溫度升高會發生什麼：費米-狄拉克分布登場（p.136）

基態是 N 電子系統在絕對零度時的狀態。溫度升高時會怎樣？Kittel 說，這是初等統計力學的標準問題，答案由費米-狄拉克分布函數給出（推導見 Appendix D 與 TP 第 7 章；TP 指 Kittel 與 Kroemer 合著的《Thermal Physics》，這個縮寫在本書前言中有說明）。

溫度升高時，電子氣的動能增加：有些在絕對零度時空著的能階被占據了，有些在絕對零度時被占據的能階則空了出來（Fig. 3）。費米-狄拉克分布給出的是：在熱平衡的理想電子氣中，能量為 ε 的一個 orbital 被占據的機率，也就是式 (5)。

有兩個用詞值得注意。「理想電子氣」表示電子之間沒有交互作用，與前面 orbital 模型的前提一致。「一個 orbital 被占據的機率」表示 f(ε) 是每個 orbital 的平均占據數，數值介於 0 與 1 之間，而不是「能量 ε 處有幾顆電子」。要得到後者，必須再乘上該能量附近有多少個 orbital，也就是態密度（p.140 式 (20) 引入）；p.140 Fig. 5 中的虛線 f(ε,T)D(ε) 畫的就是這個乘積。

費米-狄拉克分布函數

f(ε) = 1 / {exp[(ε − μ)/k_BT] + 1}

(5) 　p.136

f(ε)：能量為 ε 的一個 orbital 被占據的機率（平均占據數，0 ≤ f ≤ 1）；ε：orbital 能量；μ：化學勢，是 T 的函數，由「總粒子數 = N」決定；k_B：Boltzmann 常數；T：絕對溫度。

出處推導
來自統計力學的 Gibbs 因子：把單一 orbital 當成可與電子庫交換能量與粒子的小系統，Pauli 原理只允許它處於「空」或「有一顆電子」兩種狀態，兩者的機率比為 exp[(μ − ε)/k_BT]，歸一化即得（Appendix D p.654–655；逐步推導見下一區塊）。適用條件：熱平衡、無交互作用的費米子（理想電子氣）。
極限行為
T → 0：ε < μ 時指數 → 0，f → 1；ε > μ 時指數 → ∞，f → 0。f 變成在 ε = μ = ε_F 處由 1 跳到 0 的階梯函數，重現基態「由下往上填到 ε_F」的圖像（p.136）。ε = μ：分母 = 1 + 1 = 2，f = ½，對任何溫度都成立（p.136）。ε − μ ≫ k_BT：分母由指數主導，f ≈ exp[(μ − ε)/k_BT]，即 Boltzmann（Maxwell）分布（p.137）。此時 orbital 幾乎都空著，兩顆電子「搶同一個 orbital」的機率可以忽略，Pauli 原理的效應因此消失。μ − ε ≫ k_BT（費米海深處）：1 − f ≈ exp[(ε − μ)/k_BT]，空位（電洞）出現的機率也服從 Boltzmann 尾巴，這是第 8 章半導體價帶電洞統計的出發點。對稱性：f(μ + δ) = 1 − f(μ − δ)。
典型數值
室溫 300 K 時 k_BT ≈ 25.9 meV。f 從 0.9 降到 0.1 所跨越的能量寬度為 2 ln 9 · k_BT ≈ 4.4k_BT ≈ 0.11 eV；相較之下，鈉的 ε_F = 3.23 eV（p.139 Table 1），這個寬度只佔約 3.5%。所以室溫下金屬的費米分布仍然非常接近 T = 0 的階梯，只有費米能附近的一條窄帶被「抹圓」。

補：由 Appendix D 的 Gibbs 因子推出式 (5)補推導

正文只說答案在 Appendix D。Appendix D（p.652–655）確實給出了推導的骨架（其式 (8)–(10)），但最後「歸一化後即可寫成」那一步沒有展開。以下沿用 Appendix D 的記號完整寫出；τ ≡ k_BT 是 Kittel 所謂的「基本溫度」。

  1. 取一個 orbital 當作「系統」，其餘所有電子與晶格當作「庫」（reservoir），庫的溫度為 τ、化學勢為 μ。Pauli 原理使這個系統只有兩個狀態：空著（粒子數 0、能量 0），或被一顆電子占據（粒子數 1、能量 ε）。
  2. 基本假設：每個可及的量子態出現的機率相等。系統處於某個狀態的機率，正比於此時庫的可及態數 g_R，而 g_R = exp(σ_R)，σ_R 是庫的熵（無因次，Appendix D 定義 σ = log g）。
  3. 系統被占據時，庫失去能量 ε 與一顆粒子，所以 P(1, ε)/P(0, 0) = exp[σ_R(U₀ − ε; N₀ − 1) − σ_R(U₀; N₀)]。
  4. 庫很大，因此只需 Taylor 展開到一階（Appendix D 式 (8)）：σ_R(U₀ − ε; N₀ − 1) ≈ σ_R(U₀; N₀) − ε(∂σ/∂U) − 1·(∂σ/∂N) = σ_R(U₀; N₀) − ε/τ + μ/τ。這裡用了定義 1/τ ≡ (∂σ/∂U)_{N,V} 與 −μ/τ ≡ (∂σ/∂N)_{U,V}（Appendix D 式 (1)、(7)）。
  5. 代回得 P(1, ε)/P(0, 0) = exp[(μ − ε)/τ]，這就是 Gibbs 因子（Appendix D 式 (9)）。
  6. 歸一化（書上省略的一步）：P(0, 0) + P(1, ε) = 1。令 r ≡ exp[(μ − ε)/τ]，則 P(1) = r/(1 + r)。分子分母同除以 r：P(1) = 1/(1/r + 1) = 1/{exp[(ε − μ)/τ] + 1}（Appendix D 式 (10)）。
  7. 平均占據數 ⟨n⟩ = 0·P(0) + 1·P(1) = P(1)。令 τ = k_BT，⟨n⟩ 就是正文式 (5) 的 f(ε)。
  8. 與 Planck 分布對照：如果同一個模式可以容納 0、1、2、… 任意多個粒子（玻色子，例如第 5 章的聲子），則 ⟨n⟩ = Σ_s s r^s / Σ_s r^s = r/(1 − r) = 1/{exp[(ε − μ)/τ] − 1}；聲子數不守恆，μ = 0，就得到第 5 章的 Planck 分布。分母中的 +1 與 −1，全部來自「占據數只能是 0 或 1」這一個截斷。Pauli 原理在分布函數中留下的痕跡，就是這個正負號。

μ 的角色：由粒子數決定，T → 0 時等於 ε_F，ε = μ 處 f 恆為 ½（p.136–137）

式 (5) 中的 μ 不是一個可以任意調整的參數。Kittel 說明：μ 是溫度的函數；對於具體的問題，μ 必須選得讓系統的總粒子數算出來是正確的，也就是等於 N。

在絕對零度時，μ = ε_F。理由是：在 T → 0 的極限下，f(ε) 在 ε = ε_F = μ 處不連續地由 1（填滿）跳到 0（空）。

在任何溫度下，當 ε = μ 時，f(ε) 都等於 ½（原文以斜體強調），因為這時式 (5) 的分母為 2。

p.137 接著說明：μ 就是化學勢（chemical potential，參見 TP 第 5 章）。所以在絕對零度，化學勢等於費米能，而費米能的定義是絕對零度時最上面被填 orbital 的能量。

校註：p.136 文字層中 f = ½ 的「½」被抽成浮出的「1 2」，移到了式 (5) 之前；由算繪影像確認該處為分數 ½。

補：f(ε) 的形狀——對稱性、斜率與寬約 k_BT 的過渡區補推導

Kittel 在 p.136 只指出 f(μ) = ½。把式 (5) 多算幾行，就能得到後面熱容計算（p.142–144）需要的所有形狀資訊。

  1. 無因次化：令 x ≡ (ε − μ)/k_BT，則 f = 1/(eˣ + 1)。所有溫度下的 f 都是同一條曲線，只是橫軸以 k_BT 為單位縮放、以 μ 為原點平移。
  2. 對稱性：f(−x) = 1/(e^{−x} + 1) = eˣ/(1 + eˣ) = 1 − f(x)。意思是：比 μ 高 δ 的 orbital 被占據的機率，等於比 μ 低 δ 的 orbital 空著的機率。升溫時，「上方多出的電子」與「下方多出的空位」在機率上一一對稱；但在數量上是否對稱，還要看兩側的態密度，這正是 μ 會隨 T 移動的原因。
  3. 斜率：df/dε = (1/k_BT)·df/dx = −(1/k_BT)·eˣ/(eˣ + 1)²。在 x = 0 處，df/dε = −1/(4k_BT)。若用 ε = μ 處的切線近似，f 由 1 降到 0 所需的能量寬度恰好是 4k_BT。
  4. 10%–90% 寬度：f = 0.9 等價於 eˣ = 1/9，即 x = −ln 9 ≈ −2.20；f = 0.1 則 x = +ln 9。所以 f 從 0.9 降到 0.1 跨越 2 ln 9 · k_BT ≈ 4.39 k_BT。
  5. −∂f/∂ε 是一個以 μ 為中心、寬度約為 k_BT 的鐘形函數，而且面積為 1：∫_{−∞}^{∞}(−∂f/∂ε)dε = f(−∞) − f(∞) = 1 − 0 = 1（μ ≫ k_BT 時，積分下限可以從 0 延伸到 −∞）。T → 0 時它趨近 δ(ε − μ)。
  6. 二階矩：∫(ε − μ)²(−∂f/∂ε)dε = (k_BT)² ∫ x² eˣ/(eˣ + 1)² dx = (π²/3)(k_BT)²。這個積分就是 Kittel p.144 的式 (33)，它會出現在下面 μ(T) 的展開中，也出現在 p.144 的電子熱容 C_el = (1/3)π²D(ε_F)k_B²T 裡；熱容中的 π²/3 就是從這裡來的。

補：整個電子氣什麼時候「變古典」？——簡併判據與 Fig. 3 的最高溫曲線補推導

本區塊把 p.137 的 Boltzmann 極限推廣到整個氣體，並用它檢驗 Fig. 3 中溫度最高的曲線。三維的態計數沿用下一節（p.137–140）的結果：ε = ℏ²k²/2m、每個 k 佔 k 空間體積 (2π/L)³、自旋因子 2。

  1. 若所有 orbital 都處在尾巴裡，f(ε) ≈ e^{μ/k_BT}e^{−ε/k_BT}。總粒子數 N = Σ_{k, 自旋} f = 2 · [V/(2π)³] ∫ d³k e^{μ/k_BT} e^{−ℏ²k²/2mk_BT}。
  2. Gauss 積分 ∫ d³k e^{−ak²} = (π/a)^{3/2}，其中 a = ℏ²/2mk_BT。得 n ≡ N/V = 2e^{μ/k_BT}(mk_BT/2πℏ²)^{3/2} = 2e^{μ/k_BT}/λ_T³，λ_T ≡ (2πℏ²/mk_BT)^{1/2} 是熱 de Broglie 波長。
  3. 解出古典化學勢：μ_cl = k_BT ln(nλ_T³/2)。自洽的條件是 e^{μ/k_BT} ≪ 1，也就是 nλ_T³ ≪ 1：電子間距遠大於熱波長時，才是古典氣體。
  4. 改用 T_F 表示：三維時 n = k_F³/3π²（p.138 式 (16)），ε_F = ℏ²k_F²/2m = k_BT_F。代入可得 nλ_T³/2 = [4/(3√π)](T_F/T)^{3/2} ≈ 0.752(T_F/T)^{3/2}。所以古典條件等價於 T ≫ T_F。
  5. 檢驗 Fig. 3 的最高溫曲線：T = 10×10⁴ K = 2T_F 時，nλ_T³/2 ≈ 0.752/2^{1.5} ≈ 0.266，μ_cl = k_BT ln 0.266 ≈ −1.32k_BT ≈ −2.65ε_F。用完整的費米-狄拉克積分數值求解，得到 μ ≈ −2.46ε_F（見下文的數值表）。兩者已相當接近：T = 2T_F 時電子氣大半已經古典化，但還沒有完全進入 Boltzmann 極限（f(0) 的精確值為 0.226，Boltzmann 近似給出 0.266）。
  6. 金屬的位置：室溫下 T/T_F ≈ 300/(5×10⁴) = 0.006，nλ_T³ = 2 × 0.752 × (T_F/T)^{3/2} ≈ 3×10³，深深處在簡併區。這就是章首所說古典 Maxwell 分布失敗的定量理由。對照：電子濃度 10¹⁶ cm⁻³ 的氣體（以自由電子質量估算），T_F 只有約 2 K，室溫下完全是古典的，這正是第 8 章可以用 Boltzmann 統計處理半導體載子的原因。

補：μ(T) 的低溫展開——為什麼三維往下走、一維往上走補推導

Kittel 在 p.144 的 Fig. 8 畫出一維與三維自由電子氣的 μ(T)：一維往上彎，三維往下彎；圖說說這些曲線由粒子數積分的級數展開算出，但展開式本身沒有寫出來。以下補出這個標準的 Sommerfeld 型展開。

  1. 粒子數條件：N = ∫₀^∞ D(ε)f(ε)dε。令 G(ε) ≡ ∫₀^ε D(ε′)dε′（能量 ≤ ε 的 orbital 數），分部積分得 N = ∫₀^∞ G(ε)(−∂f/∂ε)dε（邊界項為零，因為 G(0) = 0 且 f(∞) = 0）。
  2. 把 G 在 μ 附近展開：G(ε) = G(μ) + D(μ)(ε − μ) + ½D′(μ)(ε − μ)² + …，其中用了 G′ = D。
  3. 利用上面 f 形狀區塊的結果：−∂f/∂ε 的面積為 1；它對 μ 是偶函數，所以一次矩為 0；二次矩為 (π²/3)(k_BT)²（Kittel 式 (33)）。得 N ≈ G(μ) + (π²/6)(k_BT)² D′(μ)。
  4. N 固定，所以 N = G(ε_F)。兩式相減，並取一階近似 G(μ) − G(ε_F) ≈ (μ − ε_F)D(ε_F)：(μ − ε_F)D(ε_F) ≈ −(π²/6)(k_BT)² D′(ε_F)。
  5. 結果：μ ≈ ε_F − (π²/6)(k_BT)² D′(ε_F)/D(ε_F)。μ 往哪裡移，完全由費米能處態密度的斜率決定。
  6. 代入 d 維自由電子 D ∝ ε^{d/2 − 1}，得 D′/D = (d/2 − 1)/ε_F，所以 μ ≈ ε_F[1 − (π²/6)(d/2 − 1)(k_BT/ε_F)²]。
  7. 三維（d = 3）：μ ≈ ε_F[1 − (π²/12)(k_BT/ε_F)²]，往下走。一維（d = 1）：μ ≈ ε_F[1 + (π²/12)(k_BT/ε_F)²]，往上走。二維（d = 2）：二次項為零，事實上所有冪次項都為零，μ 與 ε_F 只差一個指數小量；p.157 習題 3 的精確結果 μ = k_BT ln[exp(πnℏ²/mk_BT) − 1]，在 ε_F = πnℏ²/m 之下就是 μ = ε_F + k_BT ln[1 − exp(−ε_F/k_BT)]。
  8. 數值檢驗（k_BT/ε_F = 0.2）：展開式給出三維 0.967、一維 1.033；本站數值精確解為三維 0.965、一維 1.038；p.144 Fig. 8 在 τ/ε_F = 0.2 處目視約為 0.965 與 1.04。k_BT/ε_F = 0.01（室溫金屬）時修正量只有 8×10⁻⁵，μ 與 ε_F 在實務上完全相同。
  9. 物理圖像：若 μ 固定在 ε_F 不動，升溫時 ε_F 上方多出的電子數 ∝ D(上方)，下方多出的空位數 ∝ D(下方)，兩者的機率權重相同（f 的對稱性）。三維的 D 隨能量遞增，上方的態比下方多，N 會變大，所以 μ 必須往下移來補償；一維的 D 隨能量遞減，情形正好相反，μ 往上移；二維的 D 為常數，兩邊恰好平衡。

常見誤解與本段檢查清單我的判讀

誤解一：「μ 就是 ε_F」。ε_F 是 T = 0 基態的性質，是一個固定的數；μ 是 T 的函數，由粒子數條件決定。兩者只在 T → 0 時相等。室溫的金屬中兩者相差約 10⁻⁴ 的比例，可以混用；但溫度高到與 T_F 相當時，兩者可以差到正負號都不同（Fig. 3 中 5×10⁴ K 與 10×10⁴ K 的 μ 已經是負值）。

誤解二：「f(ε) 是能量 ε 處的電子數」。f 是每個 orbital 的占據機率。能量在 ε 到 ε + dε 之間的電子數是 D(ε)f(ε)dε，缺了態密度就不是電子數。

誤解三：「f = ½ 的地方就是 ε_F」。在任何溫度下，f = ½ 的地方都是 μ，不是 ε_F。書中的原話也是說 ε = μ 時 f = ½。

誤解四：「T_F 是電子的溫度」。T_F ≡ ε_F/k_B 只是能量單位的換算，p.140 明白說它與電子氣的溫度無關。金屬的 T_F 約為 10⁴–10⁵ K，意思是「在任何能讓金屬保持固態的溫度下，電子氣都是高度簡併的」。

誤解五：「一維盒的量子化是因為電子被困住，巨觀樣品沒有量子化」。量子化永遠存在，只是間距 ∝ 1/L² 在巨觀樣品中極小（1 cm 長的鏈，費米能附近的間距約 10⁻⁷ eV）。巨觀樣品真正的意義是「能譜準連續、可以改用態密度」，而不是「沒有量子化」。

誤解六：「Fig. 3 是一維的結果」。它放在一維小節之後，但圖說明言適用於三維。一維的 μ(T) 往上走（p.144 Fig. 8），曲線的細節會不同。

誤解七：「古典 Maxwell 分布是錯的理論」。它是費米-狄拉克分布在低占據率下的正確極限（p.137）。錯的是把它套用到金屬中占據率接近 1 的傳導電子上。
