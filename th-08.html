08

晶格、電子、磁性及其他熱容貢獻

溫區定位：低溫區　T ≪ θ　·　θ 的十分之一以下

①物理意義與直觀解釋　（我寫的教學說明）

熱容是**可加的**：任何能吸收能量的自由度都會貢獻一份。實測的 C(T) 是所有貢獻的總和，而拆解它們的關鍵工具，是**每種激發有各自的溫度冪次**。

**冪次不同這件事本身就是量測工具**。畫 C/T 對 T² 若得直線，說明只有電子＋聲子兩種貢獻；若偏離直線，就有第三種東西在裡面。這是低溫實驗判斷「樣品裡還有什麼」的標準手法。

**最容易誤判的一組**：傳導電子與非晶 TLS **都是線性於 T**。Kittel 特別提醒這兩者「毫無關係」，只是碰巧同冪次。要區分它們得靠別的手段（例如樣品是否為金屬、線性項係數與 D(ε_F) 是否相符）。

注意各貢獻的**適用範圍不同**：磁振子項只有磁有序材料才有；TLS 項只有非晶／無序固體才有；電子項只有金屬（或簡併半導體）才有。純介電晶體在低溫就只剩乾淨的 T³。

來源低溫行為物理原因
聲子（晶格）C ∝ T³三維 K 空間中被激發的模式數 ∝ T³
傳導電子C ∝ T只有費米面附近 ~k_BT 的電子能響應
磁振子（鐵磁）C ∝ T³ᐟ²磁振子色散 ω ∝ K²（非線性），改變了數格子的結果
非晶固體的二能階系統C ∝ T能量均勻分佈的局域雙井態

②重要公式與符號定義　（書中）

金屬低溫總熱容的實驗作圖式（電子項＋聲子項）

C = γT + AT³ ，作圖用 C/T = γ + AT²

(37) 　Ch6 p.145

適用於遠低於德拜溫度 θ 與費米溫度 T_F；γ 為 Sommerfeld 參數（電子項係數），A 為聲子項係數，兩者皆為材料特徵常數。以 C/T 對 T² 作圖應得斜率 A、截距 γ 的直線。

Bloch T^{3/2} 定律（磁振子熱激發造成的磁化下降）

ΔM/M(0) = (0.0587 / S Q) · (k_B T / 2JS)^{3/2}

(30) 　Ch12 p.334

Q = 1, 2, 4 分別對應 sc、bcc、fcc（每單位晶胞原子數），S 為自旋，J 為交換積分。由磁振子態密度與 Planck 分布積分得到，實驗上 ΔM/M(0) = A T^{3/2}，Ni 的 A = (7.5±0.2)×10⁻⁶ deg^{−3/2}，Fe 為 (3.4±0.2)×10⁻⁶ deg^{−3/2}（式 11, p.327）。

Debye T³ 定律（極低溫極限）

C_V ≅ (12π⁴/5) N k_B (T/θ)³ ≅ 234 N k_B (T/θ)³

(32) 　Ch5 p.114

由把積分上限取為無窮大、並用 ∫₀^∞ dx x³/(eˣ−1) = π⁴/15（式 (31)）得到；實際晶體常需低於 θ/50 才有純 T³ 行為

③推導所使用的假設　（書中）

  • 晶格（聲子）貢獻：把晶體總能寫成所有聲子模態（以波向量 K 與偏極化指標 p 標記）能量之和 U_lat = Σ_K Σ_p ⟨n_{K,p}⟩ℏω_{K,p}，模態佔據數服從 Planck 分布 ⟨n⟩ = 1/(exp(ℏω/τ)−1)，τ ≡ k_B T（書本 p.107）。
  • 熱容一律取定容值 C_V ≡ (∂U/∂T)_V；書中明說 C_V 比實驗實際量到的 C_p 更基本，並在註腳給出 C_p − C_V = 9α²BVT，且說固體中兩者的分數差通常很小、常可忽略（書本 p.107）。
  • 電子貢獻用自由電子 Fermi 氣體：加熱時並非每個電子都獲得 ~k_BT，只有落在 Fermi 能階附近 k_BT 能量範圍內的軌域電子被熱激發；定量推導時把態密度 D(ε) 取在 ε_F 處提出積分外，並忽略化學勢 μ 的溫度依賴、以常數 ε_F 取代 μ（書本 p.141, 143–144）。
  • 金屬中電子項與聲子項可直接相加：在遠低於 Debye 溫度 θ 與 Fermi 溫度 T_F 時 C = γT + AT³，γ 與 A 是材料特性常數（書本 p.145）。
  • 磁性貢獻用 magnon（量子化自旋波）：鐵磁基態全部自旋平行、只取最近鄰 Heisenberg 交換 U = −2J Σ S_p·S_{p+1}、以小振幅線性化（S^x, S^y ≪ S，取 S_p^z = S 並略去 S^x 與 S^y 乘積項），magnon 佔據數同樣用 Planck 分布，且每個 k 只有單一偏極化（書本 p.330, 332, 334）。
  • 非晶固體的「其他」貢獻：假設存在濃度 N 的二能階系統，其能階分裂 Δ 遠小於聲子 Debye 截止 k_Bθ，且 Δ 在 0 到 Δ₀ 之間以均勻機率分布（書本 p.578）。

④適用條件與限制　（書中）

  • Debye T³ 只在「僅長波聲學模被熱激發」時成立——這些正是可用巨觀彈性常數當彈性連續體處理的模態；書中明說實際晶體要達到相當純的 T³ 行為，可能必須低到 T = θ/50（書本 p.114）。
  • 書中明講的失效情形：Einstein 模型低溫下熱容以 exp(−ℏω/τ) 指數衰減，而實驗已知聲子貢獻是 T³（由 Debye 模型解釋）；不過 Einstein 模型常被用來近似聲子譜中的光學聲子部分（書本 p.117）。
  • 電子熱容的定量表式只在 k_BT ≪ ε_F 的低溫成立（書本 p.142）；書中並註明把積分下限由 −ε_F/τ 延伸到 −∞ 是安全的，前提是 ε_F/τ ~ 100 或更大（書本 p.144）。
  • 觀測到的 γ（Sommerfeld parameter）數量級雖對，但常與自由電子質量 m 算出的值不很吻合，因此改用熱有效質量 m_th，定義 m_th/m ≡ γ(observed)/γ(free)；偏離 1 涉及三個效應：能帶有效質量、電子與聲子交互作用、電子與電子交互作用（書本 p.145, 147）。重費米子化合物（UBe₁₃、CeAl₃、CeCu₂Si₂）的 γ 高出常值兩到三個數量級（書本 p.147）。
  • C = γT + AT³ 這個「電子 + 聲子」分解只被書中限定在「遠低於 θ 與 T_F」的溫度區間使用；電子線性項只在足夠低溫時才是主導項（書本 p.145）。
  • 書中明講的失效情形：玻璃與非晶固體不遵守純 Debye T³。許多絕緣玻璃在 1 K 以下出現非預期的線性項；25 mK 時熔融矽石（vitreous silica）觀測熱容超出 Debye 聲子貢獻達 1000 倍；此異常線性項雖也正比於 T，書中明說它與一般的傳導電子熱容無關，且為何非晶態必然如此，細節仍不清楚（書本 p.578, 579）。

⑤高溫與低溫行為　（書中）

高溫　T ≫ θ

非晶固體的二能階系統：在 k_BT ≫ Δ₀ 時，積分值約為 (Δ₀/2k_BT)³，得式 (25) C_V ≅ **Δ₀²/12k_BT²** —— 隨溫度上升而趨近零（書本 p.579）。注意 Δ₀ 帶平方，否則量綱不成立。高溫端真正主宰熱容的是晶格項，趨近 Dulong–Petit 的 3Nk_B（p.113、117）；電子項 γT 相對於聲子項的比值 ∝ 1/T²，因此高溫下可忽略。

低溫　T ≪ θ

非晶固體的二能階系統：在 k_BT ≪ Δ₀ 時（書中寫 for T < Δ₀/k_B），積分值約為 1/3，得式 (24) C_V ≅ 2k_B²T/3Δ₀ —— **線性於 T**（書本 p.579）。這正是許多絕緣玻璃在 1 K 以下出現預期外線性項的來源；書中明言在 25 mK 時石英玻璃的實測熱容遠高於 Debye 預測（p.578）。同一溫區內，純介電晶體的聲子項為 Debye T³（p.114）、金屬的電子項為 γT（p.144）、磁有序材料的磁振子項為 T³ᐟ²（p.334）。四者冪次不同，是低溫下拆解各貢獻的依據。
