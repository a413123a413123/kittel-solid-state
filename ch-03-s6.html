這一段在解決什麼問題我的判讀

第 3 章走到 p.80 的時候，彈性理論的骨架已經搭完了：應變六個分量 (31)(32)、應力六個分量、Hooke 定律 (37)(38) 把兩者用 36 個係數連起來，能量密度是應變的二次式 (39)，對稱性把 36 個降到 21 個 (42)，立方對稱再降到 3 個，寫成矩陣就是 (50)。

問題是：到此為止 C₁₁、C₁₂、C₄₄ 只是三個抽象的比例常數。它們既不是你在實驗室裡直接量的東西，也還看不出跟後面幾章要講的聲子有什麼關係。這一段做的正是把它們接回現實的兩件事。

第一件是靜態的：拿一個均勻的等向膨脹去打 (43)，得到體模量 B = ⅓(C₁₁ + 2C₁₂)。體模量是壓力與體積變化的關係，可以用靜水壓實驗或狀態方程直接量，Kittel 在 p.80 明說 B 與壓縮率 K 的數值列在 Table 3。

第二件是動態的：寫出彈性波的運動方程，解出三個主要方向的相速度。這一件在物理上重要得多，因為它是整本書往下走的橋——第 4 章的聲子色散關係在長波極限必須回到這裡算出的聲速，第 5 章的 Debye 模型則直接把「每個偏振的聲速取成常數」當作出發點。也就是說，這一段算出的 v = (C/ρ)^(1/2) 就是 Debye 溫度、晶格熱容、熱導率裡那個 v。

還有第三個副產品：能量密度 (43) 必須對所有應變組合為正，這個要求會把三個常數限制在一塊區域裡（習題 14）。而那塊區域的邊界，恰恰就是某個波速變成零的地方——晶格軟化、結構相變的數學前身。這條線索在這一段末尾才會收攏，但它是整段最漂亮的地方。

立方晶的剛度常數與柔度常數的互逆關係（原書式 51）

C₄₄ = 1/S₄₄ ； C₁₁ − C₁₂ = (S₁₁ − S₁₂)⁻¹ ； C₁₁ + 2C₁₂ = (S₁₁ + 2S₁₂)⁻¹

(51) 　p.80

C_ij：彈性剛度常數（elastic stiffness constants），由 (38) 定義，應力 = C × 應變，量綱為力/面積或能量/體積；S_ij：彈性柔度常數（elastic compliance constants），由 (37) 定義，應變 = S × 應力，量綱為面積/力或體積/能量。兩組常數各自都是 6×6 矩陣，互為反矩陣。

出處推導
由 (50) 的立方晶剛度矩陣求逆而得。書上 p.80 只用一句話帶過：這些關係式是對 (50) 求反矩陣算出來的。關鍵在於 (50) 是區塊對角的——上左的 3×3 區塊（xx, yy, zz 之間）與下右的 3×3 對角區塊（yz, zx, xy）完全不耦合，所以可以分開求逆。
極限行為
注意這三條不是逐項倒數。C₁₁ ≠ 1/S₁₁，C₁₂ ≠ 1/S₁₂——只有剪切那一支因為矩陣本身就是對角的，才會有 C₄₄ = 1/S₄₄ 這種乾淨的倒數。正確的說法是：矩陣求逆會把本徵值逐一取倒數，而 C₁₁ − C₁₂ 與 C₁₁ + 2C₁₂ 正好就是那個 3×3 區塊的兩個本徵值。這也解釋了為什麼後面每一個物理量（體模量、[110] 的橫波速度、穩定性判據）都只以 C₁₁ + 2C₁₂ 與 C₁₁ − C₁₂ 這兩個組合出現，而不是 C₁₁ 與 C₁₂ 各自出現。 校註（重要）：原書 p.80 式 (51) 的第一項印成「C₁₄ = 1/S₄₄」。我把該頁放大算繪後目視確認，書上確實是印 C₁₄，不是抽取工具的錯。但依 (50) 可知立方晶的 C₁₄ = 0（(47) 明文寫出 C₁₄ = C₁₅ = C₁₆ = 0），而 S₄₄ 對應的對角元素是 C₄₄，所以正確的應是 C₄₄ = 1/S₄₄。這是原書誤植。

補上 (50) 求逆的完整代數：為什麼本徵值是 C₁₁ + 2C₁₂（一重）與 C₁₁ − C₁₂（二重）補推導

書上把「求 (50) 的反矩陣」一句帶過。這一步其實是整個立方彈性理論最核心的代數，因為它一次交代了三件事：(51) 的三條關係、體模量為什麼是 ⅓(C₁₁ + 2C₁₂)、以及習題 14 的穩定性判據為什麼長成那個樣子。下面把它做完。

  1. (50) 的 6×6 矩陣是區塊對角的：左上 3×3 作用在 (e_xx, e_yy, e_zz) 上，右下 3×3 是 diag(C₄₄, C₄₄, C₄₄) 作用在 (e_yz, e_zx, e_xy) 上，兩塊之間全是 0。反矩陣因此也是區塊對角的，兩塊分開求即可。
  2. 剪切區塊最簡單：diag(C₄₄, C₄₄, C₄₄) 的反矩陣就是 diag(1/C₄₄, 1/C₄₄, 1/C₄₄)。對照 (37) 的柔度矩陣，右下區塊是 diag(S₄₄, S₅₅, S₆₆)，而立方對稱給 S₄₄ = S₅₅ = S₆₆。所以 S₄₄ = 1/C₄₄，即 C₄₄ = 1/S₄₄。這證實了上面的校註：書上印的 C₁₄ 應為 C₄₄。
  3. 法向區塊 M = [[a, b, b], [b, a, b], [b, b, a]]，其中 a ≡ C₁₁、b ≡ C₁₂。這種「對角 a、其餘全 b」的矩陣叫作圓對稱（circulant）矩陣，它的本徵向量可以直接寫出來，不必解特徵方程。
  4. 第一個本徵向量：e = (1, 1, 1)/√3。代入 M·(1,1,1)ᵀ = (a + 2b, a + 2b, a + 2b)ᵀ = (a + 2b)(1,1,1)ᵀ。所以本徵值 λ₁ = C₁₁ + 2C₁₂，一重。這個模式三個法向應變相等——就是均勻的等向膨脹（純體積變化），這正是下一小節體模量要用的變形。
  5. 第二、三個本徵向量：任何滿足 e_xx + e_yy + e_zz = 0 的向量，例如 (1, −1, 0)/√2 與 (1, 1, −2)/√6。代入 M·(1,−1,0)ᵀ = (a − b, b − a, 0)ᵀ = (a − b)(1,−1,0)ᵀ。所以本徵值 λ₂ = λ₃ = C₁₁ − C₁₂，二重。這兩個模式的膨脹 δ = e_xx + e_yy + e_zz = 0，是保體積的四方形變（tetragonal shear）。
  6. 本徵值清單完整了：C₁₁ + 2C₁₂ 一次、C₁₁ − C₁₂ 兩次。可以用跡（trace）檢查：(C₁₁ + 2C₁₂) + 2(C₁₁ − C₁₂) = 3C₁₁ = Tr M ✓。用行列式檢查：(C₁₁ + 2C₁₂)(C₁₁ − C₁₂)² = det M ✓。
  7. 反矩陣 M⁻¹ 具有相同的結構 [[p, q, q], [q, p, q], [q, q, p]]（因為它與 M 有相同的本徵向量），且本徵值是倒數：p + 2q = 1/(a + 2b)、p − q = 1/(a − b)。
  8. 解這兩條線性方程：p = ⅓[1/(a + 2b) + 2/(a − b)] = (a + b)/[(a + 2b)(a − b)]；q = ⅓[1/(a + 2b) − 1/(a − b)] = −b/[(a + 2b)(a − b)]。
  9. 對照 (37)：p = S₁₁、q = S₁₂。於是得到完整的顯式反演（書上沒印出來，但值得記住）：S₁₁ = (C₁₁ + C₁₂)/[(C₁₁ + 2C₁₂)(C₁₁ − C₁₂)]，S₁₂ = −C₁₂/[(C₁₁ + 2C₁₂)(C₁₁ − C₁₂)]。
  10. 回推 (51)：S₁₁ − S₁₂ = [(C₁₁ + C₁₂) + C₁₂]/[(C₁₁ + 2C₁₂)(C₁₁ − C₁₂)] = (C₁₁ + 2C₁₂)/[(C₁₁ + 2C₁₂)(C₁₁ − C₁₂)] = 1/(C₁₁ − C₁₂) ✓
  11. S₁₁ + 2S₁₂ = [(C₁₁ + C₁₂) − 2C₁₂]/[(C₁₁ + 2C₁₂)(C₁₁ − C₁₂)] = (C₁₁ − C₁₂)/[(C₁₁ + 2C₁₂)(C₁₁ − C₁₂)] = 1/(C₁₁ + 2C₁₂) ✓

為什麼要在意這兩個本徵值：三個常數其實是「一個體積 + 兩個剪切」我的判讀

上面那段代數不只是技巧。它告訴你一件觀念上的事：立方晶的三個獨立彈性常數，在物理上其實是三個獨立的「彈簧」，各自對應一種形變模式。

第一種是等向膨脹（本徵值 C₁₁ + 2C₁₂，一重）。整個晶體均勻脹大或縮小，形狀不變、體積變。這條彈簧的硬度就是 3B，因為 B = ⅓(C₁₁ + 2C₁₂)。

第二種是四方剪切（本徵值 C₁₁ − C₁₂，二重）。晶體沿 x 拉長、沿 y 壓扁，體積不變、形狀變。對應的有效剪切模量是 ½(C₁₁ − C₁₂)，這就是習題 11 要你證的東西，後面也會看到它正是 [110] 方向第二支橫波的有效彈性常數。之所以是二重，是因為在保體積的三維空間裡，你有兩個獨立方向可以「拉長一軸壓扁另一軸」。

第三種是立方軸剪切（本徵值 C₄₄，三重）。把立方體的一個面沿著另一個立方軸推歪，也是保體積。

第二種與第三種都是剪切、都保體積，但它們的硬度不見得相同。它們的比值定義了 Zener 各向異性比 A ≡ 2C₄₄/(C₁₁ − C₁₂)（這個名字與定義是我補的，Kittel 這幾頁沒有提）。A = 1 時晶體在彈性上完全各向同性，這時三個常數退化成兩個，也就是連續介質彈性力學裡的 Lamé 常數。A 離 1 越遠，晶體的彈性越各向異性——這是後面看 Table 11、Table 12 時最該注意的一欄「隱藏欄位」。

體模量：為什麼要選「均勻膨脹」這個特定的變形

Kittel 的處理極為簡潔：考慮均勻膨脹 e_xx = e_yy = e_zz = δ/3，把它代進立方晶的能量密度 (43)，算出能量 (52)，再跟體模量的定義式 (53) 對照，就讀出 B。

為什麼選這個變形？因為 (35) 已經定義了膨脹（dilation）δ ≡ (V′ − V)/V = e_xx + e_yy + e_zz。要讓總膨脹等於 δ 而且不引入任何形狀改變，最自然的選法就是三個法向應變平分，各取 δ/3，剪切應變全部設成零。這樣一來 (43) 裡的 C₄₄ 項自動消失——體模量與 C₄₄ 無關，這是立方對稱的直接結果，也是為什麼 (54) 只含 C₁₁ 與 C₁₂。

從上一段的本徵值語言看，這個選擇一點也不隨意：e = (δ/3)(1, 1, 1) 正好是法向區塊那個一重本徵向量的方向。沿本徵方向做形變，能量密度就是「½ × 本徵值 × 振幅²」，不會有交叉項——這才是 (52) 能一行寫完的真正原因。

書上接著說壓縮率 K 定義為 K = 1/B，並指出 B 與 K 的數值列在 Table 3。這裡要提醒一個抽取上的事實：Table 3 在書本 p.52，是一張旋轉 90° 的週期表形式的表，該頁沒有文字層（我用 PyMuPDF 算繪後目視判讀）。表頭寫的是等溫體模量與壓縮率，體模量的單位是 10¹² dyn/cm² 或 10¹¹ N/m²，壓縮率的單位是 10⁻¹² cm²/dyn 或 10⁻¹¹ m²/N，跟 Table 11、Table 12 的剛度常數同單位，可以直接對照。

補出 (52) 的 1/6 是怎麼來的補推導

書上直接給結果 U = ⅙(C₁₁ + 2C₁₂)δ²，那個 1/6 看起來有點突兀。它其實是 ½ × 3 × (1/3)² 與 3 × (1/3)² 兩項合併的結果。逐步算一次，順便確認 (43) 裡每一項的係數都用對了。

  1. 立方晶的能量密度 (43)：U = ½C₁₁(e_xx² + e_yy² + e_zz²) + ½C₄₄(e_yz² + e_zx² + e_xy²) + C₁₂(e_yy e_zz + e_zz e_xx + e_xx e_yy)。注意 C₁₁ 項與 C₄₄ 項帶 ½，C₁₂ 項不帶 ½（因為交叉項 e_yy e_zz 在原始的雙重求和 (39) 裡出現兩次，已經把 ½ 吃掉了）。這個係數細節是算對 1/6 的關鍵。
  2. 代入均勻膨脹：e_xx = e_yy = e_zz = δ/3，所有剪切應變 e_yz = e_zx = e_xy = 0。
  3. C₄₄ 項：½C₄₄ × 0 = 0。體模量裡不會有 C₄₄。
  4. C₁₁ 項：½C₁₁ × [三項，每項 (δ/3)²] = ½C₁₁ × 3 × δ²/9 = ½C₁₁ × δ²/3 = C₁₁δ²/6。
  5. C₁₂ 項：C₁₂ × [三項，每項 (δ/3)(δ/3)] = C₁₂ × 3 × δ²/9 = C₁₂δ²/3 = 2C₁₂δ²/6。
  6. 兩項相加：U = (C₁₁δ²)/6 + (2C₁₂δ²)/6 = ⅙(C₁₁ + 2C₁₂)δ² —— 正是 (52)。1/6 = (1/2)(1/3) 來自 C₁₁ 項，而 C₁₂ 項的 1/3 寫成 2/6 之後兩者才合得起來。
  7. 對照定義 (53) U = ½Bδ²：½B = ⅙(C₁₁ + 2C₁₂)，故 B = ⅓(C₁₁ + 2C₁₂) —— 正是 (54)。
  8. 一致性檢查：用上一段的本徵值語言重算。沿本徵方向 ê = (1,1,1)/√3 的形變寫成 e = A ê，則 U = ½λ₁A²，其中 λ₁ = C₁₁ + 2C₁₂。而 δ = e_xx + e_yy + e_zz = 3 × (A/√3) = √3 A，所以 A = δ/√3，A² = δ²/3。代回：U = ½(C₁₁ + 2C₁₂)(δ²/3) = ⅙(C₁₁ + 2C₁₂)δ² ✓ 兩條路線一致。

均勻膨脹下立方晶的彈性能密度

U = ⅙(C₁₁ + 2C₁₂)δ²

(52) 　p.80

U：單位體積的彈性能（能量密度）；δ：膨脹（dilation），由 (35) 定義為 δ ≡ (V′ − V)/V = e_xx + e_yy + e_zz，無因次；C₁₁、C₁₂：立方晶的兩個法向剛度常數。

出處推導
把均勻膨脹 e_xx = e_yy = e_zz = δ/3（剪切應變全為零）代入立方晶能量密度 (43)。C₄₄ 項因剪切應變為零而消失。
極限行為
這是一個二次式，意味著在小形變下彈性能與 δ 的符號無關——脹 δ 與縮 δ 花掉一樣多的能量。真實晶體不是這樣（壓縮比拉伸硬，這正是非簡諧性），所以 (52) 只在 |δ| ≪ 1 成立。非簡諧修正（δ³ 項）是第 5 章熱膨脹與熱阻的來源：如果 (52) 是嚴格的，晶體就不會熱膨脹，聲子之間也不會散射，熱導率會是無限大。
典型數值
以 Si（Table 12：C₁₁ = 1.66、C₁₂ = 0.639，單位 10¹² dyn/cm²）為例，C₁₁ + 2C₁₂ = 2.938 × 10¹² dyn/cm²。若體積壓縮 1%（δ = −0.01），U = ⅙ × 2.938×10¹² × 10⁻⁴ = 4.9 × 10⁷ erg/cm³ = 4.9 MJ/m³。換算成每個原子（Si 原子密度 5.0 × 10²² cm⁻³，此數值取自書外）約 9.8 × 10⁻¹⁶ erg ≈ 6 × 10⁻⁴ eV/atom。壓縮 1% 只花不到 1 meV/atom。（這個數字不能直接拿去跟室溫的 k_BT ≈ 25 meV 比較而推論「所以小形變近似成立」——方向其實相反：若真的把每原子彈性能拿去對比 k_BT，反而會推論熱擾動可以輕易造成大於 1% 的應變。均勻壓縮只是 3N 個簡正模當中的一個集體模式，熱平衡下它分到的是約 ½k_BT 的總能而不是每原子 k_BT。小形變近似真正的依據是原子的熱位移振幅相對於鍵長很小。）

體模量的定義

U = ½Bδ² ，等價於 B = −V dp/dV

(53) 　p.80

B：體模量（bulk modulus），量綱為壓力（能量/體積）；U：單位體積的彈性能；δ：膨脹；V：體積；p：壓力。

出處推導
這是體模量的定義式。書上寫出 U = ½Bδ² 之後，緊接著說它等價於 −V dp/dV 這個較常見的熱力學定義。
極限行為
B → ∞ 代表不可壓縮（壓縮率 K = 1/B → 0）；B → 0 代表晶體對均勻壓縮完全不抵抗，也就是體積失穩。由 (54) 可知 B → 0 等價於 C₁₁ + 2C₁₂ → 0，這正是習題 14 四條穩定性判據中的一條。另外要注意 B 有等溫與絕熱兩種：Table 3 給的是等溫值 B_T，而 Table 11、Table 12 的剛度常數是絕熱值，由它們算出的是 B_S。兩者差 B_S/B_T = C_p/C_v，在室溫的固體裡通常只差百分之幾，所以下面的數值對照才對得上。

為什麼 U = ½Bδ² 就等於 B = −V dp/dV補推導

書上只說這兩個定義「等價」，沒有寫出中間的熱力學步驟。這一步很短但很值得做一次，因為它把「能量密度的二次係數」與「壓力對體積的響應」這兩個看起來完全不同的東西接起來。

  1. 設未形變體積為 V₀，均勻形變後 V = V₀(1 + δ)，故 δ = (V − V₀)/V₀，且 dV = V₀ dδ。
  2. U 是能量密度（單位體積的能量），所以總彈性能 E = V₀ U = ½V₀Bδ²。（用 V₀ 而非 V 是因為 U 定義在未形變的參考體積上；差別是高階小量。）
  3. 壓力的定義：p = −dE/dV = −(1/V₀)(dE/dδ) = −(1/V₀)(V₀Bδ) = −Bδ。負號的意義：δ > 0（膨脹）時 p < 0，也就是要把晶體拉開需要負壓（張力），符合直覺。
  4. 現在算 −V dp/dV：dp/dV = (dp/dδ)(dδ/dV) = (−B)(1/V₀)。
  5. 在 δ → 0 的極限下 V → V₀，所以 −V dp/dV = −V₀ × (−B/V₀) = B ✓ 兩個定義確實等價。
  6. 順帶得到一條常用的形式：p = −Bδ = −B ΔV/V，或者 ΔV/V = −p/B = −Kp。這就是為什麼壓縮率 K = 1/B 在實驗上是「單位壓力造成的相對體積變化」。
  7. 數值感：Si 的 K ≈ 1.01 × 10⁻¹² cm²/dyn（Table 3，目視判讀）。1 GPa = 10¹⁰ dyn/cm²，所以 1 GPa 的靜水壓讓 Si 的體積縮約 1%。這跟 (52) 的數值欄剛好對得上。

Fig. 18 在說什麼：從「力」到「波動方程」的那一步

網頁上不放圖，所以把 Fig. 18 用文字說清楚。

畫面是一個邊長 Δx、Δy、Δz 的小立方體，切在晶體內部任意位置。看它在 x 方向受到的力。左邊那個面（位置 x）上有應力 −X_x(x)（負號是因為外法線指向 −x）；右邊那個平行面（位置 x + Δx）上有應力 X_x(x + Δx)。關鍵的一步是把右面的應力做泰勒展開：

X_x(x + Δx) ≅ X_x(x) + (∂X_x/∂x)Δx

兩個面的貢獻相減，X_x(x) 這一項精確抵消，只剩下梯度項乘上面積：淨力 = (∂X_x/∂x)Δx × ΔyΔz。這就是整個彈性波理論的核心洞見——推動物質的不是應力本身，而是應力的梯度。

除了這一對面之外，x 方向的力還有另外兩個來源：垂直於 y 的那一對面上的剪應力 X_y（x 方向的力作用在法線沿 y 的面上），與垂直於 z 的那一對面上的 X_z。圖上沒有畫這兩對，書裡用文字補充說明。三者加起來，作用在立方體上的 x 方向淨力是

F_x = (∂X_x/∂x + ∂X_y/∂y + ∂X_z/∂z) ΔxΔyΔz

最後套牛頓第二定律：力等於質量乘上 x 方向的加速度。立方體的質量是 ρΔxΔyΔz，加速度是 ∂²u/∂t²。兩邊的 ΔxΔyΔz 對消，就得到 (55)。ΔxΔyΔz 會對消這件事很重要：它代表結果與你切多大的體積元無關，也就是這是一條逐點成立的場方程，而不是某個特定小盒子的力平衡。

Fig. 19 的兩根彈簧：為什麼是梯度而不是應力

Fig. 19 是一張極簡的圖，但它承載的觀念比 Fig. 18 還基本，值得原樣講。

畫面是一個方塊，左右各接一根彈簧，左邊標 A、右邊標 B，兩根沿著 x 方向。書上的敘述分兩種情況。

情況一：A 與 B 被拉伸的量相同。這時方塊受到左右兩個大小相等、方向相反的拉力，淨力為零，方塊不動。書上用這個來說明一件事：固體裡均勻的應力 X_x 不會對體積元產生淨力。

情況二：B 比 A 拉得更多。這時方塊會被 X_x(B) − X_x(A) 這個力加速。

這張圖解釋了為什麼 (55) 右邊是應力的導數而不是應力本身。換個角度想：如果應力本身就能產生加速度，那麼一塊靜置在桌上被均勻大氣壓包圍的晶體就會自己動起來，顯然荒謬。只有應力在空間上不均勻時，兩側才會失衡，物質才會被推動。

（以下這兩個類比、以及最後偏振數目的對照，都是我補的；Kittel 這幾頁沒有寫，書上 Fig. 19 的圖說就只有上面那兩句。）這也是一個好的類比起點：電荷在均勻電位裡不受力，受力的是電位的梯度；流體不會因為壓力大而流動，會流動是因為壓力有梯度。彈性波在這個意義上就是「應力不均勻度」在晶體裡的傳播。但類比到此為止——彈性波與電磁波的本質差別在於，彈性波有三個偏振（兩橫一縱），而電磁波在真空中只有兩個橫偏振。多出來的縱波正是因為固體能抵抗壓縮。

x 方向的彈性運動方程

ρ ∂²u/∂t² = ∂X_x/∂x + ∂X_y/∂y + ∂X_z/∂z

(55) 　p.80

ρ：密度；u：位移向量 R 的 x 分量（由 (29) 定義）；X_x、X_y、X_z：三個應力分量，大寫字母代表力的方向（都是 x），下標代表施力面的法線方向。y 與 z 方向有形式完全相同的方程。

出處推導
由 Fig. 18 的體積元受力分析得到：淨 x 向力 F_x = (∂X_x/∂x + ∂X_y/∂y + ∂X_z/∂z)ΔxΔyΔz，質量 ρΔxΔyΔz，代入 F = ma 後兩邊的 ΔxΔyΔz 對消。
極限行為
這條方程本身完全沒有用到立方對稱，甚至沒有用到 Hooke 定律——它只是牛頓第二定律的連續介質版本，對任何固體（含各向異性、含非線性）都成立。晶體結構的資訊要等到把 (38)(50) 的應力—應變關係代進去才進來。 把三個分量合起來寫，右邊就是應力張量的散度：ρ ∂²R/∂t² = ∇·σ。靜態極限（∂²u/∂t² = 0）給出的是彈性平衡條件 ∇·σ = 0，那是工程力學裡的應力分析；動態的才是波。這一條方程跟第 4 章的差別值得先記住：這裡的介質是連續的，所以波速與波長無關（無色散）；第 4 章把原子的離散性放回去之後，短波長的聲子就會偏離這個線性關係，而長波長極限必須回到這裡。

(55) → (56) → (57a)：把應力換成應變、再換成位移補推導

書上從 (55) 到 (57a) 中間只印了 (56) 一個中繼站，兩步都是「代入」但都有容易漏掉的細節。這裡逐步做完，特別注意哪些 C₄₄ 項是從哪裡冒出來的。

  1. 第一步：用 (38) 與 (50) 把三個應力寫成應變。從 (50) 的矩陣逐列讀出：X_x = C₁₁e_xx + C₁₂e_yy + C₁₂e_zz（第一列）；X_y = C₆₆e_xy = C₄₄e_xy（第六列，因為 (49) 給 C₆₆ = C₄₄）；X_z = Z_x = C₅₅e_zx = C₄₄e_zx（第五列，並用了 (36) 的 X_z = Z_x）。
  2. 注意 X_z = Z_x 這一步：(36) 說 Z_x = X_z，所以 (50) 矩陣裡第五列給的 Z_x 就是我們要的 X_z。這是書上沒有特別點出、但少了就對不上的一環。
  3. 代入 (55)：ρ ∂²u/∂t² = C₁₁ ∂e_xx/∂x + C₁₂(∂e_yy/∂x + ∂e_zz/∂x) + C₄₄(∂e_xy/∂y + ∂e_zx/∂z) —— 這就是 (56)。
  4. 第二步：用 (31)(32) 把應變寫成位移的導數。(31)：e_xx = ∂u/∂x，e_yy = ∂v/∂y，e_zz = ∂w/∂z。(32)：e_xy = ∂u/∂y + ∂v/∂x，e_zx = ∂u/∂z + ∂w/∂x。
  5. 逐項代入。C₁₁ 項：C₁₁ ∂/∂x(∂u/∂x) = C₁₁ ∂²u/∂x²。
  6. C₁₂ 項：C₁₂[∂/∂x(∂v/∂y) + ∂/∂x(∂w/∂z)] = C₁₂(∂²v/∂x∂y + ∂²w/∂x∂z)。
  7. C₄₄ 的第一項：C₄₄ ∂/∂y(∂u/∂y + ∂v/∂x) = C₄₄(∂²u/∂y² + ∂²v/∂x∂y)。這裡一次生出兩項：一個純 u 的項、一個 u–v 耦合項。
  8. C₄₄ 的第二項：C₄₄ ∂/∂z(∂u/∂z + ∂w/∂x) = C₄₄(∂²u/∂z² + ∂²w/∂x∂z)。同樣生出兩項。
  9. 合併同類項：純 u 的二階項有 C₁₁∂²u/∂x² + C₄₄(∂²u/∂y² + ∂²u/∂z²)；交叉項 ∂²v/∂x∂y 的係數是 C₁₂ + C₄₄，∂²w/∂x∂z 的係數也是 C₁₂ + C₄₄。

(57b)(57c)：為什麼可以「由對稱性直接寫出」

書上 p.81 開頭說 v 與 w 的運動方程可以由 (57a) 用對稱性直接得到，然後就把 (57b)(57c) 印出來。這句話值得拆開講，因為它用的是一個非常具體的對稱操作，不是含糊的「由對稱性」。

用的是 (45) 裡那個三重旋轉：x → y → z → x。這是立方晶必然具備的對稱操作（書上 p.78 說立方結構的最低對稱要求就是四條三重旋轉軸，沿 [111] 及等價方向）。在這個代換下，位移分量跟著輪換 u → v → w → u，而 C₁₁、C₁₂、C₄₄ 因為是立方不變量所以不變。

把 (57a) 整條做一次輪換：

ρ ∂²v/∂t² = C₁₁ ∂²v/∂y² + C₄₄(∂²v/∂z² + ∂²v/∂x²) + (C₁₂ + C₄₄)(∂²w/∂y∂z + ∂²u/∂y∂x)

把它跟書上的 (57b) 比對：ρ ∂²v/∂t² = C₁₁ ∂²v/∂y² + C₄₄(∂²v/∂x² + ∂²v/∂z²) + (C₁₂ + C₄₄)(∂²u/∂x∂y + ∂²w/∂y∂z) —— 完全一致（項的順序不同而已，且混合偏導可交換）。再輪換一次就得到 (57c)。

這裡有一個實用的檢查法：(57b) 的第一項一定是 C₁₁ ∂²v/∂y²（位移分量與微分方向同名配 C₁₁），C₄₄ 配的是另外兩個方向的二階導數，而耦合項一定是「(C₁₂ + C₄₄) × 另外兩個位移分量對『自己方向 × 對方方向』的混合導數」。用這個規則寫錯的機會很小。

−ω²ρ u = C₁₁ (−K²) u ⟹ ω²ρ = C₁₁K²（式 59）

於是相速度 v_s = νλ = ω/K = (C₁₁/ρ)^(1/2)（式 60）。書上在 (58) 之後補了 K = 2π/λ 與 ω = 2πν 兩個定義，所以 νλ = (ω/2π)(2π/K) = ω/K 這個等式是自明的。

橫波：取波向量仍沿 x 立方稜，但粒子位移 v 在 y 方向：v = v₀ exp[i(Kx − ωt)]（式 61），u = w = 0。這次要代進 (57b)。C₁₁ ∂²v/∂y² = 0（v 不依賴 y）；耦合項因 u = w = 0 而消失；C₄₄(∂²v/∂x² + ∂²v/∂z²) 只剩 ∂²v/∂x² 那一半。得到 ω²ρ = C₄₄K²（式 62），故 v_s = (C₄₄/ρ)^(1/2)（式 63）。

第三支：位移改成沿 z（即 w 非零，用 (57c)），同樣的消項過程給出完全相同的速度 (C₄₄/ρ)^(1/2)。書上明確指出：K 平行於 [100] 時兩支獨立的剪切波速度相等，但在晶體中一般方向上這件事不成立。

這一句「一般方向不成立」是整段最該記住的話。兩支橫波在 [100] 簡併，不是因為橫波天生簡併，而是因為 [100] 軸上有四重旋轉對稱把 y 與 z 換過去——對稱性強迫它們相等。[110] 軸只有二重對稱，於是簡併立刻解除。

(59)(60) 　p.82

ω：角頻率（= 2πν）；K：波數（= 2π/λ）；ρ：密度；v_s：相速度；C₁₁：立方晶剛度常數。

[110] 方向為什麼是重頭戲

書上開宗明義說明了理由：在立方晶的面對角線方向傳播的波之所以特別值得注意，是因為三個彈性常數可以單單從這個方向的三個傳播速度簡單地定出來。

把這句話的實驗意義說白一點。你手上有一塊立方晶，想量它的 C₁₁、C₁₂、C₄₄。

- 只做靜水壓：只能得到 ⅓(C₁₁ + 2C₁₂)，一個方程三個未知數。

- 只沿 [100] 打超音波：得到 C₁₁（縱波）與 C₄₄（橫波），兩個方程，C₁₂ 仍然拿不到，因為 [100] 的三支波裡根本沒有 C₁₂ 出現。

- 沿 [110] 打超音波：三支波分別給 ½(C₁₁ + C₁₂ + 2C₄₄)、C₄₄、½(C₁₁ − C₁₂)。三個獨立的方程、三個未知數，一次解完。

所以 [110] 是最方便、也最標準的那個「切一塊樣品、貼一組換能器就能量完全部彈性常數」的方向——這裡的「最方便」有明確的意思：三支波的偏振恰好是純縱與純橫，反解的代數可以手算。（書上只說 [110] 有 special interest、三個彈性常數可以由這個方向的三個速度 simply 求出，並沒有說它是唯一可行的方向；原則上一般低對稱方向同樣有三支波、三個獨立速度，也能反解，只是偏振不再純粹、代數不漂亮。）這也是為什麼超音波量測彈性常數的標準樣品多半取 (110) 切面（此工程慣例為我補的，Kittel 這幾頁沒有寫）。

數學上為什麼 [110] 這麼好用？因為它的波向量有兩個相等的非零分量 K_x = K_y = K/√2，於是 (57a)(57b) 的耦合項活了起來（K_xK_y ≠ 0），把 C₁₂ 從隱藏狀態拉出來；同時 z 分量為零，讓 w 那一支完全解耦，問題降成一個 2×2 行列式而不是 3×3。這是「夠複雜到能看見 C₁₂、又夠簡單到能手算」的甜蜜點。

[110] 面內傳播、位移沿 z 的剪切波

(64)(65) 　p.82

補出 (57a)(57b) → (67) 的代入過程補推導

書上 p.82 在寫下 (66) 的試解之後，直接說「From (57a) and (57b)」然後印出 (67)。中間的代入其實有幾個容易出錯的地方（哪個 K 配哪個 C、耦合項的係數），值得逐步做一次。

  1. 試解 (66)：u = u₀ exp[i(K_x x + K_y y − ωt)]，v = v₀ exp[i(K_x x + K_y y − ωt)]，w = 0。兩個分量共用同一組 (K_x, K_y, ω)——這是「同一個簡正模」的意思。
  2. 微分規則：∂/∂x → iK_x，∂/∂y → iK_y，∂/∂z → 0，∂/∂t → −iω。因此 ∂²/∂x² → −K_x²，∂²/∂y² → −K_y²，∂²/∂x∂y → −K_xK_y，∂²/∂t² → −ω²。
  3. 代入 (57a)：−ω²ρ u = C₁₁(−K_x²)u + C₄₄[(−K_y²)u + 0] + (C₁₂ + C₄₄)[(−K_xK_y)v + 0]。最後一項中 ∂²w/∂x∂z = 0 因為 w = 0。
  4. 兩邊同乘 −1：ω²ρu = (C₁₁K_x² + C₄₄K_y²)u + (C₁₂ + C₄₄)K_xK_y v —— (67) 的上式。注意 u 自己的係數裡，與 u 同名方向的 K_x 配 C₁₁，垂直方向的 K_y 配 C₄₄。
  5. 代入 (57b)：−ω²ρ v = C₁₁(−K_y²)v + C₄₄[(−K_x²)v + 0] + (C₁₂ + C₄₄)[(−K_xK_y)u + 0]。這裡 ∂²v/∂z² = 0、∂²w/∂y∂z = 0。
  6. ω²ρv = (C₁₁K_y² + C₄₄K_x²)v + (C₁₂ + C₄₄)K_xK_y u —— (67) 的下式。與上式相比，C₁₁ 與 C₄₄ 配的 K 對調了，這正是 x ↔ y 對稱性的體現。
  7. 檢查耦合項的對稱性：兩條方程裡的耦合係數都是 (C₁₂ + C₄₄)K_xK_y，完全相同。這保證了 (68) 的 2×2 矩陣是實對稱的，因此本徵值必為實數、本徵向量必正交——物理上就是「三個簡正模的偏振互相垂直」。如果算出來不對稱，一定是代錯了。
  8. 退化檢查：令 K_y = 0（回到 [100]），上式變成 ω²ρ = C₁₁K_x²（縱波，(59) ✓），下式變成 ω²ρ = C₄₄K_x²（橫波，(62) ✓），耦合項因 K_xK_y = 0 而消失。與前一小節一致。

xy 平面內傳播、xy 平面內運動的一對耦合方程

ω²ρu = (C₁₁K_x² + C₄₄K_y²)u + (C₁₂ + C₄₄)K_xK_y v ； ω²ρv = (C₁₁K_y² + C₄₄K_x²)v + (C₁₂ + C₄₄)K_xK_y u

(67) 　p.82

u、v：位移的 x、y 分量的振幅；K_x、K_y：波向量在 xy 平面內的分量；C₁₁、C₁₂、C₄₄：立方晶剛度常數。

出處推導
把 (66) 的試解 u = u₀exp[i(K_x x + K_y y − ωt)]、v = v₀exp[i(K_x x + K_y y − ωt)]（w = 0）代入 (57a) 與 (57b)。
極限行為
耦合項的係數是 (C₁₂ + C₄₄)K_xK_y，它同時需要 K_x ≠ 0 與 K_y ≠ 0 才不為零。這一句話就解釋了所有事：K 沿 [100] 時 K_y = 0，u 與 v 解耦，兩支波各自純縱純橫；K 一旦離開立方軸，u 與 v 就混在一起，簡正模的偏振要靠解本徵值問題決定，一般不會剛好平行或垂直於 K。 寫成矩陣形式 ω²ρ (u, v)ᵀ = D (u, v)ᵀ，D 是實對稱 2×2 矩陣——這就是動力學矩陣（dynamical matrix）在連續介質極限下的樣子。第 4 章處理有基底的晶格振動時會遇到同樣結構的本徵值問題，只是那裡的矩陣元素是原子間力常數的傅立葉和，而不是彈性常數乘 K²。認出這個結構，第 4 章會好走很多。

[110] 方向的久期行列式（secular determinant）

| −ω²ρ + ½(C₁₁ + C₄₄)K² ½(C₁₂ + C₄₄)K² | | ½(C₁₂ + C₄₄)K² −ω²ρ + ½(C₁₁ + C₄₄)K² | = 0

(68) 　p.83

行列式的四個元素是 (67) 兩條齊次方程中 u 與 v 的係數；K² = K_x² + K_y²。

出處推導
把 [110] 的條件 K_x = K_y = K/√2（因此 K_x² = K_y² = K_xK_y = K²/2）代入 (67)，把所有項移到同一邊寫成齊次線性方程組。書上說得很直接：有解的條件是 u 與 v 的係數行列式等於零。
極限行為
這是標準的非平凡解條件：兩條齊次方程 A·(u,v)ᵀ = 0 若要有 (u,v) ≠ (0,0) 的解，必須 det A = 0。得不到 det A = 0 就只有 u = v = 0，也就是「沒有波」。 這個 2×2 矩陣的對角元相等（都是 −ω²ρ + ½(C₁₁ + C₄₄)K²），這是因為 [110] 方向上 x 與 y 完全等價（有一個包含 [110] 的鏡面把 x 與 y 對調）。對角元相等的實對稱 2×2 矩陣，本徵向量必然是 (1, 1)/√2 與 (1, −1)/√2——也就是說，在寫下行列式之前，對稱性就已經決定了偏振方向必定沿 [110] 與 [11̄0]，只剩下哪個配哪個根要算。這是一個很值得內化的觀點：對稱性決定偏振，動力學只決定速度。

補出 (68) → (69)：行列式怎麼展開成兩個根補推導

書上寫完 (68) 就直接說「This equation has the roots」然後印出 (69) 的兩個根。中間只有兩行代數，但做一次可以確認符號沒錯，也能看出兩個根為什麼一個是加、一個是減。

  1. 先確認 (68) 的元素。由 (67) 上式移項：[−ω²ρ + C₁₁K_x² + C₄₄K_y²]u + (C₁₂ + C₄₄)K_xK_y v = 0。代入 K_x² = K_y² = K_xK_y = K²/2：[−ω²ρ + ½(C₁₁ + C₄₄)K²]u + ½(C₁₂ + C₄₄)K² v = 0。下式同理，u 與 v 角色對調。
  2. 令 X ≡ −ω²ρ + ½(C₁₁ + C₄₄)K²（對角元）、Y ≡ ½(C₁₂ + C₄₄)K²（非對角元）。行列式條件是 X² − Y² = 0，即 (X − Y)(X + Y) = 0。
  3. 分支一：X = Y。−ω²ρ + ½(C₁₁ + C₄₄)K² = ½(C₁₂ + C₄₄)K² ⟹ ω²ρ = ½(C₁₁ + C₄₄)K² − ½(C₁₂ + C₄₄)K² = ½(C₁₁ + C₄₄ − C₁₂ − C₄₄)K² = ½(C₁₁ − C₁₂)K²。C₄₄ 完全抵消。
  4. 分支二：X = −Y。−ω²ρ + ½(C₁₁ + C₄₄)K² = −½(C₁₂ + C₄₄)K² ⟹ ω²ρ = ½(C₁₁ + C₄₄)K² + ½(C₁₂ + C₄₄)K² = ½(C₁₁ + C₁₂ + 2C₄₄)K²。
  5. 兩個根合起來就是 (69)。書上把 ½(C₁₁ + C₁₂ + 2C₄₄)K² 列為第一個根、½(C₁₁ − C₁₂)K² 列為第二個根。
  6. 檢查一（和）：兩根之和 = ½(C₁₁ + C₁₂ + 2C₄₄)K² + ½(C₁₁ − C₁₂)K² = (C₁₁ + C₄₄)K²，正好等於 2 × 對角元的常數部分，也就是矩陣的跡 ✓
  7. 檢查二（正定性）：兩個 ω² 都要為正，波速才是實數。第二個根要求 C₁₁ − C₁₂ > 0，第一個根要求 C₁₁ + C₁₂ + 2C₄₄ > 0。前者正是習題 14 四條判據裡的核心一條（書上寫成 C₁₁² − C₁₂² > 0，配上 C₁₁ > 0 之後與 C₁₁ − C₁₂ > 0 等價）。彈性穩定性與「所有波速為實數」是同一件事，這條線索到習題 14 會完整收攏。

[110] 方向 xy 面內兩支波的色散關係

ω²ρ = ½(C₁₁ + C₁₂ + 2C₄₄)K² （第一根，縱波）； ω²ρ = ½(C₁₁ − C₁₂)K² （第二根，橫波）

(69) 　p.83

出處推導

極限行為
第二個根裡完全沒有 C₄₄，而且它的有效彈性常數 ½(C₁₁ − C₁₂) 正是習題 11 定義的那個「有效剪切常數」。這不是巧合：這支波的位移沿 [11̄0]、傳播沿 [110]，造成的形變正是 e_xx = −e_yy 型的四方剪切，也就是本段開頭那個二重本徵值所對應的形變模式。 極限與物理：若 C₁₁ − C₁₂ → 0，這支橫波的速度趨於零，晶體對四方剪切完全不抵抗。這叫作軟模（soft mode），是結構相變的典型前兆——書上習題 14 末尾就指出 C₁₁ ≈ C₁₂ 時會出現不穩定，並給了 Testardi 等人 1965 年在 Phys. 補出 (70)(71)：回代決定偏振方向（含兩條校註）補推導

書上在 (69) 之後問了一句很好的問題：我們怎麼決定粒子位移的方向？答案是把每個根代回 (67) 的上式，看 u 與 v 的比值。這一步在書上只印了兩條式子 (70)(71) 與結論，中間的一行代數在這裡補出來。順便處理這一頁的兩處印刷問題。

  1. 第一根回代。把 ω²ρ = ½(C₁₁ + C₁₂ + 2C₄₄)K² 代入 (67) 的上式左邊（此時 K_x² = K_y² = K_xK_y = K²/2），得到書上的 (70)：½(C₁₁ + C₁₂ + 2C₄₄)K²u = ½(C₁₁ + C₄₄)K²u + ½(C₁₂ + C₄₄)K²v。
  2. 兩邊消去 ½K²：(C₁₁ + C₁₂ + 2C₄₄)u = (C₁₁ + C₄₄)u + (C₁₂ + C₄₄)v。
  3. 移項：[(C₁₁ + C₁₂ + 2C₄₄) − (C₁₁ + C₄₄)]u = (C₁₂ + C₄₄)v ⟹ (C₁₂ + C₄₄)u = (C₁₂ + C₄₄)v ⟹ u = v（只要 C₁₂ + C₄₄ ≠ 0）。
  4. u = v 表示位移向量正比於 (1, 1, 0)，也就是沿 [110]。而波向量 K 也沿 [110]。位移平行於 K，所以這是縱波。書上明說位移沿 [110] 且平行於 K 向量，並指向 Fig. 20。
  5. 第二根回代。把 ω²ρ = ½(C₁₁ − C₁₂)K² 代入同一條上式，得到書上的 (71)：½(C₁₁ − C₁₂)K²u = ½(C₁₁ + C₄₄)K²u + ½(C₁₂ + C₄₄)K²v。
  6. 消去 ½K²：(C₁₁ − C₁₂)u = (C₁₁ + C₄₄)u + (C₁₂ + C₄₄)v。
  7. 移項：[(C₁₁ − C₁₂) − (C₁₁ + C₄₄)]u = (C₁₂ + C₄₄)v ⟹ −(C₁₂ + C₄₄)u = (C₁₂ + C₄₄)v ⟹ u = −v。
  8. u = −v 表示位移向量正比於 (1, −1, 0)，也就是沿 [11̄0]。它與 K ∥ [110] 的內積是 1×1 + (−1)×1 + 0 = 0，確實垂直。所以這是橫波。

實務：怎麼從 [110] 的三個速度反解三個彈性常數我的判讀

書上說 [110] 的價值是三個常數可以從三個速度簡單定出，但沒有把反解寫出來。既然這是這個方向存在的理由，把它補完。

量到三個速度 v_L、v_T1、v_T2（同一塊 (110) 切面的樣品，縱波換能器一次、兩個正交的橫波換能器各一次），並獨立量出密度 ρ，則：

觀測量有效彈性常數反解
v_T1（位移沿 [001]，垂直於 K 與 [11̄0] 所張的 xy 傳播平面）C₄₄C₄₄ = ρv_T1²
v_T2（位移沿 [11̄0]，在 xy 傳播平面內、垂直於 K）½(C₁₁ − C₁₂)C₁₁ − C₁₂ = 2ρv_T2²
v_L（位移沿 [110]）½(C₁₁ + C₁₂ + 2C₄₄)C₁₁ + C₁₂ = 2ρv_L² − 2C₄₄

最後兩列相加除以 2 得 C₁₁ = ρ(v_L² + v_T2²) − ρv_T1²，相減得 C₁₂ = ρ(v_L² − v_T2²) − ρv_T1²。三個常數全部拿到。

兩個實務上的提醒。第一，這三支波的偏振方向是固定的，換能器貼的方向錯了就量到別的模式，或者同時激發兩支而看到兩個回波。第二，兩支橫波的速度在 [110] 上不簡併，這反而是好事——它們在示波器上分得開，所以一次量測能得到兩個獨立資訊。如果拿 [100] 切面來量，兩支橫波簡併成同一個回波，你永遠分不出第二個獨立的剪切資訊，也就拿不到 C₁₂。

順帶一提，這也解釋了為什麼超音波量彈性常數需要密度：(C/ρ)^(1/2) 裡的 ρ 要另外量（阿基米德法或由晶格常數與分子量算）。Table 11 特地附上密度那一欄，就是為了讓讀者能自己做這個換算。

一般方向：三個簡正模，但偏振不再是純橫或純縱

書上 p.85 在進入 SUMMARY 之前有一段總結性的陳述，值得逐句看清楚。

第一句：給定波向量 K 的大小與方向，晶體中有三個簡正模（normal modes）。三這個數字不是巧合——它等於每個原子的自由度數（x、y、z 三個位移分量），也等於 (57a)(57b)(57c) 這三條耦合方程。在第 4 章你會看到，若原胞裡有 p 個原子，簡正模會變成 3p 支（3 支聲學、3p − 3 支光學），而這一段處理的連續介質對應的正是那 3 支聲學支在 K → 0 的極限。

第二句也是最重要的一句：一般而言，這些模式的偏振（也就是粒子位移的方向）並不恰好平行或垂直於 K。這推翻了很多人從高中物理帶來的直覺——「波不是分成縱波與橫波兩種嗎？」在各向異性介質裡，嚴格的縱／橫分類只在特殊方向成立。一般方向上三支波是「準縱波」（quasi-longitudinal，偏振偏離 K 幾度到幾十度）與兩支「準橫波」。

第三句給出例外：在立方晶的 [100]、[111]、[110] 這三個特殊傳播方向上，三個模式中有兩個的粒子運動恰好橫向於 K，第三個恰好縱向（平行於 K）。書上並直接說，在這些特殊方向上分析比一般方向簡單得多。

為什麼恰好是這三個方向？因為它們是立方晶的三種高對稱軸（四重、三重、二重）。當 K 沿著一條旋轉軸時，位移沿該軸（縱向）與垂直該軸（橫向）分別屬於不同的對稱表示，動力學矩陣在這兩個子空間之間的矩陣元被對稱性強制為零，所以不混。K 一旦偏離這些軸，混合就恢復。這個群論解釋是我補的，但它正是書上「analysis is much simpler in these special directions」這句話背後的機制。

這件事在實驗上有後果：用超音波量彈性常數時，樣品切面的取向誤差會讓你激發到準縱波而非純縱波，量到的速度不再對應表上那個乾淨的有效常數。這是超音波彈性常數量測中最主要的系統誤差來源之一。

一條免費的檢查：三個波速的平方和與方向無關（習題 13）補推導

習題 13(b) 要求證明：立方晶中任何方向上三個彈性波速度的平方和等於 (C₁₁ + 2C₄₄)/ρ。這條規則是驗算 Fig. 20 那張表最快的工具——不必重新推導，只要加一加就知道有沒有抄錯。書上把它列為習題並提示「久期方程諸根之和等於對角元素 a_ii 之和」，這裡把三個主方向的驗算做完。

  1. 原理：三個 ω²ρ 是動力學矩陣的三個本徵值，本徵值之和等於矩陣的跡。立方晶的動力學矩陣對角元是 C₁₁K_i² + C₄₄(K² − K_i²)（i = x, y, z），三者相加 = C₁₁K² + C₄₄(3K² − K²) = (C₁₁ + 2C₄₄)K²。因為 v² = ω²/K²，得 Σv² = (C₁₁ + 2C₄₄)/ρ，與方向無關。
  2. [100] 驗算：C₁₁ + C₄₄ + C₄₄ = C₁₁ + 2C₄₄ ✓（縱波一支、橫波兩支簡併）
  3. [110] 驗算：½(C₁₁ + C₁₂ + 2C₄₄) + C₄₄ + ½(C₁₁ − C₁₂) = ½C₁₁ + ½C₁₂ + C₄₄ + C₄₄ + ½C₁₁ − ½C₁₂ = C₁₁ + 2C₄₄ ✓ C₁₂ 完全抵消。
  4. [111] 驗算：⅓(C₁₁ + 2C₁₂ + 4C₄₄) + 2 × ⅓(C₁₁ − C₁₂ + C₄₄) = ⅓[C₁₁ + 2C₁₂ + 4C₄₄ + 2C₁₁ − 2C₁₂ + 2C₄₄] = ⅓[3C₁₁ + 6C₄₄] = C₁₁ + 2C₄₄ ✓
  5. 三個方向全部通過，說明 Fig. 20 的六個有效常數彼此一致。這條規則也可以用來抓自己的計算錯誤：推 [111] 的時候如果算出來的三個常數加起來不等於 C₁₁ + 2C₄₄，一定有一步錯了。

第 3 章的摘要只有五條，每一條都對應章內的一個小節。這裡逐條說明它在講什麼、對應哪一段推導。

第一條：惰性氣體原子的晶體由 van der Waals 交互作用（誘發偶極—偶極交互作用）束縛，其強度隨距離以 1/R⁶ 變化。這對應 p.53–59 的討論。1/R⁶ 的來源是兩個瞬時偶極之間的二階微擾能，不是靜電偶極—偶極（那會是 1/R³ 且平均為零）。這條也是 Lennard-Jones 位能 (10) 裡吸引項的來源，而 (12) 的晶格和 Σ′p⁻⁶ = 14.45392（fcc）就是把它對全晶體加總的結果。

第二條：原子間的排斥交互作用一般來自重疊電荷分布的靜電排斥，以及 Pauli 原理——它迫使重疊的平行自旋電子進入能量較高的軌域。這條有兩個機制而不是一個，Kittel 特地並列。純靜電排斥不足以解釋短程的陡峭排斥；Pauli 不相容原理才是主因。這條與第五條（共價鍵）互為表裡：Pauli 排斥對反平行自旋是減弱的，所以反平行自旋才允許大幅重疊。

第三條：離子晶體由異號離子的靜電吸引束縛。電荷為 ±q 的 2N 個離子構成的結構，其靜電能（CGS）為 U = −Nαq²/R = −NΣ(±)q²/r_ij，其中 α 是 Madelung 常數，R 是最近鄰距離。這對應 p.60–66。注意這條裡出現的是 2N 個離子、N 出現在係數上——與習題 5 的一維鏈用的是同一套記號約定（2N 個離子 = N 個「分子」）。

第四條：金屬的結合來自價電子動能相對於自由原子時的降低。這是四種結合裡唯一一個動能主導的機制。物理圖像是：電子從束縛在單一原子上（波函數侷限、動量不確定度大、動能高）變成在整塊金屬裡離域（波函數延展、動能低）。這條會在第 6 章自由電子費米氣裡被量化。

第五條：共價鍵的特徵是反平行電子自旋的電荷分布重疊。Pauli 對排斥的貢獻對反平行自旋是減弱的，這使得更大程度的重疊成為可能；重疊的電子以靜電吸引把相關的離子實束縛在一起。這條把第二條反過來用：既然 Pauli 排斥只針對平行自旋，那麼把兩個電子配成自旋相反，就能讓它們的電荷雲大幅重疊而不付出 Pauli 代價；重疊區的負電荷同時吸引兩邊的離子實，鍵就形成了。

摘要裡沒有提彈性常數。這是這一章結構上一個值得注意的地方：第 3 章的後半（p.73–85，應力應變、彈性常數、彈性波）在 SUMMARY 五條裡完全沒有出現。原因大概是這部分在體例上比較像是往第 4 章的過渡，而不是「結合」這個主題的一部分。但從習題的分佈（14 題裡有 7 題是彈性）看得出來，Kittel 並不認為它次要。

習題 2：bcc 與 fcc 氖的內聚能比補推導

題目給了 bcc 結構的晶格和 Σ′p⁻¹² = 9.11418、Σ′p⁻⁶ = 12.2533，要求算 bcc 與 fcc 內聚能的比值，並附答案 0.958。這題的價值在於它證明一件重要的事：惰性氣體晶體選 fcc 而不是 bcc，純粹是 Lennard-Jones 求和的結果，不需要任何量子力學。

  1. 通用起點（由 (11) 推廣，把 fcc 的數字換成一般的 A₁₂ ≡ Σ′p⁻¹²、A₆ ≡ Σ′p⁻⁶）：U_tot(R) = 2Nε[A₁₂(σ/R)¹² − A₆(σ/R)⁶]。
  2. 對 R 求導並令為零：dU/dR = 2Nε[−12A₁₂σ¹²/R¹³ + 6A₆σ⁶/R⁷] = 0 ⟹ 12A₁₂σ¹²/R₀¹³ = 6A₆σ⁶/R₀⁷ ⟹ (σ/R₀)⁶ = A₆/(2A₁₂)，即 R₀/σ = (2A₁₂/A₆)^(1/6)。
  3. 回代求最小值：令 x ≡ (σ/R₀)⁶ = A₆/(2A₁₂)。U(R₀) = 2Nε[A₁₂x² − A₆x] = 2Nε[A₁₂·A₆²/(4A₁₂²) − A₆²/(2A₁₂)] = 2Nε·A₆²/A₁₂·[1/4 − 1/2] = −(Nε/2)·(A₆²/A₁₂)。
  4. 所以內聚能只透過組合 A₆²/A₁₂ 依賴結構。兩結構的比值就是這個組合的比值。
  5. fcc（書上 (12)）：A₁₂ = 12.13188、A₆ = 14.45392。A₆²/A₁₂ = 208.916/12.13188 = 17.2204。
  6. bcc（題目給）：A₁₂ = 9.11418、A₆ = 12.2533。A₆²/A₁₂ = 150.143/9.11418 = 16.4736。
  7. 比值 = 16.4736/17.2204 = 0.9566，也就是 bcc 的內聚能只有 fcc 的 95.7%。題目附的答案是 0.958，與我算的 0.9566 差 0.15%；這個差距的量級與晶格和只給到六位有效數字時的捨入一致（若把 fcc 的和改用書上 (15) 裡的四位近似 12.13 與 14.45，比值變成 0.9570）。結論不受影響：fcc 較穩定。
  8. 自洽檢查：用同一條公式回算 fcc 的平衡距離與能量。R₀/σ = (2×12.13188/14.45392)^(1/6) = 1.0902 ✓ 與書上 (14) 的 1.09 一致。U(R₀) = −(Nε/2)(17.2204) = −8.610Nε = −2.1525 × (4Nε) ✓ 與書上 (16) 的 −(2.15)(4Nε) 一致。兩個獨立檢查都通過，公式無誤。
  9. 物理解讀：fcc 的配位數是 12、bcc 是 8。van der Waals 是無方向性的中心力，這種力總是偏好高配位數的最密堆積——差距只有 4.3%，但足以決定基態結構。相對地，共價鍵有方向性，Si 才會選配位數只有 4 的鑽石結構。

習題 3：固態分子氫——量子修正有多大補推導

題目給 H₂ 從氣體量測得到的 Lennard-Jones 參數 ε = 50 × 10⁻¹⁶ erg、σ = 2.96 Å，要求算每莫耳 H₂ 的內聚能（以 fcc 結構計算，把每個 H₂ 分子當成一個球），並指出實測值 0.751 kJ/mol 遠小於計算值，因此量子修正必定非常重要。這題是第 3 章「古典模型在哪裡失效」的壓軸。

  1. 用上一題導出的通式，fcc：U(R₀) = −(Nε/2)(A₆²/A₁₂) = −8.610Nε（等同書上 (16) 的 −2.15 × 4Nε）。
  2. 每個分子的內聚能：8.610 × 50 × 10⁻¹⁶ erg = 4.305 × 10⁻¹⁴ erg。
  3. 換算成每莫耳：4.305 × 10⁻¹⁴ erg × 6.022 × 10²³ /mol = 2.593 × 10¹⁰ erg/mol。1 J = 10⁷ erg，故 = 2.593 × 10³ J/mol = 2.59 kJ/mol。
  4. （順帶：平衡距離 R₀ = 1.09σ = 1.09 × 2.96 = 3.23 Å。）
  5. 與實測比較：計算 2.59 kJ/mol，實測 0.751 kJ/mol。計算值是實測的 3.45 倍——古典的 Lennard-Jones 計算高估了將近 250%。
  6. 為什麼：書上 p.59–60 已經給了線索。量子零點能的修正對 Ne、Ar、Kr、Xe 分別是 (16) 式的 28%、10%、6%、4%，而且書上明說「原子越重，量子修正越小」，因為零點動能 ~ (h/λ)²/2M 反比於質量。H₂ 的質量只有 Ne 的 1/10，零點能修正因此遠大於 Ne 的 28%——大到把 2.59 kJ/mol 砍成 0.751 kJ/mol，也就是零點能吃掉了約 71% 的古典結合能。
  7. 這就是「量子固體」的定義（習題 1 的標題）：零點能與位能同量級的固體。He 更極端——它在常壓下根本不固化，因為零點能超過了 van der Waals 的位能井深。H₂ 勉強固化，但晶格常數被零點運動撐得比古典預測大很多。
  8. 與本段彈性的連結：量子固體的彈性常數也會被零點運動大幅軟化。這解釋了為什麼 Table 11、Table 12 裡沒有 He 與 H₂——它們的彈性常數小到與這些表的尺度不相稱，而且強烈依賴壓力。

習題 5：一維離子鏈（含一條校註）補推導

考慮一列 2N 個電荷交替為 ±q 的離子，最近鄰之間有排斥位能 A/Rⁿ。(a) 求平衡間距下的 U(R₀)；(b) 令 R₀ → R₀(1 − δ)，證明壓縮單位長度所需的功的首項是 ½Cδ²，並求 C。這題是整章唯一一個 Madelung 常數可以精確求和的例子，非常值得手算。書上並提醒：不能直接從 U(R₀) 的表達式得到 (b) 的結果，必須用完整的 U(R)。

  1. 一維 Madelung 常數。取一個參考離子，兩側距離 R、2R、3R… 各有一個離子，電荷符號交替。該離子的靜電能 = −(2q²/R)(1 − 1/2 + 1/3 − 1/4 + …) = −(2q²/R)ln 2。所以 α = 2 ln 2 ≈ 1.386。（用了 ln(1+x) 在 x = 1 的級數。一維鏈之所以能精確求和，正是因為這個交替級數收斂。）
  2. 總能量。2N 個離子 = N 個「分子」。靜電總能 = ½ × 2N × (−2q²ln2/R) = −2Nq²ln2/R（½ 是避免重複計算離子對）。最近鄰鍵有 2N − 1 ≈ 2N 條，排斥總能 = 2NA/Rⁿ。故 U(R) = 2NA/Rⁿ − 2Nq²ln2/R。
  3. (a) 平衡。dU/dR = −2nNA/R^(n+1) + 2Nq²ln2/R² = 0 ⟹ A = q²ln2·R₀^(n−1)/n。
  4. 代回：U(R₀) = 2N·[q²ln2·R₀^(n−1)/n]/R₀ⁿ − 2Nq²ln2/R₀ = (2Nq²ln2/R₀)(1/n − 1) = −(2Nq²ln2/R₀)(1 − 1/n) ✓ 與題目答案一致。
  5. 物理解讀：括號 (1 − 1/n) 是「排斥項扣掉的比例」。n → ∞（硬球極限）時 U → −2Nq²ln2/R₀，整個 Madelung 能都保留；n 越小排斥越軟、扣掉越多。典型的 n ≈ 9，扣掉 11%。
  6. (b) 壓縮功。這裡必須用完整的 U(R) 做泰勒展開（這正是題目提醒的重點）。U'(R₀) = 0，所以首項是二階：ΔU = ½U''(R₀)(ΔR)²，其中 ΔR = R₀(1−δ) − R₀ = −R₀δ。
  7. U'' = 2n(n+1)NA/R^(n+2) − 4Nq²ln2/R³。代入 A = q²ln2·R₀^(n−1)/n：第一項 = 2(n+1)Nq²ln2/R₀³。故 U''(R₀) = [2(n+1) − 4]Nq²ln2/R₀³ = 2(n−1)Nq²ln2/R₀³。
  8. ΔU = ½ × 2(n−1)Nq²ln2/R₀³ × R₀²δ² = (n−1)Nq²ln2·δ²/R₀。
  9. 除以長度。鏈長 L = 2NR₀。單位長度的功 = (n−1)Nq²ln2·δ²/(R₀ · 2NR₀) = ½·[(n−1)q²ln2/R₀²]·δ²。
  10. 對照 ½Cδ² 得 C = (n−1)q²ln2/R₀²。
  11. 校註（我的判讀，非書上說法）：書上印的答案是 C = (n−1)q²ln2/R₀（分母只有一次方）。我把書本 p.86 該式放大算繪目視確認，書上確實印 R₀。但量綱上這說不通：ΔU/L 的量綱是能量/長度，δ 無因次，所以 C 必須有能量/長度的量綱。在 CGS 中 q²/R 是能量，q²/R² 才是能量/長度。因此 應為 R₀²。我的逐步推導也給出 R₀²。疑為原書誤植。（若把 (b) 讀成「整條鏈的總壓縮功」而非「單位長度的功」，則係數是 2N(n−1)q²ln2/R₀，仍然不是書上印的形式。）
  12. 與正文的連結：這裡的 C 就是一維版本的彈性剛度常數，扮演的角色與 (54) 的 B 完全相同——都是「能量密度對應變的二階導數」。n − 1 這個因子的來源也與三維的情形一樣：Madelung 吸引項貢獻 −4（來自 R⁻¹ 的二階導數），排斥項貢獻 +2(n+1)，淨得 2(n−1)。排斥的陡峭度 n 直接決定了晶體有多硬，這是第 3 章前後兩半（結合能／彈性常數）之間最直接的一條橋。

習題 8：Young's modulus 與 Poisson's ratio——(51) 的直接應用補推導

題目說一塊立方晶沿 [100] 方向受到拉伸，要求用彈性剛度常數表示 Young's modulus 與 Poisson's ratio（定義見 Fig. 21）。Fig. 21 畫的是一根長度 l、寬度 w 的長方體受到沿 x 的張力後變成長度 l + δl、寬度 w − δw；圖說定義 Young's modulus 為單向張應力下的「應力/應變」且試片側面自由，Poisson's ratio 定義為 (δw/w)/(δl/l)。這題是上面那段 3×3 矩陣反演最實用的出口。

  1. 關鍵是「側面自由」這個邊界條件。沿 [100] 拉伸、側面不受力，意思是六個應力分量裡只有 X_x ≠ 0，其餘 Y_y = Z_z = Y_z = Z_x = X_y = 0。這時候該用柔度 S 而不是剛度 C，因為已知的是應力、要求的是應變。這就是柔度常數存在的理由。
  2. 由 (37)：e_xx = S₁₁X_x（其餘項因應力為零而消失）；e_yy = S₂₁X_x = S₁₂X_x；e_zz = S₃₁X_x = S₁₂X_x。
  3. Young's modulus：Y ≡ X_x/e_xx = 1/S₁₁。
  4. Poisson's ratio：ν ≡ −e_yy/e_xx = −S₁₂/S₁₁（Fig. 21 定義成 (δw/w)/(δl/l)，因為側向是收縮，δw 取正值時已含了負號）。
  5. 代入前面導出的顯式柔度：S₁₁ = (C₁₁ + C₁₂)/[(C₁₁ + 2C₁₂)(C₁₁ − C₁₂)]，S₁₂ = −C₁₂/[(C₁₁ + 2C₁₂)(C₁₁ − C₁₂)]。
  6. Y = (C₁₁ + 2C₁₂)(C₁₁ − C₁₂)/(C₁₁ + C₁₂)
  7. ν = C₁₂/(C₁₁ + C₁₂)
  8. 檢查一（兩個極端特例）：令 C₁₂ = 0，則 Y = C₁₁、ν = 0。合理：沒有橫向耦合就沒有 Poisson 收縮。（注意 C₁₂ = 0 只是「無橫向耦合」的特例，不是各向同性條件；立方晶的彈性各向同性條件是 C₁₁ = C₁₂ + 2C₄₄，也就是 Zener 比 A = 1，見 (57a) 那一塊。）令 C₁₁ = C₁₂，則 Y = 0（晶體對 [100] 拉伸完全不抵抗）、ν = 1/2（體積守恆的極限）。這正好是穩定邊界 C₁₁ − C₁₂ = 0。
  9. 檢查二（與 B 的關係）：各向同性彈性學有 B = Y/[3(1 − 2ν)]。代入：1 − 2ν = (C₁₁ + C₁₂ − 2C₁₂)/(C₁₁ + C₁₂) = (C₁₁ − C₁₂)/(C₁₁ + C₁₂)。故 Y/[3(1−2ν)] = [(C₁₁+2C₁₂)(C₁₁−C₁₂)/(C₁₁+C₁₂)] × [(C₁₁+C₁₂)/(3(C₁₁−C₁₂))] = ⅓(C₁₁ + 2C₁₂) = B ✓ 與 (54) 完全一致。這是一個很強的交叉驗證。
  10. 數值（Si，Table 12）：Y = (2.938)(1.021)/(2.299) × 10¹² = 1.305 × 10¹² dyn/cm² = 130 GPa（這是 Si 沿 [100] 的 Young's modulus，MEMS 文獻裡的標準值）；ν = 0.639/2.299 = 0.278。
  11. 提醒：Y 與 ν 都依賴拉伸方向。Si 沿 [111] 的 Young's modulus 約 188 GPa，遠大於 [100] 的 130 GPa。工程手冊上那個單一的「矽的楊氏模數」數值其實是多晶平均值，用在單晶元件上要小心。

習題 11：有效剪切常數 ½(C₁₁ − C₁₂)補推導

題目要求證明：立方晶中的剪切常數 ½(C₁₁ − C₁₂) 由設定 e_xx = −e_yy = ½e、其餘應變為零所定義（如 Fig. 22）。提示是考慮能量密度 (43)，找出一個 C′ 使得 U = ½C′e²。Fig. 22 的圖說指出這個變形由 e_xx = −e_yy 兩個剪切複合而成。這題三行就做完，但它給了 [110] 那支 T₂ 波一個直觀的名字。

  1. 設定：e_xx = e/2，e_yy = −e/2，e_zz = 0，所有剪切應變 e_yz = e_zx = e_xy = 0。
  2. 先檢查體積：δ = e_xx + e_yy + e_zz = e/2 − e/2 + 0 = 0。這是保體積的形變 ✓ 符合「剪切」的定義。
  3. 代入 (43)。C₁₁ 項：½C₁₁(e_xx² + e_yy² + e_zz²) = ½C₁₁(e²/4 + e²/4 + 0) = C₁₁e²/4。
  4. C₄₄ 項：剪切應變全為零，貢獻 0。
  5. C₁₂ 項：C₁₂(e_yy e_zz + e_zz e_xx + e_xx e_yy) = C₁₂(0 + 0 + (e/2)(−e/2)) = −C₁₂e²/4。
  6. 合計：U = (C₁₁ − C₁₂)e²/4 = ½ · [½(C₁₁ − C₁₂)] · e²。
  7. 對照 U = ½C′e² 得 C′ = ½(C₁₁ − C₁₂) ✓
  8. 為什麼叫「剪切」常數：e_xx = −e_yy 這個形變，若把座標軸轉 45°（轉到 [110] 與 [11̄0]），會變成純粹的 e_x'y' 型剪切。也就是說它是「沿立方面對角線方向的剪切」，與 C₄₄ 所描述的「沿立方軸的剪切」是不同的兩種剪切。這正是立方晶需要兩個獨立剪切常數的原因。
  9. 與 (69) 的連結：[110] 方向 T₂ 波的有效彈性常數就是這個 ½(C₁₁ − C₁₂)。現在理由清楚了——那支波的位移沿 [11̄0]、傳播沿 [110]，它在晶體裡造成的正是 Fig. 22 這種形變。習題 11 與 (69) 的第二根講的是同一件事，一個從能量看、一個從波動看。

習題 9 與 10：補上 Fig. 20 的 [111] 那一列補推導

習題 9 要求證明立方晶 [111] 方向縱波速度為 v = [⅓(C₁₁ + 2C₁₂ + 4C₄₄)/ρ]^(1/2)，提示是這種波滿足 u = v = w，可令 u = u₀exp[iK(x+y+z)/√3]exp(−iωt)，並使用 (57a)。習題 10 要求證明 [111] 橫波速度為 v_s = [⅓(C₁₁ − C₁₂ + C₄₄)/ρ]^(1/2)。這兩題補完之後 Fig. 20 的三列就全部有推導了。

  1. 設定：K 沿 [111]，所以 K_x = K_y = K_z = K/√3，因此 K_x² = K_y² = K_z² = K²/3，且任兩者相乘 K_iK_j = K²/3。
  2. 習題 9（縱波）：位移也沿 [111]，即 u = v = w（振幅相同）。代入 (57a)，用 ∂²/∂x_i∂x_j → −K_iK_j：
  3. ω²ρu = C₁₁K_x²u + C₄₄(K_y² + K_z²)u + (C₁₂ + C₄₄)(K_xK_y v + K_xK_z w)
  4. 代入 K_i² = K_iK_j = K²/3 與 u = v = w：ω²ρu = (K²/3)[C₁₁ + 2C₄₄]u + (C₁₂ + C₄₄)(K²/3)(u + u) = (K²/3)[C₁₁ + 2C₄₄ + 2C₁₂ + 2C₄₄]u
  5. 整理：ω²ρ = ⅓(C₁₁ + 2C₁₂ + 4C₄₄)K²，故 v = [⅓(C₁₁ + 2C₁₂ + 4C₄₄)/ρ]^(1/2) ✓
  6. 習題 10（橫波）：位移垂直於 [111]，例如取 (u, v, w) ∝ (1, −1, 0)。代入 (57a)（此時 w = 0、v = −u）：
  7. ω²ρu = (K²/3)[C₁₁ + 2C₄₄]u + (C₁₂ + C₄₄)(K²/3)(v + w) = (K²/3)[C₁₁ + 2C₄₄]u + (C₁₂ + C₄₄)(K²/3)(−u)
  8. 整理：ω²ρ = (K²/3)[C₁₁ + 2C₄₄ − C₁₂ − C₄₄] = ⅓(C₁₁ − C₁₂ + C₄₄)K²，故 v_s = [⅓(C₁₁ − C₁₂ + C₄₄)/ρ]^(1/2) ✓
  9. 驗證這是二重簡併：另一個垂直於 [111] 的獨立方向可取 (1, 1, −2)/√6。代入 (57a)（u = 1, v = 1, w = −2 的比例）：ω²ρ·1 = (K²/3)(C₁₁ + 2C₄₄)·1 + (C₁₂ + C₄₄)(K²/3)(1 + (−2)) = (K²/3)[C₁₁ + 2C₄₄ − C₁₂ − C₄₄] ✓ 同一個值。兩支橫波簡併，與 Fig. 20 的圖說一致。
  10. 平方和檢查：⅓(C₁₁ + 2C₁₂ + 4C₄₄) + 2·⅓(C₁₁ − C₁₂ + C₄₄) = ⅓(3C₁₁ + 6C₄₄) = C₁₁ + 2C₄₄ ✓ 通過習題 13 的規則。
  11. 校註（習題 10 的印刷）：書上 p.87 習題 10 印的是 v_s = [⅓(C₁₁ − C₁₂ + C₄₄/ρ]^(1/2)——右括號掉在 ρ 之後、⅓( 的左括號沒有配對關閉。我放大算繪目視確認書上確實如此印刷。依量綱（括號內三項都必須是彈性常數，然後整組除以 ρ）應為 [⅓(C₁₁ − C₁₂ + C₄₄)/ρ]^(1/2)。原書排版誤植。另外習題 9 的速度符號印成 v_x（下標 x），依上下文應是縱波速度 v_ℓ 或 v_L；這不影響物理。
  12. 數值（Si，ρ = 2.33 g/cm³）：[111] 縱波 9.36 km/s、橫波 5.10 km/s。與 [100] 的 8.44 / 5.84 相比，[111] 是 Si 縱波最快、橫波最慢的方向之一。（以下為我補的外部連結，書上未提：這種方向依賴性在聲子聚焦（phonon focusing）實驗裡會直接看到——從點熱源出發的聲子並不均勻地向各方向散開，而是沿著群速度較大的方向聚集成明亮圖樣。）

習題 14：穩定性判據——本段所有線索的匯合點補推導

題目說：立方晶（原胞一個原子）對小的均勻形變穩定的判準，是能量密度 (43) 對所有應變分量的組合都為正。問這對彈性剛度常數施加了什麼限制。書上給的答案是 C₄₄ > 0、C₁₁ > 0、C₁₁² − C₁₂² > 0、C₁₁ + 2C₁₂ > 0，並提示這在數學上就是「實對稱二次型正定」的問題，還指出 C₁₁ ≈ C₁₂ 時會出現不穩定，給了 Testardi 等人 1965 年 Phys. Rev. Letters 15, 250 的實例。這題是整段的收束：它用的正是最開頭那個 3×3 區塊對角化。

  1. (43) 是六個應變分量的二次型，而且它是區塊對角的：剪切區塊（e_yz, e_zx, e_xy）與法向區塊（e_xx, e_yy, e_zz）之間沒有交叉項。正定的條件是兩個區塊各自正定。
  2. 剪切區塊：U_shear = ½C₄₄(e_yz² + e_zx² + e_xy²)。這是三個平方項之和，正定 ⟺ C₄₄ > 0。
  3. 法向區塊：U_normal = ½ eᵀ M e，M = [[C₁₁, C₁₂, C₁₂], [C₁₂, C₁₁, C₁₂], [C₁₂, C₁₂, C₁₁]]（注意 (43) 的 C₁₂ 項沒有 ½，正好對應矩陣的非對角元是 C₁₂ 而不是 2C₁₂）。正定 ⟺ 所有本徵值 > 0。
  4. 本徵值前面已經算過：C₁₁ + 2C₁₂（一重，對應均勻膨脹）與 C₁₁ − C₁₂（二重，對應保體積的四方剪切）。所以條件是 C₁₁ + 2C₁₂ > 0 且 C₁₁ − C₁₂ > 0。
  5. 與書上答案的等價性。令 a ≡ C₁₁ + 2C₁₂ > 0、b ≡ C₁₁ − C₁₂ > 0。反解 C₁₁ = (a + 2b)/3 > 0 ✓（書上的第二條）。C₁₁ + C₁₂ = (2a + b)/3 > 0，故 C₁₁² − C₁₂² = (C₁₁ − C₁₂)(C₁₁ + C₁₂) = b(2a + b)/3 > 0 ✓（書上的第三條）。反過來，若 C₁₁ > 0 且 C₁₁² > C₁₂²，則 C₁₁ > |C₁₂| ≥ C₁₂，得 C₁₁ − C₁₂ > 0。兩組條件完全等價。
  6. 物理翻譯——這才是這題的重點。三條獨立條件恰好對應這一段算過的三個波速：
  7. C₄₄ > 0 ⟺ [100] 橫波速度 (C₄₄/ρ)^(1/2) 為實數；
  8. C₁₁ − C₁₂ > 0 ⟺ [110] 的 T₂ 波速度 [½(C₁₁−C₁₂)/ρ]^(1/2) 為實數；
  9. C₁₁ + 2C₁₂ > 0 ⟺ 體模量 B = ⅓(C₁₁ + 2C₁₂) > 0，晶體不會自發塌縮。
  10. 因此「彈性穩定」與「所有彈性波的頻率都是實數」是同一件事。若某個條件被違反，對應的 ω² < 0，ω 變成純虛數，位移 exp(−iωt) 變成指數增長——晶體會沿著那個模式自發形變，也就是發生結構相變。這個模式就叫軟模。
  11. Testardi 的例子：書上指出 C₁₁ ≈ C₁₂ 時的不穩定，那正是 C₁₁ − C₁₂ → 0、四方剪切模軟化的情形，會導致立方→四方的馬氏體相變。（書上只給了文獻出處，沒有點名材料；就我所知這類軟化出現在 A15 結構的 V₃Si、Nb₃Sn 等超導體，但這一句是我補的外部知識，不是書上的內容。）
  12. 數值檢查（用 Table 11、Table 12 的資料）：所有列出的材料都滿足四條判據，但餘裕差很多。Na：C₁₁² − C₁₂² = 0.073² − 0.062² = 0.00148，相對於 C₁₁² = 0.00533 只有 28%——鹼金屬離四方剪切失穩最近。Diamond：C₁₁² − C₁₂² = 114.2，相對於 C₁₁² = 115.8 有 99%，餘裕極大。這與 Zener 比 A 的大小是同一件事的兩種說法（A 大 ⟺ C₁₁ − C₁₂ 小 ⟺ 接近軟模）。

這一段往後怎麼用：接到第 4、5 章與熱物性我的判讀

最後把這一段放回整本書的脈絡，說明它接下來會在哪裡被用到。

接第 4 章（聲子 I：晶格振動）。第 4 章會把原子的離散性放回去，得到單原子鏈的色散關係 ω(K)。那條曲線在 K → 0 的斜率必須等於這一段算出的聲速 (C/ρ)^(1/2)——這是連續介質極限與離散晶格模型之間的一致性檢查，也是驗算第 4 章結果的標準手法。反過來說，這一段的三支波（一縱兩橫）就是第 4 章三支聲學支在長波極限的樣子。

接第 5 章（聲子 II：熱性質）。第 5 章的 Debye 模型把每個偏振的聲速取成常數，而那個常數就是這裡算出來的 v。具體地說，Debye 溫度 θ_D 與聲速的關係是 θ_D ∝ v·n^(1/3)（n 是原子數密度），所以彈性常數大、密度小的材料（鑽石）有高 Debye 溫度，低溫熱容小、熱導率高。Table 11 顯示彈性常數隨溫度上升而下降，這也意味著 θ_D 嚴格說並非常數。

把 Si 的數字串起來看：C₁₁ = 1.66 × 10¹² dyn/cm² ⟹ 縱波 8.4 km/s、橫波 5.8 km/s ⟹ 平均聲速 ~6.5 km/s ⟹ Debye 溫度約 640–650 K。這條「彈性常數 → 聲速 → Debye 溫度 → 熱容」的鏈條，起點就在這一段。

接熱傳導與熱電容研究（與 FinFET Cth 萃取的接點）。晶格熱導率的動力學理論形式是 κ = ⅓ C v ℓ，其中 v 正是這裡的聲速、C 是晶格熱容、ℓ 是聲子平均自由程。在奈米尺度元件裡（FinFET 的 fin 寬度已經進到十奈米量級，遠小於室溫 Si 的聲子平均自由程約 100–300 nm），邊界散射讓 ℓ 被幾何尺寸截斷，κ 大幅下降，而 v 與 C 基本上不變——因為它們是材料的體性質，由這一段的彈性常數與第 5 章的熱容決定。

這對熱容 Cth 的萃取有一個直接的含意：元件層級的熱容 Cth ≈ ρ·c_p·V 幾乎不受奈米尺度效應影響，受影響的主要是熱阻 Rth。也就是說，在做 Cth 萃取時，「材料熱容是可信的體值」這個假設有相當紮實的物理基礎，而熱阻那一側才是需要小心尺寸效應的地方。這一段提供的彈性常數與聲速，正是判斷這條界線落在哪裡的第一手資料。

一個容易誤用的地方。Fig. 20 的表只適用於立方晶、且座標軸沿立方稜。如果你在做應變矽（strained Si）或 SiGe，晶體受到雙軸應變之後立方對稱被破壞（變成四方對稱），獨立彈性常數從 3 個增加到 6 個，(57) 這組方程與 Fig. 20 的表都不再適用。這在 FinFET 的模擬裡是真實存在的情境——通道區的 Si 幾乎總是處於應變狀態。
