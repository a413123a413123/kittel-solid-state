①主要內容與研究問題

本章處理聲子氣體的熱學性質，核心是晶格熱容（lattice heat capacity）以及非諧交互作用帶來的效應。首先用 Planck 分布寫出聲子的熱平衡佔據數與總能量，再把對 K 的求和換成對頻率的積分，因此中心問題變成求態密度 D(ω)。書中依序給出一維與三維的模態計數（固定端與週期性邊界條件）、Debye 模型（聲速為常數）與 Einstein 模型（單一頻率）的態密度與熱容，並導出低溫 Debye T³ 定律與 D(ω) 的一般表達式。後半部處理非諧晶格交互作用：熱膨脹的來源，以及熱傳導係數 K 的動力學理論、聲子氣體的熱阻、umklapp 過程與缺陷/尺寸效應。

②核心物理概念

  • 熱容通常指定容熱容 C_V ≡ (∂U/∂T)_V，比實驗直接量到的 C_p 更基本；聲子對晶體熱容的貢獻稱為晶格熱容 C_lat。
  • 聲子的熱平衡佔據數由 Planck 分布給出，此分布可由 Boltzmann 因子對諧振子各量子態求和直接導出。
  • 把對波向量的求和換成對頻率的積分後，中心問題變成求態密度 D(ω)（單位頻率範圍內的模態數），此函數稱為 density of modes 或 density of states。
  • 模態計數可用固定端邊界條件或週期性邊界條件；兩者給出相同的模態數（每個可動原子一個模態）。三維下每個極化、每個分支在 K 空間中每體積 (2π/L)³ 有一個允許的 K 值。
  • Debye 模型把聲速視為常數（ω = vK），並引入截斷頻率 ω_D 與截斷波向量 K_D，使模態總數恰等於原胞數 N，藉此定義 Debye 溫度 θ。
  • 高溫時 Debye 熱容趨近古典值 3Nk_B；低溫時趨近 T³ 定律。T³ 行為的物理圖像是：只有 ℏω < k_BT 的長波聲學模被激發，佔 K 空間體積的比例約為 (T/θ)³。
  • Einstein 模型假設 N 個同頻率振子，態密度為 δ 函數；高溫給出 Dulong–Petit 值，但低溫以 exp(−ℏω/τ) 衰減，與實驗的 T³ 不符，故常用來近似光學聲子部分。
  • D(ω) 的一般式為對等頻率面的面積分除以群速度；群速度為零的臨界點造成 Van Hove 奇異點。
  • 諧近似的推論（波不互相作用、無熱膨脹、絕熱與等溫彈性常數相等、彈性常數與壓力溫度無關、高溫熱容為常數）在真實晶體都不精確成立，偏差來自非諧項。
  • 熱膨脹來自晶體位能中的非諧項；以 Boltzmann 分布計算平均位移可得古典區的 ⟨x⟩ 正比於溫度，且最低階只涉及反對稱項 gx³。
  • 熱傳導以動力學理論 K = ⅓Cvℓ 描述；聲子平均自由程由幾何散射與聲子間散射決定，非諧耦合預測高溫時 ℓ 正比於 1/T。
  • 只有會改變聲子總動量的 umklapp 過程（K₁ + K₂ = K₃ + G）才造成熱阻；純 N 過程保持聲子流不變，熱阻為零。低溫時 umklapp 失效，改由邊界尺寸效應與同位素散射主導。

③重要模型與公式

Planck 分布（聲子熱平衡佔據數）

⟨n⟩ = 1 / [exp(ℏω/τ) − 1]， τ ≡ k_B T

(2) p.107；同式在小節末另編為 (7) p.108 　p.107

⟨n_{K,p}⟩ 為波向量 K、極化 p 的聲子熱平衡佔據數；τ ≡ k_BT；⟨…⟩ 表熱平衡平均

晶格熱容的一般積分式

C_lat = k_B Σ_p ∫ dω D_p(ω) · x² eˣ / (eˣ − 1)²， x ≡ ℏω/τ = ℏω/k_BT

(10) 　p.108

D_p(ω) 為極化 p 的態密度（單位頻率的模態數）；由 U = Σ_p ∫dω D_p(ω)ℏω/[exp(ℏω/τ)−1] 對溫度微分而得

Debye 模型的態密度

ω = vK ⟹ D(ω) = Vω² / (2π²v³)

(21), (22) 　p.112

v 為（每種極化視為常數的）聲速；V 為試樣體積；由一般式 D(ω) = dN/dω = (VK²/2π²)(dK/dω)（式 (20)）代入 ω = vK 得到

Debye 截斷頻率與截斷波向量

ω_D³ = 6π²v³N/V ； K_D = ω_D/v = (6π²N/V)^{1/3}

(23), (24) 　p.112

N 為試樣中的原胞數；Debye 模型不允許 K > K_D 的模態，K ≤ K_D 的模態數恰好用盡單原子晶格的自由度

Debye 溫度

θ = (ℏv/k_B) (6π²N/V)^{1/3}

(28) 　p.112

θ 為 Debye 溫度，由 ω_D 定義；並定義 x ≡ ℏω/k_BT、x_D ≡ ℏω_D/k_BT = θ/T

Debye 模型熱容（完整式）

C_V = 9Nk_B (T/θ)³ ∫₀^{x_D} dx · x⁴ eˣ / (eˣ − 1)²

(30) 　p.113

由 U = 9Nk_BT(T/θ)³∫₀^{x_D}dx x³/(eˣ−1)（p.113 明言的式 (26) 中間表達式）對溫度微分；x_D = θ/T；T ≫ θ 時趨近古典值 3Nk_B

Debye T³ 定律（極低溫極限）

C_V ≅ (12π⁴/5) N k_B (T/θ)³ ≅ 234 N k_B (T/θ)³

(32) 　p.114

由把積分上限取為無窮大、並用 ∫₀^∞ dx x³/(eˣ−1) = π⁴/15（式 (31)）得到；實際晶體常需低於 θ/50 才有純 T³ 行為

Einstein 模型熱容

C_V = (∂U/∂T)_V = N k_B (ℏω/τ)² · e^{ℏω/τ} / (e^{ℏω/τ} − 1)²

(34) 　p.117

N 個同頻率 ω 的振子（一維）；三維時 N 換成 3N。高溫極限為 3Nk_B（Dulong–Petit 值），低溫則以 exp(−ℏω/τ) 衰減

態密度的一般結果（等頻率面積分）

D(ω) = V/(2π)³ · ∮ dS_ω / v_g ， v_g = |grad_K ω|

(37) 　p.118

dS_ω 為 K 空間中等頻率面上的面積元；v_g 為聲子群速度大小；積分遍及 ω = 常數的曲面，結果對應色散關係的單一分支，亦可用於電子能帶理論

非諧位能與古典熱膨脹

U(x) = cx² − gx³ − fx⁴ ； ⟨x⟩ = (3g/4c²) k_B T

(38), (40) 　p.120

x 為偏離絕對零度平衡間距的位移；c、g、f 皆為正；gx³ 項代表原子互斥的非對稱性，fx⁴ 項代表大振幅下振動的軟化。最低階的熱膨脹只牽涉反對稱項 gx³

熱傳導係數（氣體動力學理論）

j_U = −K dT/dx ； K = ⅓ C v ℓ

(41) j_U=−K dT/dx 在 p.121；(42) K=⅓Cvℓ 在 p.122 　p.121

j_U 為熱能通量（單位時間單位面積傳遞的能量）；C 為單位體積的熱容；v 為平均粒子（聲子）速度；ℓ 為碰撞間的平均自由程。Debye 首先將此式用於介電固體的熱傳導

Umklapp（U）過程的三聲子碰撞

K₁ + K₂ = K₃ + G

(47) 　p.125

G 為倒晶格向量；G = 0 者稱 normal（N）過程。只有 U 過程會大幅改變聲子總動量 J = Σ_K n_K ℏK（式 (46)），因而造成熱阻；適合發生 umklapp 的聲子能量約為 ½k_Bθ，低溫下其數目大致隨 exp(−θ/2T) 變化

④本章最重要的結論

聲子熱容的計算歸結為求態密度 D(ω)：Debye 模型（聲速常數、截斷於 ω_D）給出高溫的古典值 3Nk_B 與低溫的 T³ 定律 C_V ≅ 234 Nk_B(T/θ)³，與實驗（如固態氬）吻合；Einstein 模型雖然低溫以指數衰減而不符實驗，但常用來近似光學聲子部分。真實晶體的熱膨脹、聲子間散射與有限熱傳導都無法由諧近似解釋，必須引入非諧項。熱傳導以 K = ⅓Cvℓ 描述，而能造成熱阻的是會改變聲子總動量的 umklapp 過程 K₁ + K₂ = K₃ + G，不是 N 過程；低溫下 umklapp 失效，平均自由程改由試樣尺寸與同位素、雜質等缺陷散射決定，此時 K 隨 C 而呈 T³ 變化。
