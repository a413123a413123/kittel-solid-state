07

金屬的電子熱容

溫區定位：低溫區　T ≪ θ　·　θ 的十分之一以下

①物理意義與直觀解釋　（我寫的教學說明）

古典預測是災難性的錯誤：若每個傳導電子都像理想氣體分子那樣帶 ³⁄₂k_BT，金屬的熱容應該比實測大兩個數量級。Kittel 稱這是早期金屬電子論最大的困難。

解答是 Pauli 不相容原理。電子填滿費米海之後，絕大多數電子被「鎖死」——它上方的能階都被佔滿，它拿了 k_BT 的能量也無處可去。只有費米面附近寬約 k_BT 的那一薄層電子有空位可跳。這層電子佔全部的比例約 T/T_F，其中 T_F 是費米溫度（金屬中約 5×10⁴ K）。

於是：能被激發的電子數 ∝ N(T/T_F)，每個帶 k_BT，總能量 ∝ Nk_BT²/T_F，微分得 C_el ∝ Nk_BT/T_F——線性於 T，而且比古典值小了 T/T_F ~ 0.01 這個因子。這一步的推理形式與 Pauli 順磁磁化率完全同構（Ch11），兩者都源自「只有費米面附近的電子能響應」。

實驗上怎麼用：低溫金屬的總熱容是電子項與聲子項相加，C = γT + AT³。把數據畫成 C/T 對 T²，就會是一條直線——斜率給聲子項 A（進而給 Debye 溫度 θ），截距給電子項 γ（稱 Sommerfeld 參數，正比於費米面的態密度 D(ε_F)）。這是固態實驗最經典的一張圖，一次量到兩個完全不同來源的物理量。

什麼時候電子項才重要：C_el/C_phonon ∝ T/T³ = 1/T²，所以溫度越低電子項越佔優。室溫下聲子完全主宰，電子項是百分比量級的修正；到了幾 K 的低溫，電子項反而變成主角。

②重要公式與符號定義　（書中）

電子熱容的一般積分式

C_el = dU/dT = ∫₀^∞ dε (ε − ε_F) (df/dT) D(ε)

(28) 　Ch6 p.142

ΔU = U(T) − U(0) 為 N 個電子由 0 加熱到 T 的總能量增量；f(ε) 為費米-狄拉克函數，是 (27) 式中唯一與溫度相關的項；D(ε) 為單位能量範圍的軌域數。

低溫電子熱容（Sommerfeld 展開結果）

C_el = (1/3) π² D(ε_F) k_B² T

(34) 　Ch6 p.144

適用於 k_B T ≪ ε_F；推導中令 τ ≡ k_B T、x ≡ (ε − ε_F)/τ，並用 ∫₋∞^∞ dx x²eˣ/(eˣ+1)² = π²/3。

自由電子氣的電子熱容（以費米溫度表示）

C_el = (1/2) π² N k_B T / T_F

(36) 　Ch6 p.144

由 (34) 代入 D(ε_F) = 3N/2ε_F = 3N/2k_B T_F 得到；k_B T_F ≡ ε_F。C_el 正比於 T，室溫下比古典值 (3/2)Nk_B 小約 0.01 或更少（T_F ~ 5×10⁴ K）。

金屬低溫總熱容的實驗作圖式（電子項＋聲子項）

C = γT + AT³ ，作圖用 C/T = γ + AT²

(37) 　Ch6 p.145

適用於遠低於德拜溫度 θ 與費米溫度 T_F；γ 為 Sommerfeld 參數（電子項係數），A 為聲子項係數，兩者皆為材料特徵常數。以 C/T 對 T² 作圖應得斜率 A、截距 γ 的直線。

熱有效質量（由觀測 γ 與自由電子 γ 之比定義）

m_th/m ≡ γ(observed) / γ(free)

(38) 　Ch6 p.145

m_th 為熱有效質量，m 為電子質量。此形式自然出現是因為 ε_F 反比於電子質量，故 γ ∝ m。偏離 1 源自傳導電子與週期位能、與聲子、與其他電子的交互作用。

③推導所使用的假設　（書中）

  • 自由電子模型：組成原子的價電子成為傳導電子，在金屬體積內自由運動；傳導電子與晶格離子的交互作用留到下一章（能帶理論）才處理（p.133）。
  • 書中把「free electron Fermi gas」定義為「遵守 Pauli 原理的自由電子氣」；並明講 orbital（單電子軌域）模型只有在電子之間沒有交互作用時才是嚴格的（p.134）。
  • 三維推導採週期性邊界條件的平面波 ψ_k = exp(ik·r)，單電子能量 ε_k = ℏ²k²/2m；基態下被佔據的軌域填滿 k 空間中半徑 k_F 的球，ε_F = (ℏ²/2m)(3π²N/V)^(2/3)（p.137–138, p.140）。
  • 有限溫度下軌域被佔據的機率由 Fermi–Dirac 分布 f(ε) = 1/(exp[(ε−μ)/k_BT]+1) 給出，μ 由總粒子數守恆定出，且 T→0 時 μ = ε_F（p.136）。
  • 低溫定量推導假設 k_BT ≪ ε_F，因此把態密度 D(ε) 在 ε_F 取值後提到積分外（書中稱此為 a good approximation）（p.142–143）。
  • 同樣基於 k_BT ≪ ε_F：忽略化學勢 μ 的溫度依賴、直接用常數 ε_F 取代 μ；並把積分下限由 x = −ε_F/τ 延伸到 −∞（書中理由是低溫時 ε_F/τ ~ 100 以上，被積函數已可忽略）（p.143–144）。

④適用條件與限制　（書中）

  • 定量結果 C_el = (1/3)π²D(ε_F)k_B²T = (1/2)π²N k_B T/T_F 是「valid at low temperatures k_BT ≪ ε_F」的表示式，書中明確如此限定（p.142, p.144）。
  • C = γT + AT³ 這個電子項＋聲子項的分解，書中限定在「溫度遠低於 Debye 溫度 θ 與 Fermi 溫度 T_F」時才寫得出來（p.145）。
  • 古典統計力學的預測（每個自由粒子 (3/2)k_B、電子總貢獻 (3/2)Nk_B）與實驗牴觸：室溫觀測到的電子貢獻通常小於此值的 0.01。書中明講這是古典 Maxwell 分布函數的失敗，而不是自由電子模型本身的失敗（p.133, p.141）。
  • 觀測到的 γ（Sommerfeld parameter，數值列於 p.146 的 Table 2）數量級是對的，但常與用自由電子質量 m 算出的值「不太吻合」；書中因此定義熱有效質量 m_th/m ≡ γ(observed)/γ(free)（p.145）。
  • γ 偏離自由電子值的三個來源，書中逐條列出：傳導電子與剛性晶格週期位能的交互作用（band effective mass）、傳導電子與聲子的交互作用（電子拖動鄰近離子）、傳導電子彼此之間的交互作用（p.145, p.147）。
  • 重費米子化合物（UBe₁₃、CeAl₃、CeCu₂Si₂）的 γ 比一般金屬高 2–3 個數量級，書中提到其 f 電子慣性質量可能高達 1000 m —— 自由電子估計在此完全不適用（p.147）。

⑤高溫與低溫行為　（書中）

高溫　T ≫ θ

書中所謂「高溫端」主要是與古典預測的對照：古典統計力學預測自由粒子的熱容為 (3/2)k_B，若 N 個原子各貢獻一個價電子，電子對熱容的貢獻應為 (3/2)Nk_B，如同單原子理想氣體（p.141）。但實際上室溫觀測到的電子貢獻通常小於此值的 0.01（p.141）；書中給的量化理由是：因 T_F ~ 5×10⁴ K，室溫下 C_el 比古典值小約 0.01 或更小（p.142）。書中並在 Fig. 8 說明常見金屬室溫下 τ/ε_F ≈ 0.01，故 μ 非常接近 ε_F，也就是說「室溫」對電子氣而言仍屬簡併的低溫區（p.144）。書中在此章沒有處理 T 接近或超過 T_F（非簡併）時電子熱容如何過渡到古典值。

低溫　T ≪ θ

書中引 Fermi 的話指出比熱在絕對零度消失、低溫下正比於絕對溫度（p.141）。定性論證：從絕對零度加熱時，並非每個電子都獲得 ~k_BT 的能量，只有落在費米能附近 k_BT 能量範圍內軌域的電子被熱激發，佔比約 T/T_F；故 U_el ≈ (N T/T_F)k_BT，C_el = ∂U/∂T ≈ N k_B (T/T_F)，與 T 成正比（p.141）。定量結果為 C_el = (1/3)π²D(ε_F)k_B²T（用到 ∫ x²e^x/(e^x+1)² dx = π²/3），再代入自由電子氣的 D(ε_F) = 3N/2ε_F = 3N/2k_BT_F，得 C_el = (1/2)π² N k_B T/T_F（p.144）。實驗上，在遠低於 θ 與 T_F 時金屬熱容寫成 C = γT + AT³，電子項線性於 T 且在足夠低溫佔主導；作 C/T 對 T² 圖應得直線，斜率 A、截距 γ（鉀的實測例見 Fig. 9：C/T = 2.08 + 2.57 T²）（p.145）。
