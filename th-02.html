02

聲子色散關係與態密度

溫區定位：過渡區　T ~ θ　·　熱容爬升最陡的一段

①物理意義與直觀解釋　（我寫的教學說明）

**色散關係 ω(K)** 回答的是「某個波長的振動，頻率是多少」。它不是一條線而是好幾支：每原胞有 p 個原子，三維下就有 3p 支——3 支**聲學支**（acoustic，長波極限下相鄰原子同相位運動，ω → vK 線性趨近零）與 3(p−1) 支**光學支**（optical，相鄰原子反相位，即使 K → 0 頻率也不為零）。矽是每原胞 2 個原子的鑽石結構，所以有 3 支聲學支與 3 支光學支。

但算熱容時我們**不需要**知道每個 K 對應哪個 ω，只需要知道「頻率落在 ω 到 ω+dω 之間有幾個模式」——這就是**態密度** D(ω)。從 ω(K) 到 D(ω) 是一次資訊壓縮：K 空間的三維資訊被壓成一維的頻率分佈。

直觀上 D(ω) 是「等頻率面在 K 空間掃過的面積除以它推進的速度」——所以群速度 v_g = |∇_K ω| 越小，同樣一點頻率變化就掃過越多 K 空間，D(ω) 越大。群速度為零的地方（色散曲線的水平處）出現**van Hove 奇異點**，D(ω) 發散。這個結構會直接印在熱容曲線上。

**整條路是這樣的**：ω(K) → D(ω) → 配上 Planck 分佈 → 總能量 U(T) → 對 T 微分 → 熱容 C(T)。後面 Einstein 與 Debye 兩個模型的差別，就只是**對 D(ω) 做了不同的簡化假設**。

②重要公式與符號定義　（書中）

Debye 模型的態密度

ω = vK ⟹ D(ω) = Vω² / (2π²v³)

(21), (22) 　Ch5 p.112

v 為（每種極化視為常數的）聲速；V 為試樣體積；由一般式 D(ω) = dN/dω = (VK²/2π²)(dK/dω)（式 (20)）代入 ω = vK 得到

晶格熱容的一般積分式

C_lat = k_B Σ_p ∫ dω D_p(ω) · x² eˣ / (eˣ − 1)²， x ≡ ℏω/τ = ℏω/k_BT

(10) 　Ch5 p.108

D_p(ω) 為極化 p 的態密度（單位頻率的模態數）；由 U = Σ_p ∫dω D_p(ω)ℏω/[exp(ℏω/τ)−1] 對溫度微分而得

態密度的一般結果（等頻率面積分）

D(ω) = V/(2π)³ · ∮ dS_ω / v_g ， v_g = |grad_K ω|

(37) 　Ch5 p.118

dS_ω 為 K 空間中等頻率面上的面積元；v_g 為聲子群速度大小；積分遍及 ω = 常數的曲面，結果對應色散關係的單一分支，亦可用於電子能帶理論

③推導所使用的假設　（書中）

  • 以週期性邊界條件在邊長 L 的立方體（N³ 個原胞）上列舉模：K 空間中每 (2π/L)³ 體積有一個允許的 K 值，即每單位 K 空間體積有 V/8π³ 個允許值，對每個偏振、每個分支各自成立（書本 p.111）
  • Debye 近似：對每個偏振型態，聲速取為常數，如同古典彈性連續體，色散關係寫成 ω = vK（書本 p.112）
  • 若試樣中有 N 個原胞，聲學聲子總模數即為 N；由此定出截止頻率 ω_D³ = 6π²v³N/V 與截止波向量 K_D = ω_D/v，且不允許波向量大於 K_D 的模，K ≤ K_D 的模數目正好耗盡單原子晶格的自由度（書本 p.112）
  • 為簡潔假設聲子速度與偏振無關，因而把單一偏振的結果乘以因子 3（書本 p.112）
  • Einstein 模型：一維中 N 個同頻率 ω 的振子，態密度取為 δ 函數 D(ω) = Nδ(ω − ω₀（書中 p.114 用 ω₀，非 ω_E）)；三維時 N 換成 3N，因每個振子有三個模（書本 p.114、117）
  • 熱平衡佔據由 Planck 分布 ⟨n⟩ = 1/[exp(ℏω/τ) − 1] 給出（τ ≡ k_BT）；所論熱容一律是定容熱容 C_V，且只計聲子貢獻，即晶格熱容 C_lat（書本 p.107）

④適用條件與限制　（書中）

  • Debye T³ 只在「僅長波聲學模被熱激發」時成立——正是那些能以巨觀彈性常數當成彈性連續體處理的模；近似失效的短波長模能量太高，低溫下不會被顯著佔據（書本 p.114）
  • 真實晶體中 T³ 成立的溫度相當低：書中明講可能必須低到 T = θ/50 以下才能得到相當純的 T³ 行為（書本 p.114）
  • 書中明講的失效：Einstein 模型在低溫時熱容以 exp(−ℏω/τ) 衰減，而實驗上已知聲子貢獻是 T³（由上述 Debye 模型說明）；不過 Einstein 模型常被用來近似聲子譜中的光學聲子部分（書本 p.117）
  • Debye 的 D(ω) ∝ ω² 是理想化：實際晶體的譜雖然在小 ω 也以 ω² 起始，但在奇異點處會發展出不連續（書本 p.119，Fig. 14）
  • 一般式 D(ω) = (V/8π³)∮dS_ω/v_g 只對色散關係的單一分支成立；群速度為零的臨界點會產生 Van Hove 奇異點（書本 p.118–119）。一維情形同樣是：色散關係水平（群速為零）處 D₁(ω) 就有奇異點（書本 p.111）
  • 定容熱容 C_V 比實驗實際測得的定壓 C_p 更基本；書中以熱力學關係說明兩者在固體中的分數差通常很小、常可略去，且 T → 0 時 C_p → C_V（書本 p.107 註 1）

⑤高溫與低溫行為　（書中）

高溫　T ≫ θ

Debye 模型在 T ≫ θ 時熱容趨近古典值 3Nk_B（書本 p.113）；Fig. 7 標示 T/θ 大時的漸近值為 24.943 J mol⁻¹ deg⁻¹（書本 p.113）。Einstein 模型的高溫極限同樣是 C_V → 3Nk_B，書中稱之為 Dulong and Petit 值（書本 p.117）。底層原因是 Planck 分布在高溫下對某態的佔據數近似正比於溫度（書本 p.106）。書中並把「熱容在 T > θ 變成常數」列為諧振理論的後果之一（書本 p.119）。

低溫　T ≪ θ

極低溫時把 (29) 式的積分上限取到無窮大（用 ∫₀^∞ x³/(eˣ−1) dx = π⁴/15），得 U ≅ 3π⁴Nk_BT⁴/5θ³，故 T ≪ θ 時 C_V ≅ (12π⁴/5)Nk_B(T/θ)³ ≅ 234 Nk_B(T/θ)³，即 Debye T³ 近似（書本 p.114）。書中另給定性論證：只有 ℏω < k_BT 的模會被顯著激發，佔 K 空間 (K_T/K_D)³ = (T/θ)³ 的比例，約 3N(T/θ)³ 個模各帶約 k_BT 能量，得 U ≈ 3Nk_BT(T/θ)³、C_V = ∂U/∂T = 12Nk_B(T/θ)³（書本 p.114–115）。實驗上固態氬的低溫熱容對 T³ 作圖，與 θ = 92.0 K 的 Debye T³ 律吻合極佳（書本 p.115）。相對地，Einstein 模型低溫以 exp(−ℏω/τ) 指數衰減，與實驗的 T³ 不符（書本 p.117）。
