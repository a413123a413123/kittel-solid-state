①主要內容與研究問題

本章處理與核自旋、電子自旋角動量相關的動力學磁效應，也就是各類磁共振：NMR、NQR、EPR/ESR、FMR、SWR、AFMR、CESR。書中先以 NMR 為基礎，建立共振條件 ω = γB₀、進動運動方程、縱向（T₁）與橫向（T₂）弛豫的 Bloch 方程與吸收功率的 Lorentz 線型。接著討論線寬的來源（剛性晶格中的偶極–偶極交互作用）與運動窄化（motional narrowing）——這是全章最具反直覺性的結果。再處理超精細分裂（接觸超精細交互作用、F 中心、矽中施體原子）與金屬中的 Knight 位移。後半部把同一套進動語言推廣到有序磁性系統：FMR 的形狀效應（去磁因子）、薄膜自旋波共振、反鐵磁共振（異向場與交換場的幾何平均）。最後以受激輻射的 maser／laser 原理與三能階 maser 作結。共同的問題是：共振線的位置、寬度與精細結構分別告訴我們固體的什麼資訊？

②核心物理概念

  • 共振研究可提供四類資訊：單一缺陷的電子結構（由精細結構）、自旋或環境的運動（由線寬變化）、自旋所感受的內部磁場（由共振線位置，如化學位移、Knight 位移）、以及集體自旋激發。
  • 核磁矩與角動量平行：μ = γℏI，γ 為磁旋比；磁場中 I = 1/2 有兩個能階，能差給出共振條件 ℏω = γℏB₀。
  • T₁（縱向／自旋–晶格弛豫時間）描述 M_z 趨向平衡的過程，能量由自旋系統流向晶格振動；絕緣體中主要靠聲子調制晶場，其過程分為 direct、Raman、Orbach 三種，溫度依賴不同。
  • T₂（橫向弛豫時間）是各個磁矩失相（dephasing）的時間；不同局域磁場使自旋以不同頻率進動，最終 M_x、M_y 歸零。因 M_x、M_y 變化不改變磁能，決定 T₂ 的條件可比 T₁ 寬鬆。
  • 剛性晶格中線寬主要由磁偶極–偶極交互作用造成，量級 B_i ≈ μ/a³；質子在 2 Å 間距下約 2 gauss。
  • 運動窄化：當原子快速相對運動、局域場隨機翻轉的特徵時間 τ 很短時，失相變成隨機行走問題，線寬被壓縮為 Δω = (Δω)₀²τ，τ 越短線越窄。水中的質子共振線僅為凍結情形的約 10⁻⁵。
  • 接觸超精細交互作用 U = a I·S 源自電子自旋電流在核位置的磁場，正比於 |ψ(0)|²；只有 s 電子（L=0）貢獻接觸項。氫的基態超精細分裂為 1420 MHz。
  • 超精細分裂可作為順磁點缺陷的結構探針：KCl 中的 F 中心與六個 K³⁹（I = 3/2）作用，I_max = 9，給出 2I_max+1 = 19 個超精細成分、4096 種自旋排列。矽中磷施體在高濃度時因快速跳躍而發生運動窄化，分裂線併為單一窄線。
  • Knight 位移是金屬中核共振相對於抗磁固體的偏移，正比於傳導電子的 Pauli 自旋磁化率乘以核位置電子密度與平均電子密度之比。
  • FMR 的特殊之處：橫向磁化率極大、試樣形狀（去磁場）扮演關鍵角色、交換耦合壓抑偶極線寬（YIG 球可窄至 0.2 G）、且在低射頻功率即飽和（激發自旋波模）。
  • 反鐵磁共振頻率由異向場 B_A 與交換場 B_E 的幾何組合決定；maser／laser 的關鍵在於製造上能階的過剩佈居，三能階 maser 以泵浦飽和 3↔1 巧妙解決此問題。

③重要模型與公式

核磁矩與角動量的關係

μ = γℏI

(1) 　p.363

γ 為磁旋比（常數），I 為以 ℏ 為單位量度的核角動量。

磁共振吸收的基本條件

ℏω = γℏB₀ → ω = γB₀

(4) 　p.364

B₀ 為靜磁場。對質子 γ = 2.675×10⁴ s⁻¹ G⁻¹ = 2.675×10⁸ s⁻¹ T⁻¹，故 ν(MHz) = 4.258 B₀(kilogauss) = 42.58 B₀(tesla)（式 4a）；電子自旋則為 ν(GHz) = 2.80 B₀(kilogauss) = 28.0 B₀(tesla)（式 4b）。

磁化的陀螺（進動）運動方程

dM/dt = γ M × B_a

(7) 　p.366

M = Σμ_i 為單位體積的核磁化，B_a 為外加磁場。由 ℏ dI/dt = μ × B_a（式 5）對所有核求和而得，前提是只有單一同位素（單一 γ）重要。

Bloch 方程（含縱向與橫向弛豫）

dM_x/dt = γ(M×B)_x − M_x/T₂; dM_y/dt = γ(M×B)_y − M_y/T₂; dM_z/dt = γ(M×B)_z + (M₀ − M_z)/T₁

(13) 　p.368

T₁ 為縱向（自旋–晶格）弛豫時間，T₂ 為橫向（失相）弛豫時間，M₀ = χ₀B₀ 為平衡磁化。方程不對 x, y, z 對稱，因系統被沿 ẑ 的靜場所偏置。書中註明 Bloch 方程只是合理近似而非嚴格，未能描述全部固體中的自旋現象。

自由進動解與共振半高半寬

M_x = m e^{−t/T′} cos ωt, M_y = −m e^{−t/T′} sin ωt; ω₀ = γB₀, T′ = T₂; (Δω)_{1/2} = 1/T₂

(15) 自由進動解、(17) ω₀=γB₀ 皆在 p.369 　p.369

吸收功率為 𝒫(ω) = ωγM_zT₂B₁² / [1 + (ω₀ − ω)²T₂²]（式 19），B₁ 為旋轉射頻場振幅。運動類比於二維阻尼諧振子。

剛性晶格的偶極線寬

ΔB = [3(μ·r₁₂)r₁₂ − μ r₁₂²] / r₁₂⁵; B_i ≈ μ/a³

(21), (23) 　p.370

μ 為鄰近磁偶極矩，r₁₂ 為兩偶極間位置向量，a 為最近鄰間距。對間距 2 Å 的質子，B_i ≈ 2 gauss = 2×10⁻⁴ tesla（p.371）。轉換到 SI 需將右式乘以 μ₀/4π。

運動窄化（motional narrowing）

T₂ = 1/(γ²B_i²τ); Δω = 1/T₂ = (Δω)₀² τ

(26) 在 p.372 末；(27)(28) 在 p.373 　p.373

τ 為局域場隨機翻轉（原子跳躍）的特徵時間，(Δω)₀ ≈ γB_i 為剛性晶格線寬。成立條件為 (Δω)₀τ ≪ 1。此結果與剛性晶格的 T₂ ≈ 1/γB_i 截然不同。

接觸超精細交互作用

U = −μ_I·B̄ ≅ γℏμ_B|ψ(0)|² I·S; U = a I·S

(33), (34) 　p.374

|ψ(0)|² 為電子波函數在核位置的機率密度，μ_B = eℏ/2mc 為 Bohr 磁子，a 為超精細常數，I 為以 ℏ 為單位的核自旋。因球殼平均場為零，只有 s 電子（L = 0）貢獻接觸項。

Knight 位移

K = −ΔB/B₀ = a χ_s / (g_N μ_B γ_I ℏ)

(38) 　p.378

χ_s 為傳導電子的 Pauli 自旋磁化率，a 為超精細耦合常數，γ_I 為核磁旋比。近似上 K ≈ χ_s|ψ(0)|²/N，即 Pauli 磁化率再乘上核位置電子濃度與平均電子濃度之比。

鐵磁共振（均勻模）與形狀效應

ω₀ = γ{[B₀ + (N_y − N_z)M][B₀ + (N_x − N_z)M]}^{1/2}; 垂直薄板 ω₀ = γ(B₀ − 4πM); 平行薄板 ω₀ = γ[B₀(B₀ + 4πM)]^{1/2}

(41), (42), (43) 　p.381

N_x, N_y, N_z 為橢球的去磁因子，M 為磁化，B₀ 為外加靜場。球體 N_x = N_y = N_z 時退化為 ω₀ = γB₀。薄膜自旋波共振再加上交換項 Dk²，k = nπ/L（式 44）。

反鐵磁共振頻率

ω₀² = γ² B_A (B_A + 2B_E)

(48) 　p.384

B_A = 2K/M 為異向場（K 為異向能密度、M = |M₁| = |M₂|），B_E = λM 為交換場。此為零外加磁場、單軸反鐵磁的結果。

Maser 作用條件與交換窄化

n_u − n_l > V ΔB / (8πμQ) （CGS）; 交換窄化 Δω ≈ (Δω)₀² / ω_ex

(53) 在 p.387；交換窄化 (49) 在 p.386 　p.387

n_u、n_l 為上、下能階的原子數，V 為腔體體積，Q 為腔體品質因子，μ 為磁矩，ΔB 由 μΔB = ℏΔω 定義。交換窄化式中 ω_ex ≈ J/ℏ 扮演跳躍頻率 1/τ 的角色，(Δω)₀² = γ²⟨B_i²⟩ 為無交換時的靜態偶極線寬平方（p.386）。

④本章最重要的結論

所有磁共振現象都建立在同一個核心關係上：自旋在磁場中以 ω = γB₀ 進動，並透過 Bloch 方程中的 T₁（能量流向晶格）與 T₂（相位失序）弛豫。共振線的三個特徵各自攜帶不同的固體資訊——位置給出自旋所感受的內場（化學位移、Knight 位移、FMR 的去磁場、AFMR 的 B_A 與 B_E），寬度給出運動與交換（運動窄化 Δω = (Δω)₀²τ、交換窄化 Δω ≈ (Δω)₀²/ω_ex），精細結構則給出單一缺陷的電子結構（F 中心、矽中的施體原子）。把同一套進動語言推廣到有序系統即得 FMR、SWR 與 AFMR；而在非平衡的上能階過剩佈居下，同一組能階便可用於受激輻射放大，這就是 maser 與 laser 的原理。
