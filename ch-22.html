①主要內容與研究問題

本章問：如果晶體由 A、B 兩種元素隨機佔據規則晶格位（組成 A_xB_{1−x}），平移對稱性不再完美，能帶理論的結論（費米面、能隙）還成立嗎？絕緣體會不會因能隙消失而變導體？書中的答案是：完美平移對稱性被破壞的後果幾乎總是遠比乍看之下輕微，因為有效屏蔽位能本身就比自由離子位能弱，而且主體原子與添加原子的有效位能差異可能非常小（Si-Ge、Cu-Ag 是經典例子）。章節接著處理取代型固溶體的 Hume-Rothery 規則與電子化合物（電子/原子比與費米球接觸布里淵區邊界的關聯）、order–disorder 轉變與有序度的基本統計理論（長程有序參數 P、混合熵、轉變溫度）、相圖與共晶、過渡金屬合金的磁矩與 s-d 散射，最後是 Kondo 效應與電阻極小值。

②核心物理概念

  • 低濃度雜質原子無法對負責能隙與費米面形狀的有效位能 Fourier 分量 U_G 造成太大影響；雜質引入的非倒晶格向量處的分量，在低濃度下相對 U_G 從不算大。
  • 無序合金的殘餘電阻率隨無序增加；Cu_xAu_{1−x} 的殘餘電阻率隨組成變化為 x(1−x)，即 Nordheim 規則；緩慢冷卻形成 Cu₃Au 與 CuAu 有序結構時，殘餘電阻率因有序而降低。
  • 銀中溶入 1 原子% 銅只增加 0.077 μΩ-cm 的殘餘電阻率，對應的幾何散射截面僅為雜質原子「投影面積」的 3%，可見散射效應非常小。
  • Hume-Rothery 規則：固溶體穩定要求原子直徑差不超過約 15%（Cu-Zn 有利，Zn 可溶到 38 原子%；Cu-Cd 不利，Cd 只能溶 1.7 原子%）；但若 A、B 有強烈形成金屬間化合物的化學傾向，即使直徑有利也不會形成固溶體。
  • 合金的電子結構常可用每原子平均傳導（價）電子數 n 描述；CuZn 的 n = 1.50，CuAl 的 n = 2.00。結構序列 fcc → bcc → γ → hcp 隨 n 增加而出現，對應費米球內接接觸各晶格布里淵區邊界的濃度（fcc 1.36、bcc 1.48、γ 1.54、理想 c/a 的 hcp 1.69）。
  • 有序 AB 合金（bcc）中 B 原子的最近鄰全是 A 原子、反之亦然；這出現在 A-B 吸引為主導交互作用時。合金在絕對零度完全有序，升溫後有序度下降，超過轉變溫度即無序。
  • 轉變溫度標誌長程有序（跨越許多原子間距的秩序）的消失，但近鄰的短程有序或關聯可以在轉變溫度之上持續存在。
  • 有序 CuZn 是 CsCl 結構（簡單立方空間晶格，基底 Cu 在 000、Zn 在 ½½½），結構因子不會消失，故簡單立方空間晶格的所有反射都出現；無序時平均結構因子退化成 bcc 形式，h+k+l 為奇數的反射消失。因此有序晶格多出「超晶格線」。
  • AB 合金（bcc）的轉變是二階，以熱容不連續為標誌；A₃B 則是一階，以潛熱為標誌。
  • 本章的有序度基本理論只考慮 AA、AB、BB 最近鄰對的鍵能，並假設機率互相獨立；平衡有序度由自由能 F = E − TS 對 P 極小化決定，得到可用圖解法求解的超越方程式。
  • 短程有序參數 r 量度最近鄰鍵中 AB 鍵所佔的比例（完全無序時 AB 合金每個 A 原子平均有 4 個 AB 鍵，總數為 8）；r 只反映原子周圍的局部秩序，而 P 反映整個次晶格的純度。轉變溫度之上長程有序嚴格為零，但短程有序不為零。
  • 把銅加入鎳時，每原子有效磁子數線性下降並在 Cu₀.₆₀Ni₀.₄₀ 附近歸零，因為銅提供的額外電子填滿了 3d 能帶。過渡金屬 3d 能帶的平均態密度比 4s 能帶高一個數量級。
  • 過渡金屬的電阻率比緊接其後的貴金屬高約 5 倍（Ni/Pd/Pt 為 7.4/10.8/10.5 μΩ-cm，Cu/Ag/Au 為 1.7/1.6/2.2），因為 s 電子路徑被 d 電子碰撞增加電阻——這是 d 能帶填滿時不存在的強力額外散射機制（s-d 散射）。
  • 在非磁性金屬中稀薄溶入磁性離子時，傳導電子氣在磁性離子附近被磁化，造成間接交換作用（Friedel 或 RKKY 交互作用）；由此產生的 Kondo 效應在低溫給出電阻極小值，且電阻極小值出現處必然存在局域磁矩。

③重要模型與公式

無序合金的平均結構因子（超晶格線消失）

⟨S(hkl)⟩ = ⟨f⟩ + ⟨f⟩ e^{−iπ(h+k+l)} , ⟨f⟩ = (1/2)(f_Cu + f_Zn)

(2) 　p.629

有序 CuZn（CsCl 結構）的結構因子為 S(hkl) = f_Cu + f_Zn e^{−iπ(h+k+l)}（式 1），因 f_Cu ≠ f_Zn 而不會消失；無序時退化為 bcc 形式，h+k+l 為奇數時反射消失

以長程有序參數表示的最近鄰鍵數（bcc，配位數 8）

N_AA = N_BB = 2(1 − P²)N ; N_AB = 4(1 + P²)N

(4) 　p.630

P 為長程有序參數，定義為次晶格 a 上 A 原子數等於 (1/2)(1+P)N、次晶格 b 上 A 原子數等於 (1/2)(1−P)N；P = ±1 為完全有序，P = 0 為無長程有序

鍵能總和與有序參數的關係

E = N_AA U_AA + N_BB U_BB + N_AB U_AB = E₀ + 2N P² U

(3)(4) 在 p.630；(5)(6) 在 p.631 　p.630

E₀ = 2N(U_AA + U_BB + 2U_AB)，有效交互作用 U = 2U_AB − U_AA − U_BB（式 6）；U_ij 為 ij 鍵的能量

混合熵（configurational entropy）

S = 2N k_B ln 2 − N k_B [ (1 + P) ln(1 + P) + (1 − P) ln(1 − P) ]

(8) 　p.631

由 S = k_B ln G 與 Stirling 近似得到，其中 G = { N! / [(1/2)(1+P)N]! [(1/2)(1−P)N]! }²（式 7）；P = ±1 時 S = 0，P = 0 時 S = 2N k_B ln 2

平衡有序度的條件（自由能對 P 極小）

4N P U + N k_B T ln[ (1 + P)/(1 − P) ] = 0

(9) 　p.631

由 F = E − TS 對 P 微分得到；此超越方程式可用圖解法求解，給出平滑下降的 P(T) 曲線

order–disorder 轉變溫度

T_c = −2U / k_B

(10) 　p.631

在轉變點附近展開式 (9) 得 4NPU + 2N k_B T P = 0，並在 T_c 處 P = 0；要發生轉變，有效交互作用 U 必須為負

Kondo 效應：自旋相關電阻率隨低溫上升

ρ_spin = c ρ_M [ 1 + (3zJ/ε_F) ln T ] = c a − c b ln T

(12) 　p.639

J 為交換能，z 為最近鄰數，c 為磁性雜質濃度，ρ_M 量度交換散射的強度；J 為負時自旋電阻率隨溫度下降而上升

電阻極小值的位置

ρ = α T⁵ + c a − c b ln T , dρ/dT = 5αT⁴ − c b/T = 0 , T_min = (c b / 5α)^{1/5}

(13), (14), (15) 　p.640

αT⁵ 為此溫區的聲子貢獻；電阻極小值溫度隨磁性雜質濃度的五分之一次方變化，與實驗（至少 Cu 中的 Fe）相符

④本章最重要的結論

隨機取代型合金雖破壞了完美平移對稱性，但後果遠比預期輕微：低濃度雜質不足以改變決定能隙與費米面的 Fourier 分量 U_G，因此能帶理論的結論大致保留，殘餘電阻率只隨無序度以 x(1−x) 的 Nordheim 形式增加。合金的相結構主要由每原子電子數 n 控制，fcc→bcc→γ→hcp 的序列對應費米球接觸各布里淵區邊界的電子濃度。order–disorder 轉變可用只含最近鄰鍵能的簡單統計理論描述：長程有序參數 P 由自由能極小化決定，轉變溫度 T_c = −2U/k_B，且必須 U < 0 才會發生轉變；長程有序在 T_c 之上嚴格為零，但短程有序仍存在。稀薄磁性合金則因交換散射的動態本質與低溫費米面的銳利，出現 Kondo 電阻極小值，其位置隨雜質濃度的 1/5 次方變化。

⑤與前後章的關係　（我的判讀）

無序佔位打破 Ch1–2 的平移對稱，也動搖 Ch7 能帶理論的前提（書中開章即問：費米面與能隙還在嗎）。與 Ch19 非晶的無序討論互相呼應；Kondo 效應連到 Ch18 量子點中的同名現象。
