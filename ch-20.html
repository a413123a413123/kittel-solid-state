①主要內容與研究問題

本章處理晶體中的點缺陷：化學雜質、空缺晶格位（lattice vacancy）與不在正常晶格位上的額外原子。書中強調某些晶體性質受缺陷控制的程度與受主體成分控制的程度相當——某些半導體的導電度完全來自微量化學雜質，許多晶體的顏色與發光來自雜質或缺陷，原子擴散可被雜質或缺陷大幅加速，機械與塑性性質通常由缺陷控制。章節依序處理：晶格空缺（Schottky 缺陷、Frenkel 缺陷、離子晶體中的成對空缺、二價離子摻雜造成的空缺）、擴散（Fick 定律、活化能、跳躍頻率、離子導電度與 Einstein 關係、金屬中的自擴散），以及色心（F 心、F_A 心、M 心、R 心、V_K 心）。

②核心物理概念

  • 最簡單的缺陷是晶格空缺（Schottky 缺陷）：把內部晶格位的原子搬到晶體表面的晶格位；熱平衡下永遠存在一定數量的空缺，因為無序增加了熵。
  • 緊密堆積金屬在接近熔點時的空缺比例約 10⁻³ 到 10⁻⁴，但某些合金（如硬質過渡金屬碳化物 TiC）某一成分的空缺比例可高達 50%。
  • 離子晶體中形成數目大致相等的正、負離子空缺在能量上通常較有利，因為成對空缺可在局部尺度維持電中性。純鹼金屬鹵化物以 Schottky 缺陷為主，純鹵化銀以 Frenkel 缺陷為主。
  • Frenkel 缺陷是原子從晶格位移到間隙位（interstitial position），即正常不被原子佔據的位置。
  • 在 KCl 中摻入 CaCl₂ 時，每個 Ca²⁺ 進入正常 K⁺ 位就必須產生一個 K⁺ 空缺以維持電中性，因此密度下降；這些額外空缺才是離子導電度增強的原因，而非二價離子本身特別可動。
  • 空缺沿一方向的擴散等價於原子沿反方向的擴散；熱生成的缺陷其形成能會對晶體熱容產生額外貢獻（如溴化銀）。
  • 擴散遵守 Fick 定律，但嚴格說驅動力是化學位能梯度而非僅濃度梯度；擴散常數隨溫度呈 Arrhenius 形式，活化能即原子越過最近鄰位能障所需的能量。
  • 帶電雜質（p.590 逐字 If the impurities are charged）的擴散率可經 Einstein 關係 k_BT μ = qD 轉換成遷移率與導電度；在空缺數由二價離子決定的溫度區間，ln σ 對 1/k_BT 的斜率給出正離子空缺跳躍的活化能 E₊；在熱生成主導的區間，斜率則為 E₊ + (1/2)E_f。
  • 室溫下跳躍頻率約 1 s⁻¹，100 K 時約 10⁻²⁵ s⁻¹，可見低溫擴散極慢。
  • 色心是會吸收可見光的晶格缺陷；一般的晶格空缺並不會使鹼金屬鹵化物著色，只影響紫外吸收。可用化學雜質、過量金屬離子、x/γ 射線與電子轟擊、或電解來著色。
  • F 心（源自德文 Farbe）已由電子自旋共振確認為被束縛在負離子空缺上的一個電子；負離子空缺在完美週期晶格中等效於一個孤立正電荷，會吸引並束縛電子。兩個相鄰 F 心組成 M 心，三個組成 R 心。
  • 電洞形成的色心不如電子色心單純：鹵素離子的 p⁵ 組態是非對稱的，會因 Jahn–Teller 效應扭曲鄰近環境；最著名的捕獲電洞中心是 V_K 心，形如負鹵素分子離子（KCl 中為 Cl₂⁻）。

③重要模型與公式

熱平衡下的晶格空缺數（Boltzmann 因子）

n/(N − n) = exp(−E_V / k_B T) ; n/N ≅ exp(−E_V / k_B T) (n ≪ N)

(1), (2) 　p.585

N 為原子數，n 為平衡空缺數，E_V 為把原子從晶體內部晶格位搬到表面晶格位所需的能量；E_V ≈ 1 eV、T ≈ 1000 K 時 n/N ≈ e⁻¹² ≈ 10⁻⁵

離子晶體中成對空缺（Schottky pair）的平衡數

n ≅ N exp(−E_p / 2 k_B T)

(3) 　p.586

n 為空缺對數目，E_p 為形成一對正負離子空缺的能量；由統計計算得到

Frenkel 缺陷的平衡數

n ≅ (N N')^{1/2} exp(−E_I / 2 k_B T)

(4) 　p.586

N 為晶格位數，N' 為可能的間隙位數，E_I 為把原子從晶格位移到間隙位所需能量；適用於 n ≪ N, N'

Fick 擴散定律

J_N = −D grad N

(5) 　p.588

J_N 為單位時間通過單位面積的原子數；D 為擴散常數（擴散率），單位 cm²/s 或 m²/s；負號表示擴散離開高濃度區

擴散常數的溫度依賴（Arrhenius 形式）

D = D₀ exp(−E / k_B T)

(6) 　p.588

E 為該過程的活化能；碳在 α 鐵中的實驗值為 E = 0.87 eV、D₀ = 0.020 cm²/s

由跳躍頻率導出的擴散常數

p ≅ ν exp(−E / k_B T) ; D = ν a² exp(−E / k_B T)

(7), (9) 　p.590

ν 為特徵原子振動頻率，p 為單位時間跳躍頻率，a 為晶格常數（兩平面間距）；對應式 (6) 中的 D₀ = ν a²

帶電雜質的離子導電度（經 Einstein 關係）

σ = N q μ = (N q² ν a² / k_B T) exp(−E / k_B T)

(11) 　p.590

N 為帶電荷 q 的雜質離子濃度；遷移率 μ = (qνa²/k_BT) exp(−E/k_BT)（式 10），由 Einstein 關係 k_BT μ = qD 得到

熱生成主導區間的空缺比例

f ≅ exp(−E_f / 2 k_B T)

(12) 　p.590

E_f 為形成一對空缺的能量（依 Schottky 或 Frenkel 缺陷理論）；此區間 ln σ 對 1/k_BT 的斜率為 E₊ + (1/2)E_f

④本章最重要的結論

點缺陷（空缺、間隙原子、化學雜質）在熱平衡下必然存在，其濃度由 Boltzmann 因子 exp(−E/k_BT) 決定，Schottky 與 Frenkel 缺陷的成對形成則給出 exp(−E/2k_BT) 的一半指數。這些缺陷是原子擴散的載體：擴散常數 D = νa²exp(−E/k_BT) 具 Arrhenius 形式，並可透過 Einstein 關係與離子導電度連結，因此量測 ln σ 對 1/k_BT 的斜率可在不同溫度區間分別得到空缺跳躍活化能 E₊ 與空缺對形成能 E_f。缺陷也決定光學性質：F 心已由電子自旋共振確認為束縛在負離子空缺上的電子，是鹼金屬鹵化物中最簡單的捕獲電子中心。
