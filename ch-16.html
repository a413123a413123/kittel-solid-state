①主要內容與研究問題

本章先問兩個問題：在介電物質內部，Maxwell 方程式中的巨觀電場 E 與極化 P 有何關係？以及作用在晶格中某個原子位置上的局域電場與極化有何關係？後者決定該原子的偶極矩。接著由局域場與極化率導出介電常數，得到 Clausius–Mossotti 關係。第二半章討論結構相變，特別是鐵電相變：以「極化災變（polarization catastrophe）」與「橫向光學聲子軟化（soft mode）」兩個互補觀點理解位移型（displacive）轉變，並用 Landau 自由能展開處理一階與二階相變，最後談反鐵電性、鐵電疇與壓電性。

②核心物理概念

  • 極化 P 定義為單位體積的偶極矩（對晶胞體積平均）；巨觀電場 E 定義為微觀電場 e(r) 對晶胞體積的平均。
  • 均勻極化物體所產生的巨觀場等於虛擬表面電荷密度 σ=n̂·P 在真空中的場；橢球體具有均勻極化產生均勻退極化場的優點。
  • 局域場分解為 Elocal=E₀+E₁+E₂+E₃，其中只有 E₃（球內偶極的場）隨晶胞內位置急速變化；立方對稱位置 E₃=0。
  • Lorentz 關係：立方位置的局域場等於巨觀場 E 加上 4πP/3（CGS）或 P/3ε₀（SI），實驗數據支持此關係。
  • 總極化率可分為電子、離子、偶極三部分；光頻下只剩電子極化率，此時 Clausius–Mossotti 化為 (n²−1)/(n²+2)=(4π/3)ΣNjαj。
  • 結構相變由自由能 F=U−TS 的極小決定；聲子譜較軟的結構熵較大，因此可能在高溫變成穩定相。
  • 鐵電轉變是結構相變的一個子類，特徵是晶體中出現自發介電極化；鈣鈦礦結構因 O²⁻ 位置非立方、局域場因子異常大而特別容易發生位移型轉變。
  • LST 關係把高靜態介電常數與低頻 TO 模連結起來：ωT→0 時 ε(0)→∞；SrTiO₃ 的中子散射證實 ωT²∝(T−T₀)。

③重要模型與公式

橢球體的退極化場與退極化因子

E₁x = −Nx Px , E₁y = −Ny Py , E₁z = −Nz Pz ; Nx+Ny+Nz = 4π (CGS)，=1 (SI)

(8) 　p.458

N＝退極化因子，依橢球主軸比而定；球體 N=4π/3（CGS）、1/3（SI），薄板法向 N=4π、長圓柱縱向 N=0

Lorentz 局域場關係

E_local = E₀ + E₁ + (4π/3)P = E + (4π/3)P (CGS); E_local = E + P/(3ε₀) (SI)

(17) 　p.462

E₂=(4π/3)P＝Lorentz 空腔表面極化電荷的場；立方位置 E₃=0

Clausius–Mossotti 關係

(ε − 1)/(ε + 2) = (4π/3) Σ_j N_j α_j (CGS); (ε−1)/(ε+2) = (1/3ε₀) Σ_j N_j α_j (SI)

(24) 　p.464

N_j＝j 類原子濃度，α_j＝其極化率（p=αE_local）；僅對滿足 Lorentz 局域場的晶體結構成立

極化災變條件

Σ_i N_i α_i = 3/4π (CGS)

(31) 　p.472

α_i＝i 型離子的電子加離子極化率，N_i＝其單位體積數目；此時 ε→∞，零外場下可有有限極化

順電態的 Curie–Weiss 型介電常數

取 (4π/3)ΣN_iα_i = 1 − 3s，s ≪ 1，則 ε ≅ 1/s ; 若 s ≅ (T − Tc)/ξ，則 ε ≅ ξ/(T − Tc)

(32)(33)(34)(35) 　p.472

s＝偏離臨界值的小量，ξ＝常數，Tc＝轉變溫度；與鈣鈦礦順電態的觀測溫度變化相符

Landau 自由能密度展開與平衡條件

F̂(P;T,E) = −EP + g₀ + ½g₂P² + ¼g₄P⁴ + ⅙g₆P⁶ + ⋯ ; ∂F̂/∂P = 0 = −E + g₂P + g₄P³ + g₆P⁵ + ⋯

(37)(38) 　p.475

g_n＝隨溫度變化的係數；若晶體未極化態具反演中心則無奇次項；取 g₂ = γ(T − T₀)（式(39)），γ>0

二階相變的自發極化

γ(T − T₀)P_s + g₄P_s³ = 0 ⟹ |P_s| = (γ/g₄)^(1/2) (T₀ − T)^(1/2)

(40) 在 p.475 末；(41) |P_s| 在 p.476 　p.475

g₄>0 時為二階轉變，T₀＝Curie 溫度，P_s＝自發極化；LiTaO₃ 為例。g₄<0 時為一階轉變（式(42)(43)，p.477）

轉變溫度以上的介電常數

ε(T > Tc) = 1 + 4πP/E = 1 + 4π/[γ(T − T₀)]

(44) 　p.478

一階或二階轉變皆適用；二階時 T₀=Tc，一階時 T₀<Tc

④本章最重要的結論

介電常數必須透過局域場才能與原子極化率連結：在立方位置採用 Lorentz 局域場 E+4πP/3，即得 Clausius–Mossotti 關係 (ε−1)/(ε+2)=(4π/3)ΣNjαj。當 ΣNiαi 逼近臨界值 3/4π 時發生極化災變，ε 發散並在零外場下出現自發極化，這正是位移型鐵電轉變；同一件事的等價說法是橫向光學聲子凝聚（軟模），由 LST 關係 ωT²/ωL²=ε(∞)/ε(0) 可知 ε(0) 很大必然對應 ωT 很低，SrTiO₃ 的中子散射數據證實了這一點。Landau 自由能展開則統一描述兩類轉變：g₄>0 給二階轉變、極化連續趨零（|Ps|∝(T₀−T)^½），g₄<0 給一階轉變、極化在 Tc 不連續跳變（BaTiO₃）。
