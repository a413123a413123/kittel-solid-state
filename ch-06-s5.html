05磁場中的運動

MOTION IN MAGNETIC FIELDS

書本 p.152-156　·　小節 5 / 6　·　概念 14　推導 12　公式 9

自由電子模型在 p.147 用「整顆費米球平移」得到 σ = ne²τ/m，但電導率把載子數 n 與碰撞時間 τ 綁在一起分不開；本段在運動方程式中加入碰撞摩擦與 Lorentz 力，解出磁場中的穩態漂移速度與迴旋頻率 ω_c，再用「橫向不准有電流」逼出一個 τ、m、B 全部消掉的量——Hall 係數 R_H = −1/nec——使我們能直接數載子並讀出其電荷符號；Table 4 顯示這把尺在 Na、K 上準到千分之幾，卻在 Al、In、Be、As 上連符號都量錯，這個失敗正是第 7–9 章能帶論與「電洞」概念的起點。

這一段在解決什麼問題我的判讀

第 6 章到 p.148 為止，自由電子模型已經交出一張漂亮的成績單：式(43) σ = ne²τ/m 把電導率寫成載子濃度 n、電荷 e、質量 m 與碰撞時間 τ 的組合。但這條式子在實驗上有一個繞不過去的缺點：量電阻只能得到 n 與 τ 的乘積。一塊金屬導電性差，究竟是因為載子少，還是載子很多但很快就被散射掉？單憑 σ 無從分辨。p.150–152 討論 Matthiessen 規則與 umklapp 散射時，其實隱含地假設 n 已知（直接取價電子數），讓 τ 去承擔所有的溫度與雜質相依性——這個假設本身需要一個獨立的實驗來驗證。

這一段（p.152 下半到 p.156 上半）提供的就是那個獨立實驗。做法是在運動方程式裡再加一個力：磁場的 Lorentz 力。磁力不做功，但會把漂移中的電子往側面推；如果樣品側面不讓電流流出，電荷就會在側面堆積，建立一個橫向電場（Hall 場）把側推的力抵銷。這個橫向電場正比於 τ，縱向電流也正比於 τ——兩者相除，τ 就消失了。剩下的 Hall 係數 R_H = −1/nec 只含載子濃度 n 與載子電荷的符號。

這使 Hall 效應成為固態物理最重要的「載子計數器」之一，也讓它成為自由電子模型第一個在定性層次上失敗的地方：Table 4 裡鋁、銦、鈹、砷量到的 R_H 是正的，彷彿導電的是帶正電的粒子。一個只有自由電子的模型無論怎麼調參數都給不出正號。p.156 把這個異常交給 Peierls（1928）與後來被 Heisenberg 命名的「電洞」，並說答案要等第 7–9 章的能帶論；第 7 章 p.163 開頭列舉自由電子模型的不足時，「Hall 係數出現正值」也明列其中。

出發點：p.147–148 的「整顆費米球平移」

式(48) 的開場白說它是由 (39) 與 (41) 的論證得到的，所以要先把 p.147–148 的圖像重新擺好。

p.147 從自由電子的動量關係 mv = ℏk 出發，寫下牛頓第二定律 (39)：F = m dv/dt = ℏ dk/dt = −e[E + (1/c)v × B]（CGS）。在沒有碰撞、B = 0 的情況下積分，得到 (40) k(t) − k(0) = −eEt/ℏ：每一個電子的波向量都以相同速率在 k 空間平移。若 t = 0 時電子氣填滿以原點為心的費米球，則時間 t 之後整顆球的中心移到 (41) δk = −eEt/ℏ。Kittel 特別指出費米球是整體平移的，因為每個電子都位移同一個 δk。

p.148 的 Fig. 10 把這件事畫成兩格（網頁不附圖，以文字描述）：(a) 在 k_x–k_y 平面上，t = 0 的費米球以原點為心；圖說指出淨動量為零，因為每一個被佔據的軌域 k 都有一個被佔據的 −k 與之配對。(b) 恆定的力 F 作用時間 t 之後，球心移到新位置；圖說指出每個軌域的 k 都增加了 δk = Ft/ℏ，等同於整顆費米球平移 δk，N 個電子的總動量為 Nℏδk，系統能量增加 N(ℏδk)²/2m。

接著 p.147 引入碰撞：電子與雜質、晶格缺陷、聲子碰撞，使被推移的費米球可以在電場中維持穩態。若碰撞時間為 τ，穩態位移就由 (41) 取 t = τ 給出；增量速度為 −eEτ/m，於是 n 個電荷 −e 的電子給出電流密度 (42) j = nqv = ne²τE/m，也就是 Ohm 定律；p.148 由此定義 (43) σ = ne²τ/m 與 (44) ρ = m/ne²τ。

含碰撞摩擦的費米球運動方程式

ℏ(d/dt + 1/τ) δk = F

(48) 　p.152

δk：費米球中心在 k 空間相對於原點的位移（整顆球一起動，所以一個向量就描述了全體傳導電子的狀態）；F：作用在每一個電子上的外力；τ：碰撞時間，1/τ 為碰撞率；ℏ：約化 Planck 常數。p.153 對兩項的稱呼：(ℏd/dt)δk 是自由粒子的加速度項，ℏδk/τ 代表碰撞造成的摩擦。

出處推導
p.152 說它由 (39) 與 (41) 的論證而來：(39) 給出無碰撞時 ℏ dδk/dt = F（整顆球等速平移），再加上一個以碰撞率 1/τ 表示的摩擦項 ℏδk/τ。摩擦項是唯象的假設——碰撞使位移以固定速率 1/τ 衰減，衰減率與 δk 的大小、方向都無關（線性、各向同性），這就是弛豫時間近似。Kittel 沒有從散射理論推導它；p.150 的 (45) 1/τ = 1/τ_L + 1/τ_i 則說明多種散射機制並存時碰撞率相加。
極限行為
（1）τ → ∞（無碰撞）：退回 ℏ dδk/dt = F，費米球無止境地等速平移，即 (40)(41)。（2）穩態 d/dt → 0：δk = Fτ/ℏ，恰好是 (41) 取 t = τ——p.147「取 t = τ」的口頭處方在此成為精確結果，它的意思並不是「球在時間 τ 時突然停下」，而是加速與摩擦平衡後的終端位移。（3）外力在某時刻關掉：δk 以 e^(−t/τ) 指數衰減回零，τ 就是動量分布弛豫回基態的時間常數，對應 p.150 所說「電場關掉後分布以淨弛豫率回到基態」。（4）若外力以角頻率 ω 振盪，d/dt → −iω，當 ωτ ≳ 1 時加速度項不能忽略，這是第 14 章金屬介電響應的出發點；本段只處理靜態場，所以後面都令 d/dt = 0。
典型數值
銅，室溫：p.150 說電阻比 1000 的銅樣品殘餘電阻率為 1.7×10⁻³ μΩ·cm，隱含室溫 ρ ≈ 1.7 μΩ·cm；配合 Table 1 的 n = 8.45×10²² cm⁻³，τ = m/ne²ρ ≈ 2.5×10⁻¹⁴ s。取 j = 100 A/cm²（10⁶ A/m²），漂移速度 v = j/ne ≈ 7.4×10⁻⁵ m/s，δk = mv/ℏ ≈ 0.64 m⁻¹；而 Table 1 的 k_F = 1.36×10⁸ cm⁻¹ = 1.36×10¹⁰ m⁻¹，δk/k_F ≈ 5×10⁻¹¹。費米球的位移極其微小，線性的 (48) 完全足夠；穩態在 10⁻¹³ s 量級內即建立。

解開 (48)：τ 同時是「加速時間」與「弛豫時間」補推導

Kittel 寫下 (48) 後直接加磁場，沒有先解它。但先把只有恆定電場的最簡單情形解一遍很值得：它把 p.147 的兩個口頭說法——「取 t = τ」與「碰撞使被推移的球維持在穩態」——變成可以檢驗的數學，也說明為什麼後面 (52) 可以直接令時間導數為零。

解出來的形式與 RC 電路充電完全相同：F/ℏ 扮演「電源」，1/τ 扮演「漏電」，δk 像電容上的電壓，時間常數就是 τ。金屬的 τ 在 10⁻¹⁴ s 量級，任何直流或低頻量測都早已處在穩態，這就是本段接下來一律取 d/dt = 0 的理由。

校註：p.147 原文把增量速度印成「v = δk/m = −eEτ/m」，少了一個 ℏ；依 p.147 開頭的 mv = ℏk 與 p.153 推 (50) 時寫的 mv = ℏδk，應為 v = ℏδk/m。此處已將該頁算繪成影像目視確認，是原書排印的疏漏，不是抽字造成的。第 5 步採用正確的 ℏδk/m。

  1. 第 1 步：只加恆定電場，F = −eE，t = 0 時 δk(0) = 0。把 (48) 寫成標準一階線性形式：dδk/dt + δk/τ = F/ℏ。
  2. 第 2 步：乘上積分因子 e^(t/τ)，左邊變成全微分：d/dt[δk e^(t/τ)] = (F/ℏ) e^(t/τ)。
  3. 第 3 步：從 0 積到 t：δk e^(t/τ) = (Fτ/ℏ)(e^(t/τ) − 1)，所以 δk(t) = (Fτ/ℏ)(1 − e^(−t/τ))。
  4. 第 4 步（早期，t ≪ τ）：展開 1 − e^(−t/τ) ≈ t/τ，得 δk ≈ Ft/ℏ = −eEt/ℏ，正是 (41)——碰撞還來不及作用，電子自由加速。
  5. 第 5 步（晚期，t ≫ τ）：e^(−t/τ) → 0，δk → Fτ/ℏ = −eEτ/ℏ，即 (41) 以 τ 取代 t。漂移速度 v = ℏδk/m = −eEτ/m，電流 j = n(−e)v = ne²τE/m，回到 (42)。
  6. 第 6 步（關掉電場）：若在 t₀ 時令 F = 0，(48) 變成 dδk/dt = −δk/τ，解為 δk(t) = δk(t₀) e^(−(t − t₀)/τ)。同一個 τ 既決定加速多久被「截斷」，也決定位移多快衰減。若有數種獨立的散射機制，各自的衰減率相加，就是 (45) 1/τ = 1/τ_L + 1/τ_i。

為什麼 Lorentz 力裡只需要放漂移速度補推導

p.153 只用一句「若 mv = ℏδk」，就把 (48) 改寫成以速度表示的 (50)。讀者常卡在這裡：費米面上的每個電子都以 v_F ~ 10⁸ cm/s 飛行，各自受到方向不同、大小可觀的 Lorentz 力，憑什麼只用一個微小的漂移速度 v 去算磁力？下面把這一步補出來。

數量級的對比很驚人：銅在 100 A/cm² 下漂移速度約 7×10⁻⁵ m/s，而 Table 1 的 v_F = 1.57×10⁶ m/s，相差 10¹⁰ 倍以上。每個電子個別都在以 v_F 繞迴旋軌道，但這些巨大的個別運動兩兩抵消，對電流與淨受力有貢獻的只是整顆球那一點點位移。(50)–(55) 描述的全是這個「抵消之後剩下來的」集體運動。

要注意第 2 步用到 v_i = ℏk_i/m，也就是拋物線色散。第 9 章處理真實費米面時，速度由能帶的斜率決定，不再正比於 k，「整顆球平移、只看平均速度」的簡化就不再精確——這是 Table 4 部分偏差與異常的伏筆（此為本講解的判讀）。

  1. 第 1 步：設第 i 個電子的波向量 k_i = k_i⁰ + δk，其中 {k_i⁰} 填滿以原點為心的費米球。依 Fig. 10(a) 的配對論證（每個 k 都有 −k），Σ_i k_i⁰ = 0。
  2. 第 2 步：自由電子 v_i = ℏk_i/m，所以全體速度和 Σ_i v_i = (ℏ/m)(Σ_i k_i⁰ + Nδk) = Nℏδk/m。定義 v ≡ ℏδk/m，則 Σ_i v_i = Nv：v 就是電子氣的平均（質心）速度，也就是漂移速度。這正是 p.153「若 mv = ℏδk」的意思。
  3. 第 3 步：作用在全體電子的總力 Σ_i (−e)[E + (1/c)v_i × B] = −e[NE + (1/c)(Σ_i v_i) × B] = −Ne[E + (1/c)v × B]。第二個等號只用了一件事：Lorentz 力對速度是線性的，「和的叉積」等於「叉積的和」。
  4. 第 4 步：平均每個電子所受的力為 F = −e[E + (1/c)v × B]，正是以漂移速度代入的 (49)。把它放進 (48) 並用 mv = ℏδk，就得到 (50)。
  5. 第 5 步（推論）：若只有磁場、沒有位移（δk = 0，v = 0），淨磁力為零。每個電子的 k 繞著 B 軸旋轉，而以原點為心的費米球繞通過球心的軸旋轉後映回自身——平衡態不被磁場擾動，也不產生淨電流。

作用在電子上的 Lorentz 力

F = −e(E + (1/c) v × B)（CGS）；F = −e(E + v × B)（SI）

(49) 　p.153

e：基本電荷的大小，依定義為正（p.154 明言），電子電荷為 −e；E、B：外加電場與磁場（p.153 考慮的是均勻磁場）；v：電子速度，在本段用法下即漂移速度；c：光速，只出現在 CGS（高斯制）。

出處推導
古典電磁學中電荷 q 所受的力 q(E + v × B/c)，取 q = −e。p.147 的 (39) 已經用過同一個力；p.153 在考慮均勻磁場中的運動時把它單獨寫出，並並列 SI 形式。高斯制中 E（statvolt/cm）與 B（gauss）量綱相同，所以磁項必須乘 v/c 才可相加；SI 中磁場單位 T = V·s/m² 已把這個因子吸收，故寫成 v × B。
極限行為
（1）B = 0：F = −eE，回到 p.147 的 Ohm 定律問題。（2）E = 0：磁力永遠垂直於速度，不做功，只能改變速度的方向而不能改變其大小——磁場本身無法把能量交給電子氣，只能讓它轉彎，這是迴旋運動的根源。（3）以漂移速度 v = eτE/m 代入，磁力與電力之比為 vB/cE = eBτ/mc = ω_cτ（本講解的推算）：ω_cτ 同時是「兩次碰撞間轉過的弧度」與「磁力相對於電力的大小」，後面的 Hall 角正是這個比值。
典型數值
銅，室溫，B = 1 T（10 kG）：ω_cτ ≈ 1.76×10¹¹ s⁻¹ × 2.5×10⁻¹⁴ s ≈ 4.4×10⁻³，也就是作用在漂移電子上的磁力只有電力的約 0.4%。這說明為什麼金屬中的 Hall 效應是一個很小的效應。

磁場中漂移速度的運動方程式

m(d/dt + 1/τ) v = −e(E + (1/c) v × B)（CGS）

(50) 　p.153

m：自由電子質量；v：漂移速度（mv = ℏδk）；τ、E、B、e、c 同前。

出處推導
把 (49) 的 F 代入 (48)，並用 p.153 的 mv = ℏδk 把 ℏ(d/dt + 1/τ)δk 換成 m(d/dt + 1/τ)v。背後的兩個前提是：拋物線色散（速度與波向量成正比），以及 Lorentz 力對速度線性，使平均力可以只用平均速度表示（見上一個推導區塊）。
極限行為
（1）B = 0：m(dv/dt + v/τ) = −eE，即 Drude 形式的 Ohm 定律。（2）τ → ∞ 且 E = 0：純粹的迴旋運動（見下方推導）。（3）穩態：左邊只剩 mv/τ，方程式變成 v 的線性代數方程組，就是 (52)。（4）把 m 換成有效質量 m* 後，同一條方程式描述半導體中的載子，第 8 章 p.200 的迴旋共振即以 m* 表示。

從 (50) 拆出 (51)：叉積的分量與符號檢查補推導

p.153 讓靜磁場 B 沿 z 軸，直接寫出 (51) 的三個分量式，中間的叉積沒有展開。這裡補上，並做一次獨立的符號檢查，因為第二式裡的負號與後面 Hall 場的正負直接相關。

三個分量式裡，x 與 y 透過 ±(eB/c) 項彼此耦合，z 分量則完全不認得磁場。這個結構決定了後面的一切：磁場只在垂直於自己的平面上讓運動轉彎。注意第 5 步的情境：沿 +x 運動的電子被推向 +y；在 Hall 實驗中電子是沿 −x 漂移（與電場方向相反），所以會被推向 −y，這正是 Fig. 14(b) 所畫的偏轉方向。

  1. 第 1 步：令 B = Bẑ = (0, 0, B)。叉積 v × B = x̂(v_y·B − v_z·0) − ŷ(v_x·B − v_z·0) + ẑ(v_x·0 − v_y·0) = (v_yB, −v_xB, 0)。
  2. 第 2 步（x 分量）：m(d/dt + 1/τ)v_x = −e[E_x + (1/c)v_yB] = −e(E_x + (B/c)v_y)。
  3. 第 3 步（y 分量）：m(d/dt + 1/τ)v_y = −e[E_y + (1/c)(−v_xB)] = −e(E_y − (B/c)v_x)。這個負號來自叉積的 y 分量 −v_xB，是最常抄錯的地方。
  4. 第 4 步（z 分量）：叉積的 z 分量為零，所以 m(d/dt + 1/τ)v_z = −eE_z，磁場完全不出現。
  5. 第 5 步（符號檢查）：讓電子沿 +x 運動（v_x > 0，其他分量為零、無電場）。第 3 步右邊變成 −e(−Bv_x/c) = +eBv_x/c > 0，電子被推向 +y。用右手定則獨立驗證：力 = q v × B/c，q = −e，x̂ × ẑ = −ŷ，所以力 ∝ (−e)(−ŷ) = +ŷ。兩者一致。
  6. 第 6 步：p.153 說 SI 的結果以 1 取代 c 即得，例如 y 分量變成 m(d/dt + 1/τ)v_y = −e(E_y − Bv_x)。

(51) 的自由解：迴旋頻率從哪裡來補推導

p.153 在給出 (52) 時才定義 ω_c = eB/mc，並說它是第 8 章半導體迴旋共振所討論的迴旋頻率。其實 ω_c 在 (51) 裡早就藏著：只要把電場與碰撞拿掉，(51) 描述的就是純粹的旋轉。

ω_cτ 的物理意義就此清楚：它是電子在兩次碰撞之間沿迴旋圓轉過的角度。ω_cτ ≪ 1 時電子還沒怎麼轉彎就被撞了，磁場只是一個小擾動；ω_cτ ≫ 1 時電子在兩次碰撞間可以繞好幾圈，磁場主宰運動。

數值：B = 1 T（10 kG）、自由電子質量時，ω_c = 1.76×10¹¹ s⁻¹，f_c = ω_c/2π ≈ 28 GHz。銅的 v_F = 1.57×10⁸ cm/s（Table 1），迴旋半徑 r_c = v_F/ω_c ≈ 8.9 μm。室溫下平均自由徑 ℓ = v_Fτ ≈ 1.57×10⁶ m/s × 2.5×10⁻¹⁴ s ≈ 39 nm，電子在被撞之前只沿半徑 9 μm 的圓走了 39 nm，約 4×10⁻³ 弧度，幾乎是直線。反之，p.151 說極純的銅在 4 K 時 τ 約 2×10⁻⁹ s、平均自由徑約 0.3 cm，此時 ω_cτ ≈ 350，電子在兩次碰撞間繞了五十多圈。同一塊金屬、同一個磁場，只因溫度與純度不同，就從 ω_cτ ≪ 1 走到 ω_cτ ≫ 1。

  1. 第 1 步：在 (51) 中令 E = 0、τ → ∞，並記 ω_c ≡ eB/mc：dv_x/dt = −ω_c v_y，dv_y/dt = +ω_c v_x。
  2. 第 2 步：定義複數速度 v₊ ≡ v_x + i v_y。則 dv₊/dt = −ω_c v_y + iω_c v_x = iω_c(v_x + i v_y) = iω_c v₊。
  3. 第 3 步：解為 v₊(t) = v₊(0) e^(iω_c t)：速度向量在 x–y 平面上以角頻率 ω_c 等速旋轉，大小 |v₊| 不變（磁力不做功）。對電子而言，從 +z 往下看是逆時針方向。
  4. 第 4 步：位置也在圓上運動，半徑 r_c = |v|/ω_c = mc|v|/eB：速度越大、磁場越弱、質量越大，圓越大。
  5. 第 5 步（加回碰撞）：保留 1/τ，第 2 步變成 dv₊/dt = (iω_c − 1/τ)v₊，解為 v₊ ∝ e^(iω_c t) e^(−t/τ)。旋轉每經過約 τ 就被碰撞打斷一次，兩次碰撞間轉過的角度為 ω_cτ 弧度。
  6. 第 6 步：SI 中以 1 取代 c，ω_c = eB/m。

(52) 　p.153

ω_c = eB/mc：迴旋頻率（cyclotron frequency），書中在 (52) 之後的正文定義（SI 以 1 取代 c 得 eB/m）；ω_cτ：無因次，兩次碰撞間的迴旋角；其餘同 (51)。

出處推導
p.153：在靜電場中的穩態，時間導數為零。以 x 式為例：(m/τ)v_x = −eE_x − (eB/c)v_y，兩邊乘 τ/m 並記 eBτ/mc = ω_cτ，即得第一式；y、z 兩式同理。書中指出 ω_c 就是第 8 章半導體迴旋共振所討論的迴旋頻率。
極限行為
（1）B → 0（ω_cτ → 0）：v = −eτE/m，各向同性的 Ohm 定律。（2）(52) 是隱式的——v_x 的式子裡有 v_y，反之亦然——必須聯立才得到顯式解（下一個推導區塊），聯立後即第 6 章習題 9 的磁導電張量 (64)。（3）ω_cτ ≪ 1：磁場只帶來一個與 B 成正比的小修正，電流幾乎平行於電場。（4）ω_cτ ≫ 1：習題 9 的 (65) 顯示 σ_xx 到 1/ω_cτ 階為零，而 σ_yx = nec/B = −σ_xy，與 τ 無關，書中稱為 Hall 電導（Hall conductivity）；此時電流幾乎完全垂直於電場。
典型數值

把 (52) 解開：顯式漂移速度、磁導電張量與「沒有磁阻」補推導

Kittel 在 p.153 只把 (52) 寫成隱式，就直接跳到 Hall 條件。把它顯式解開有兩個好處：一是能直接對上第 6 章習題 9（p.159）的磁導電張量 (64)；二是能看出一個常被忽略的結論——在 Hall 幾何下，縱向電流完全不受磁場影響。

第 6 步的結論值得停下來看。第 8 章習題 5（p.219）的題幹明白寫著：習題 6.9 顯示在漂移速度近似下，載子在電場與磁場中的運動不會造成橫向磁阻，但有兩種載子時結果就不同。原因就在上面：Hall 場恰好抵銷 Lorentz 力的側推，電子沿 x 方向走得與沒有磁場時一模一樣。真實金屬普遍量得到磁阻，本身就說明「單一載子、單一 τ、球形費米面」的圖像不完整；第 8 章習題 5 用兩種載子、第 9 章習題 10（p.254）用開放軌道說明磁阻如何出現。

反過來，如果樣品幾何讓 Hall 場建立不起來（例如又短又寬、兩端電極把側面短路，使 E_y ≈ 0），第 4 步給出 j_x = σ₀E_x/(1 + Q²)，有效電阻率變成 ρ₀[1 + (ω_cτ)²]。同樣的物理，只是換了邊界條件，磁阻就出現了。這一點在後面的「研究接點」會再用到。

  1. 第 1 步：記 Q ≡ ω_cτ、a ≡ eτ/m。(52) 的前兩式整理成 v_x + Q v_y = −aE_x，−Q v_x + v_y = −aE_y。
  2. 第 2 步：由第二式 v_y = −aE_y + Q v_x，代入第一式：v_x + Q(−aE_y + Q v_x) = −aE_x，即 v_x(1 + Q²) = −a(E_x − QE_y)。
  3. 第 3 步：v_x = −a(E_x − QE_y)/(1 + Q²)；回代得 v_y = −a(QE_x + E_y)/(1 + Q²)；v_z = −aE_z。
  4. 第 4 步：電流 j = n(−e)v，並記 σ₀ = ne²τ/m：j_x = σ₀(E_x − QE_y)/(1 + Q²)，j_y = σ₀(QE_x + E_y)/(1 + Q²)，j_z = σ₀E_z。寫成矩陣正是 p.159 習題 9 的 (64)：第一列 (1, −ω_cτ, 0)、第二列 (ω_cτ, 1, 0)、第三列 (0, 0, 1 + (ω_cτ)²)，整體乘上 σ₀/[1 + (ω_cτ)²]。
  5. 第 5 步（強場，Q ≫ 1）：σ_xx = σ₀/(1 + Q²) ≈ σ₀/Q²，相對於 σ_yx 小了 1/Q；σ_yx = σ₀Q/(1 + Q²) ≈ σ₀/Q = (ne²τ/m)(mc/eBτ) = nec/B，τ 完全消掉——即 (65)。
  6. 第 6 步（Hall 幾何，j_y = 0）：由第 4 步 j_y = 0 得 QE_x + E_y = 0，即 E_y = −QE_x（這就是 (53)）。代回 j_x：j_x = σ₀(E_x + Q²E_x)/(1 + Q²) = σ₀E_x。縱向電流與沒有磁場時完全相同。

ω_c 指向的地方：第 8 章迴旋共振及其後我的判讀

p.153 對 ω_c 只留下一句指引：它就是第 8 章半導體迴旋共振中討論的迴旋頻率。這裡把那條線索順著書往後拉一遍，讓讀者知道這個量在全書的份量。

第 8 章 p.200：式(30) 把迴旋頻率寫成 ω_c = eB/m*c，m* 是適當的迴旋有效質量。實驗做法是在垂直於靜磁場的方向加射頻電場，當射頻頻率等於 ω_c 時發生共振吸收；線寬由碰撞時間 τ 決定，要得到清晰的共振必須 ω_cτ ≥ 1——書中的說法是平均自由徑要夠長，讓載子在兩次碰撞間至少繞一個弧度。這正是前面推導中「ω_cτ = 兩次碰撞間的迴旋角」的直接應用。同頁還說電洞與電子在磁場中的旋轉方向相反，這是 Hall 係數正負號在動力學上的對應：同一個磁場，正負載子往相反方向轉彎，所以 Hall 場也反號。

第 14 章習題 3、4（p.425）：以 ω_e = eB/m_e c、ω_h = eB/m_h c 描述圓極化電磁波中的載子運動，導出 Alfvén 波與 helicon 波——後者正是 Table 4 最準確數據所用的方法（下文另述）。

第 17 章 p.498：把習題 6.9 的磁導電張量搬到 MOS 表面的二維通道，ω_c 依然是 eB/mc（SI 為 eB/m），並在 ω_cτ ≫ 1 的極限下導向量子 Hall 效應。

所以 ω_c 不只是 (52) 裡的一個縮寫：它是全書「磁場 × 載子」主題的共同時間尺度，而 ω_cτ 則是判斷該用哪一套近似的開關。第 8 章把 m 換成 m*，就是把本段的自由電子結果推廣到能帶中的載子。

Hall 效應：定義、實驗幾何與 Fig. 14

p.153 對 Hall 場的定義是：當電流 j 流過磁場 B 時，在導體兩個面之間、沿 j × B 方向建立起來的電場。標準配置是一根矩形截面的棒狀樣品：沿棒長方向（x）加縱向電場 E_x，沿橫向（z）加磁場。書中給出的唯一物理條件是：若電流無法沿 y 方向從棒的側面流出，就必須有 δv_y = 0；而由 (52)，這只有在存在一個橫向電場時才可能。

Fig. 14（p.154）的內容（網頁不附圖，以下逐格描述）：

(a) 立體圖：一根長方體棒沿 x 方向水平放置，上方五支向上的箭頭代表沿 +z 的磁場 B_z；左端有箭頭指入、右端有箭頭指出並標示 j_x，表示電流密度沿 +x 流過棒。右上角的座標軸：z 朝上、x 朝右、y 以斜線畫向紙內。圖說：矩形截面的棒狀樣品置於磁場 B_z 中，加在兩端電極上的電場 E_x 使電流密度 j_x 沿棒流動。

(b) 剛開始的瞬間（左側標註：垂直於 ẑ 軸的截面，剛啟動）：等於從上往下看 x–y 平面。棒上方標 E_x 箭頭朝右，右側 j_x 朝右。棒內有三組白色小箭頭，每組三支，全部指向左（帶負電的電子漂移方向與電場相反），而且每一支都從右往左畫、並向下彎（朝 −y）。圖說：這是電場剛加上後帶負電電子的漂移速度，朝 −y 方向的偏轉由磁場造成。

(c) 穩態（左側標註：垂直於 ẑ 軸的截面，穩態中的漂移速度）：棒的上緣（+y 面）外側排著一列「+」號，下緣（−y 面）外側排著一列「−」號；棒中央有一支朝下的箭頭標示 E_y；白色箭頭仍然指向左，但已是筆直的水平箭頭，不再彎曲。右側座標軸：y 朝上、x 朝右、z 以小圓圈表示指出紙面。圖說：電子堆積在棒的一個面上，相對的面則建立起正離子過剩，直到如 (c) 所示，橫向電場（Hall 場）恰好抵銷磁場造成的 Lorentz 力。

從 (b) 到 (c) 就是整個 Hall 效應的物理：磁場先把電子往側面推；側面不通，電荷只好堆積；堆積的電荷產生電場，把電子往回推；當兩個側向力相等時，電子恢復直線漂移，堆積停止。式(53) 就是「兩個側向力相等」的定量表述。

Hall 場的方向，以及建立它需要多少電荷我的判讀

方向。 p.153 說 Hall 場「in the direction j × B」。這句話要讀成「沿 j × B 那條軸」，而不是「一定指向 j × B」。以 Fig. 14 的幾何算一次：j 沿 +x、B 沿 +z，j × B = x̂ × ẑ = −ŷ。對電子，(53) 給出 E_y < 0，確實指向 −y，與 j × B 同向；但若載子帶正電，Hall 場會反過來指向 +y。把 (54) 寫成向量形式最清楚：E_H = R_H (B × j) = −R_H (j × B)。R_H < 0 時 E_H 平行於 j × B，R_H > 0 時反平行。Hall 場沿哪條軸是幾何決定的，沿這條軸的正負號才是物理——整個 Table 4 的討論就是在讀這個正負號。

電荷量。 Fig. 14(c) 畫出一整排「+」與「−」，容易讓人以為側面堆積了大量電荷。估算一下：銅、室溫、j = 100 A/cm²、B = 1 T，由 (55) 的 SI 形式 |R_H| = 1/ne ≈ 7.4×10⁻¹¹ m³/C，Hall 場 E_y = |R_H| j B ≈ 7.4×10⁻⁵ V/m。把兩個側面當成平行板，所需的面電荷密度 σ_s ≈ ε₀E_y ≈ 6.5×10⁻¹⁶ C/m²，換算大約每平方公分 0.4 個電子。相比之下，金屬表面每平方公分約有 10¹⁵ 個原子。也就是說，Hall 場只需要極其微量的電荷重新分布，對載子濃度 n 完全沒有可察覺的影響；這也是為什麼 (53)–(55) 可以放心地用「未受擾動」的 n。

建立時間。 這一點電荷要多快就位？它由金屬內部電荷重新分布的時間決定，遠短於任何輸運量測的時間尺度（p.148 提到高斯制中 σ 具有頻率的量綱，銅的 σ 換算成頻率極高）。因此在直流量測中，Fig. 14(b) 的「剛啟動」階段實際上看不到，量到的永遠是 (c) 的穩態。

由 δv_y = 0 推出 (53)，並以受力平衡再驗一次補推導

p.153 只說「由 (52)，這只有在存在橫向電場時才可能」，就直接寫出 (53)。中間只有兩行代數，但第 5 步提供了一個不依賴 (52) 的物理檢驗，第 6 步則把數學上的負號與 Fig. 14 的圖對起來——讀者若能自己把這三樣東西對上，就不會再搞錯 Hall 場的方向。

第 2 步有一個容易略過的結果：在 Hall 幾何下 v_x 與 B 無關。這就是前一個推導區塊得到「沒有磁阻」的同一件事，只是從速度而不是電流的角度看。

  1. 第 1 步：橫向電流 j_y = n(−e)v_y = 0 ⇔ v_y = 0。書中寫成 δv_y = 0；因為 (50)–(52) 的 v 本身就是漂移（增量）速度，δv_y 與 (52) 的 v_y 是同一個量。
  2. 第 2 步：把 v_y = 0 代入 (52) 的 x 式：v_x = −(eτ/m)E_x——與沒有磁場時完全相同。
  3. 第 3 步：(52) 的 y 式左邊為零：0 = −(eτ/m)E_y + ω_cτ v_x，所以 E_y = (m/eτ)·ω_cτ·v_x。
  4. 第 4 步：代入第 2 步的 v_x：E_y = (m/eτ)·ω_cτ·(−eτ/m)E_x = −ω_cτ E_x = −(eBτ/mc)E_x。這就是 (53)。
  5. 第 5 步（受力平衡的另一種看法）：穩態且 v_y = 0 時，(51) 的 y 式左邊為零，所以 y 方向的總力必須為零：−e(E_y − (B/c)v_x) = 0，即 E_y = (B/c)v_x。以 v_x = −eτE_x/m 代入，同樣得到 E_y = −(eBτ/mc)E_x。Hall 場恰好抵銷磁力的側推，這正是 Fig. 14 圖說的描述。
  6. 第 6 步（符號）：E_x > 0 時 v_x < 0（電子往 −x 漂移），E_y < 0：Hall 場指向 −y，由帶正電的 +y 面指向帶負電的 −y 面，與 Fig. 14(c) 的「上 +、下 −、E_y 朝下」一致。
  7. 第 7 步：SI 以 1 取代 c：E_y = −ω_cτE_x = −(eBτ/m)E_x，與 p.154 印出的 SI 形式相同。

Hall 場

E_y = −ω_cτE_x = −(eBτ/mc)E_x（CGS）；E_y = −ω_cτE_x = −(eBτ/m)E_x（SI）

(53) 　p.153

E_y：橫向電場（Hall 場）；E_x：縱向外加電場；ω_cτ：兩次碰撞間的迴旋角。CGS 形式印在 p.153 末，SI 形式印在 p.154 上方。

出處推導
(52) 加上 Hall 條件 δv_y = 0（橫向不准有電流）。前提：單一種載子、所有電子共用同一個 τ、樣品側面絕緣、穩態。
極限行為
（1）Hall 角：總電場與電流方向之間的夾角 θ_H 滿足 tan θ_H = |E_y/E_x| = ω_cτ。ω_cτ ≪ 1（室溫金屬）時 θ_H 極小，電場幾乎平行於電流；ω_cτ ≫ 1 時電場幾乎垂直於電流，與習題 9 強場極限中「電流垂直於電場」是同一件事的兩面。（2）E_y 對 B 線性、對 τ 線性：E_y/E_x 本身含 τ，所以它不是乾淨的載子計數量，必須再除以電流——這就是 (54) 要定義 R_H 的原因。（3）E_y 的正負號由載子電荷決定：換成帶正電的載子，ω_c 的定義中 e 的符號翻轉，E_y 變號。
典型數值
銅，室溫，B = 1 T：tan θ_H = ω_cτ ≈ 4.4×10⁻³，θ_H ≈ 0.25°。取 j = 100 A/cm²，縱向場 E_x = ρj ≈ 1.7×10⁻⁸ Ω·m × 10⁶ A/m² = 1.7×10⁻² V/m，Hall 場 E_y ≈ 7.4×10⁻⁵ V/m。

Hall 係數的定義

R_H ≡ E_y/(j_x B)

(54) 　p.154

R_H：Hall 係數（Hall coefficient）；E_y：Hall 場；j_x：縱向電流密度；B：磁場大小（沿 z）。

出處推導
這是定義，p.154 直接命名為 Hall 係數。為什麼這樣定義（本講解補充）：由 (53)，E_y = −ω_cτE_x；又 j_x = σE_x，所以 E_y = −(ω_cτ/σ)j_x = −(eBτ/mc)(m/ne²τ)j_x = −B j_x/(nec)。Hall 場同時正比於 j_x 與 B，除掉這兩個由實驗者控制的量之後，剩下的就是只屬於材料的常數。
極限行為
（1）正負號：在 Fig. 14 的幾何下，R_H < 0 表示 Hall 場指向 −y，對應負電載子；R_H > 0 則對應正電載子。向量形式 E_H = R_H(B × j)。（2）在簡單模型中 R_H 與 B、τ、m、溫度都無關；實驗上若發現 R_H 隨 B 或溫度變化，本身就是模型不足（多種載子、非球形費米面）的訊號。（3）單位：CGS 為 statvolt·cm/(statamp·gauss)；SI 為 V·m/(A·T) = m³/C。（4）p.155 特別提醒：同一個符號 R_H 有時被用來表示二維問題中的 Hall 電阻，兩者意義不同（後面另立區塊說明換算）。

從 (54) 到 (55)：τ、m、B、E_x 如何全部消掉補推導

p.154 的 (55) 把中間式與結果寫在同一行，但沒有說明為什麼那麼多量會同時消失。逐項看一次很有啟發性：τ 之所以會消掉，是因為 Hall 場與縱向電流都正比於 τ——前者因為電子漂移越快、受到的磁力越大，後者因為電子漂移越快、電流越大。散射強弱對兩者的影響完全相同，所以相除之後散射就不見了。

這正是本段開頭所說的目標：σ 把 n 與 τ 綁在一起，R_H 只含 n。第 6 步把兩者合起來，得到遷移率 μ = |R_H|σ 與 ω_cτ = μB——這兩個關係在半導體量測裡天天用到，Kittel 在本段並沒有寫出，但它們只是 (43) 與 (55) 的直接組合。

數值：銅，室溫，|R_H| = 7.4×10⁻¹¹ m³/C，σ = 1/ρ ≈ 5.9×10⁷ S/m，μ = |R_H|σ ≈ 4.3×10⁻³ m²/(V·s) = 43 cm²/(V·s)；在 1 T 下 μB ≈ 4.3×10⁻³，與前面用 τ 直接算的 ω_cτ 一致。

  1. 第 1 步（分子）：由 (53)，E_y = −(eBτ/mc)E_x。
  2. 第 2 步（分母）：p.154 用 j_x = ne²τE_x/m。這裡可以放心用 B = 0 的 Ohm 定律，是因為在 Hall 幾何下 j_x 與 B 無關（前面推導已證明 j_x = σ₀E_x）。所以 j_xB = (ne²τE_x/m)B。
  3. 第 3 步：R_H = E_y/(j_xB) = −(eBτE_x/mc) / (ne²τE_xB/m)，這就是 p.154 (55) 中間那一項。
  4. 第 4 步（逐項消去）：B 上下各一個，消去；τ 上下各一個，消去；E_x 上下各一個，消去；m 在分子的分母與分母的分母各一個，消去；e 分子一次、分母兩次，剩分母一個 e。結果 R_H = −1/(nec)。
  5. 第 5 步（SI）：以 1 取代 c，R_H = −1/(ne)。
  6. 第 6 步（與電導率合併）：|R_H|·σ = (1/nec)(ne²τ/m) = eτ/mc（CGS）；在 SI 中 |R_H|·σ = eτ/m ≡ μ，即載子遷移率。並且 ω_cτ = (eB/m)τ = μB（SI）。因此同時量 ρ 與 R_H，就能把 n 與 τ 分開：n 由 R_H 給出，τ（或 μ）由 R_Hσ 給出。

(55) 　p.154

n：傳導電子濃度；e：基本電荷，p.154 強調「for e is positive by definition」，所以 R_H 對自由電子為負；c：光速（僅 CGS）。

(54) 代入 (53) 的 E_y 與 j_x = ne²τE_x/m。假設：單一種載子（自由電子）、所有電子的弛豫時間相同且與速度無關（p.155 明言）、球形費米面與拋物線色散。

銅（Table 1 的 n = 8.45×10²² cm⁻³）：R_H = −1/ne = −7.4×10⁻¹¹ m³/C，換成 CGS 為 −0.82×10⁻²⁴，與 Table 4 的計算值相同。樣品厚度 d = 0.1 mm、電流 I = 1 A、B = 1 T 時，Hall 電壓 V_H = |R_H| I B/d ≈ 0.74 μV（V_H = R_H I B/d 的推導見後面「三維 Hall 係數與二維 Hall 電阻」區塊）。對比 n = 10¹⁷ cm⁻³ 的半導體：|R_H| ≈ 6.2×10⁻⁵ m³/C，只要 I = 1 mA，同樣幾何下 V_H ≈ 0.62 mV。R_H 相差約一百萬倍，這就是 Hall 量測在半導體上容易、在金屬上困難的原因。

書中對 (55) 的限定與補充

p.155 在 (55) 之後用兩段話補了四點。依原文順序整理如下。

一、載子濃度越低，Hall 係數的大小越大。 因此量 R_H 是量載子濃度的一個重要方法。

限定三的內容：「量級為 1 的因子」長什麼樣延伸知識

p.155 只說若弛豫時間依賴速度，會出現「量級為 1 的數值因子」，沒有給出它的形式。以下推導不在 Kittel 本段中，是標準輸運理論的結果，以本段的 (52)/(64) 為起點就能得到。

物理圖像：弛豫時間長的電子漂移得快，受的磁力也大，對 Hall 場的貢獻按 τ² 加權；對縱向電流的貢獻卻只按 τ 加權。兩種平均不同，比值就不再是 1。

這個因子在金屬與半導體中的份量很不一樣。p.151 指出所有碰撞只涉及費米面附近的電子——在簡併的金屬中，參與輸運的電子幾乎都以 v_F 運動，「τ 隨速度變化」幾乎沒有施展空間，r 非常接近 1。在非簡併半導體中，載子依 Maxwell 分布散在很寬的能量範圍內（此時的平均要按能量適當加權），r 可以明顯偏離 1；常見的標準結果是聲學聲子散射 r = 3π/8 ≈ 1.18、游離雜質散射 r ≈ 1.93。這也是為什麼元件量測上常區分「Hall 遷移率」與「漂移遷移率」：兩者相差的正是這個 r。

  1. 第 1 步：把電子依弛豫時間分成若干組，第 i 組濃度 n_i、弛豫時間 τ_i，Σn_i = n。弱場下（Q_i = ω_cτ_i ≪ 1，忽略 Q_i²），由前面的張量第 4 步：j_x = Σ_i σ_i(E_x − Q_iE_y)，j_y = Σ_i σ_i(Q_iE_x + E_y)，σ_i = n_ie²τ_i/m。
  2. 第 2 步：Hall 條件 j_y = 0 是對總電流而言，不是每一組各自為零：E_y = −(Σ_i σ_iQ_i / Σ_i σ_i)E_x。
  3. 第 3 步：Σ_i σ_iQ_i = (e³B/m²c)Σ_i n_iτ_i² ≡ (ne³B/m²c)⟨τ²⟩；Σ_i σ_i = (ne²/m)⟨τ⟩。
  4. 第 4 步：到 B 的一階，j_x ≈ Σ_i σ_i E_x = (ne²/m)⟨τ⟩E_x（−Q_iE_y 項是 B² 階）。
  5. 第 5 步：R_H = E_y/(j_xB) = −[(ne³B/m²c)⟨τ²⟩ / ((ne²/m)⟨τ⟩)]E_x / [(ne²/m)⟨τ⟩E_xB] = −(1/nec)·⟨τ²⟩/⟨τ⟩²。
  6. 第 6 步：由 Cauchy–Schwarz 不等式 ⟨τ²⟩ ≥ ⟨τ⟩²，等號只在所有 τ 相等時成立，此時回到 (55)。比值 r ≡ ⟨τ²⟩/⟨τ⟩² ≥ 1 在半導體輸運文獻中稱為 Hall 因子。

兩種載子的 Hall 係數（弱場，第 8 章習題 3）

R_H = (1/ec)·(p − nb²)/(p + nb)²，b ≡ μ_e/μ_h（CGS；SI 去掉 c）

p.218

n、p：電子與電洞濃度；μ_e、μ_h：電子與電洞遷移率；b：遷移率比。題目給定各自的弛豫時間 τ_e、τ_h 與質量 m_e、m_h。

出處推導
p.155 說電子與電洞並存時式子會變複雜，但沒有寫出；第 8 章習題 3（p.218）給出了結果，要讀者在漂移速度近似下推導。題目的提示：在縱向電場存在時，找出使橫向電流為零的橫向電場；以 (6.64) 推廣到兩種載子，並忽略 (ω_cτ)² 相對於 ω_cτ 的項（即忽略 B² 階，弱場）。
極限行為
（1）p = 0：R_H = −nb²/(ec·n²b²) = −1/nec，回到 (55)。（2）n = 0：R_H = +1/pec，正號，對應「電洞」。（3）n = p（補償的半金屬或本質半導體）：R_H = (1/nec)(1 − b²)/(1 + b)² = (1/nec)(1 − b)/(1 + b)，正負號由遷移率比決定、與載子數無關，大小則被 (1 − b)/(1 + b) 壓低。（4）p = nb² 時 R_H = 0：即使有大量載子，Hall 係數也可以恰好為零。這四個極限合起來說明：有兩種載子時，R_H 的正負號不一定代表多數載子的正負號。
典型數值
（以下為本講解的估算，僅作量級示範。）砷：第 8 章 Table 7（p.216）給 n = p = 2.12×10²⁰ cm⁻³，1/pec ≈ 328×10⁻²⁴ CGS；Table 4 的 +50×10⁻²⁴ 對應 (1 − b)/(1 + b) ≈ 0.15，即 b ≈ 0.74（電洞遷移率較高）。鉍：Table 7 給 n ≈ 2.9×10¹⁷、p ≈ 3.0×10¹⁷ cm⁻³，若只有一種載子（取 3.0×10¹⁷ cm⁻³）|R_H| 會高達約 2.3×10⁵×10⁻²⁴；實測 −6000×10⁻²⁴ 小了約 40 倍；以 n ≈ p 的補償近似 (1/nec)(1 − b)/(1 + b) 計算，對應 b ≈ 1.05（若代入上面 n、p 的個別值精確求解，則 b ≈ 1.07）。注意 Table 4 是室溫的傳統量測，Table 7 未註明條件，且此式忽略 B² 項，這些數字只能說明「小載子濃度 → 巨大 R_H、補償 → 再打折」的量級。

強磁場極限：兩種載子時 R_H 只數 n − p補推導

這個推導把第 8 章習題 5 的兩個結果合起來，得到一個本段沒有寫、卻是理解 Table 4 最關鍵的式子：在 ω_cτ ≫ 1 的強場極限下，Hall 係數只計算「電子數減電洞數」。

它的重要性在於 Table 4 最精確的數據（helicon 法）是在 4 K 取得的。前面算過，極純金屬在 4 K 的 ω_cτ 可以達到數百，正是強場極限。所以 Al、In 的 helicon 值應該用第 4 步的式子去理解，而不是弱場的習題 3 公式——下一個區塊就這樣做。

注意第 3 步在 n = p 時分子為零，R_H 恆為零；p.219 的習題也說此時 σ ∝ B⁻²，而 n ≠ p 時 σ 在強場下飽和。補償與否，在強場下是涇渭分明的兩種行為。

  1. 第 1 步：第 8 章習題 5（p.219）處理濃度 n 的電子與濃度 p 的電洞在強場（ω_cτ ≫ 1）下的行為，要讀者證明 σ_yx = (n − p)ec/B，並給出（Q ≡ ω_cτ，記 A ≡ n/Q_e + p/Q_h）：Hall 場 E_y = −(n − p)A⁻¹E_x，x 方向有效電導 σ_eff = (ec/B)[A + (n − p)²A⁻¹]。
  2. 第 2 步：Hall 幾何下 j_x = σ_effE_x，代入 (54)：R_H = E_y/(j_xB) = −(n − p)A⁻¹E_x / {(ec/B)[A + (n − p)²A⁻¹]E_xB}。
  3. 第 3 步：B 與 E_x 消去，分子分母同乘 A：R_H = −(n − p) / {ec[A² + (n − p)²]}。
  4. 第 4 步：強場極限 Q_e, Q_h → ∞，所以 A → 0：R_H → −1/[(n − p)ec]（n ≠ p）。
  5. 第 5 步：結果只含淨載子數 n − p，與 τ、質量、遷移率比全部無關——比弱場的習題 3 公式乾淨得多。若 n > p 為負，若 p > n 為正，p = n 時 Hall 場為零（題目也指出 E_y 在 n = p 時消失）。
  6. 第 6 步（對照單一載子）：p = 0 時 R_H = −1/nec，與 (55) 相同。單一載子時 R_H 在弱場與強場都一樣，所以前面推導 (55) 時沒有區分場的強弱；兩種載子時，弱場與強場的答案不同。

為什麼鋁與銦「恰好」是一個電洞延伸知識

Table 4 最引人注目的不只是 Al、In 的正號，還有它們的大小：Al 的 +1.136 對「每原子一個電洞」的 +1.135，In 的 +1.774 對 +1.780，吻合到千分之幾。一個錯誤的模型為什麼能給出這麼精確的數？p.156 只說這些值與每原子一個正載子的計算相符，解釋留給第 7–9 章。以下是把書中幾處材料接起來的推論；其中「鋁的第二區費米面是電洞型、且軌道為封閉」這一點是更進階教材的標準說法，Kittel 在本章與第 9 章並沒有逐字寫出，因此本區塊標為 ext。

第一塊材料：強場極限只數 n_e − n_h。 上一個推導區塊由第 8 章習題 5 得到 R_H → −1/[(n_e − n_h)ec]，與 τ、有效質量、費米面細節都無關。helicon 數據在 4 K 取得（Table 4 表題），極純金屬在此溫度 ω_cτ ≫ 1。

第二塊材料：鋁的電子如何分布在各區。 第 9 章 p.222 的 Fig. 1 圖說：鋁每個原胞有三個價電子，第二區約有一半被電子填滿；p.250–251 說鋁的自由電子費米球完全填滿第一區，並大幅伸入第二、第三區，第四區的小口袋在計入晶格位能後清空、電子併入第三區。

計數。 依 Fig. 1 圖說以「每原胞三個價電子」計（fcc 的原胞只含一個原子），每一區每原胞可容納 2 個電子（含自旋）。第一區全滿用掉 2 個；剩下 1 個分到第二區（n₂ 個電子）與第三區（n₃ 個電子），n₂ + n₃ = 1。第二區接近半滿、以電洞型的費米面計算，電洞數為 2 − n₂；第三區以電子計算，電子數為 n₃。於是

n_e − n_h = n₃ − (2 − n₂) = (n₂ + n₃) − 2 = 1 − 2 = −1（每原子）。

代入強場公式：R_H = +1/(n_atom·e·c)——恰好是「每原子一個電洞」，而且這個結果與 n₂、n₃ 各是多少完全無關。費米面的形狀再複雜，只要軌道是封閉的，強場 Hall 係數就只看這個整數。這就解釋了為什麼一個「錯誤的」單載子公式配上「1 hole」能準到千分之幾：它其實是在正確的強場極限下，數對了淨載子數。

銦同為三價；若其費米面在各區的分布具有同樣的拓撲（本講解未在 Kittel 中查證），同一個計數給出同樣的 +1/(n_atom·e·c)，與 Table 4 的 +1.774 對 +1.780 一致。

反過來說，同樣的鋁在室溫、弱場下量 Hall 係數，結果會依賴各區載子的遷移率（像習題 3 那樣），不會是乾淨的「一個電洞」。Table 4 對 Al、In 只列了 helicon 值。

三維 Hall 係數與二維 Hall 電阻的換算補推導

p.155 的提醒——R_H 這個符號有時被用來指二維問題中的 Hall 電阻——看似一句旁白，其實指向全書後段一個重要主題。上面的推導說明兩者差在哪裡：同樣從 (54) 出發，三維的 R_H 把樣品厚度除掉，留下材料常數；二維的 Hall 電阻則把厚度併入面密度，留下一個與 B 成正比的電阻。

第 17 章接著在 p.499 描述整數量子 Hall 效應：在低溫、強磁場下，Hall 電阻 V_H/I_x 出現平台，平台值精確等於 25,813 Ω 除以整數，而 25,813 Ω 正是 h/e² 以歐姆表示的值。那裡的 ρ_H 就是本區塊第 4 步的 B/n_sec 在量子條件下被「鎖」在特定值上。讀文獻時看到 R_H、R_xy、ρ_xy、ρ_H，要先弄清楚它指的是三維係數還是二維電阻，單位會立刻告訴你答案。

  1. 第 1 步：取寬 w、厚 d 的片狀樣品，電流 I 沿 x，則 j_x = I/(wd)。
  2. 第 2 步：由 (54)，E_y = R_H j_x B；兩側面間的 Hall 電壓 V_y = E_y·w = R_H I B/d。寬度 w 消掉了。
  3. 第 3 步：Hall 電阻 V_y/I_x = R_H B/d。以 (55) 代入，大小為 B/(n d e c) = B/(n_s e c)，其中 n_s ≡ nd 是每單位面積的載子數。
  4. 第 4 步：這正是第 17 章 p.498 的 (18a)：二維通道的 Hall 電阻 ρ_H = V_y/I_x = B/n_sec（SI 中為 B/n_se），量綱是電阻（ohm）。
  5. 第 5 步（比較）：三維 Hall 係數 R_H 是材料常數，SI 單位 m³/C，與 B 無關；二維 Hall 電阻是可直接量到的電阻，正比於 B、反比於面密度 n_s。兩者之比為 B/d。

表題的單位換算實際示範補推導

表題給了兩個換算因子卻沒說它們從哪裡來。上面把它們從 statvolt 與 statamp 的定義推出來，並拿鈉的數據實際走一遍。

兩個觀察。第一，「9」其實是 8.988 的四捨五入：第一因子 = c²×10⁻⁹、第二因子 = c²×10⁻⁷（c 以 cm/s 計），所以用表題因子換算會有約 0.1% 的誤差，對 helicon 值的第四位有效數字已經有影響。第二，volt-cm/amp-gauss 是一個混合單位（電壓、電流用實用單位，長度用 cm，磁場用 gauss），在今天的文獻裡已經少見；實務上最常用的是 m³/C 或 cm³/C（1 m³/C = 10⁶ cm³/C）。典型金屬的 |R_H| 落在 10⁻¹¹–10⁻¹⁰ m³/C，也就是表中 10⁻²⁴ CGS 量級的數乘上 9×10¹³。

高斯制中還有一個容易混淆的地方：CGS 的 −1/nec 單位是 cm³/(statC·cm/s) = cm²·s/statC，看起來與第 1 步的 statvolt·cm/(statamp·gauss) 不同；但高斯制中 gauss 與 statvolt/cm 量綱相同，代入後第 1 步的單位化為 cm²/statamp = cm²·s/statC，兩者一致。

  1. 第 1 步（CGS 單位是什麼）：由定義 (54)，[R_H] = [E_y]/([j_x][B]) = (statvolt/cm) / [(statamp/cm²)·gauss] = statvolt·cm/(statamp·gauss)。
  2. 第 2 步（換算常數）：1 statvolt = 299.79 V ≈ 300 V；1 statamp = 10/c A（c 以 cm/s 計）= 3.336×10⁻¹⁰ A ≈ 1/(3×10⁹) A。
  3. 第 3 步（第一個因子）：1 statvolt·cm/(statamp·gauss) = (299.79 V·cm)/(3.336×10⁻¹⁰ A·gauss) = 8.988×10¹¹ V·cm/(A·gauss) ≈ 9×10¹¹。這就是表題的第一個換算因子。
  4. 第 4 步（換成 SI）：1 V·cm/(A·gauss) = V·(10⁻² m)/(A·10⁻⁴ T) = 10² V·m/(A·T)。又 T = V·s/m²，所以 V·m/(A·T) = V·m·m²/(A·V·s) = m³/(A·s) = m³/C。因此再乘 100：8.988×10¹³ ≈ 9×10¹³，即表題的第二個因子。

書中對 Table 4 的判讀：吻合、反例與「電洞」的誕生

p.155 末到 p.156 上半，Kittel 對 Table 4 做了三層判讀。

第一層：成功。 鈉與鉀的精確值（helicon 法）與每原子一個傳導電子、用 (55) 算出的值極為吻合。

第三層：解釋的出處。 這個符號異常由 Peierls（1928）解釋。這些看似帶正號的載子，後來被 Heisenberg 稱為「holes」（電洞）；它們的運動無法以自由電子氣解釋，卻能在第 7–9 章將要發展的能帶論中得到自然的說明。能帶論也說明了像 As、Sb、Bi 那樣非常大的 Hall 係數是怎麼出現的。

第 8 章：電洞的性質被寫成規則。 第 8 章章末摘要（p.218）先說明：只缺一個電子的能帶中，電洞的性質等同於帶內其餘 N − 1 個電子；接著列出五條：（a）電洞的波向量 k_h = −k_e；（b）在外加場中 k_h 的變化率要求電洞帶正電荷 e_h = e；（c）電洞速度 v_h = v_e；（d）電洞能量 ε_h(k_h) = −ε(k_e)；（e）電洞有效質量 m_h = −m_e。其中「電洞帶正電荷」直接決定了 (55) 的符號翻轉。p.200 則說電洞與電子在磁場中的旋轉方向相反。

為什麼 helicon 法最準我的判讀

p.155 說最準確的量測來自 helicon 共振法，並說它在第 14 章以習題的形式處理。Table 4 也顯示 helicon 值與計算值吻合到千分之幾，而傳統值常偏離約 5%–32%。這個差距有幾個可以從書中材料推出的原因。

一、helicon 頻率直接就是 R_H。 第 14 章習題 4（p.425）要讀者證明：只有一種載子（濃度 p）、且 ω ≪ ω_h = eB/m_hc 時，helicon 的色散關係為 ω = (Bc/4πpe)K²（CGS）。把 R_H = 1/pec 代入，係數 Bc/(4πpe) = (c²B/4π)·R_H。也就是說，在已知的磁場下量出頻率與波向量的關係，得到的就是 R_H 本身（本講解的改寫），而且不需要在樣品上接任何電極，避開了傳統 Hall 量測中電極位置不對稱之類的接點問題。但幾何誤差並沒有因此消失：由上式 R_H = 4πω/(c²BK²)，必須知道 K，而有限樣品中的 K 由邊界條件（例如駐波條件）決定，所以樣品尺寸仍會透過 K 進入 R_H 的萃取。以上是本講解的推論，書中沒有說明 helicon 法的準確度從何而來。同一個習題要讀者估計鈉在 K = 1 cm⁻¹、B = 1000 G 下的 helicon 頻率；代入 Table 1 的 n 可得 |ω| ≈ 0.19 s⁻¹（約 0.03 Hz），是極低頻的波。書中括號提醒：這個頻率為負，對圓偏振模而言，頻率的正負號代表旋轉方向。

二、4 K 意味著強場極限。 習題的推導完全忽略碰撞，這等於假設 ω_cτ ≫ 1；實際上 helicon 的阻尼隨 1/ω_cτ 增加，只有在 ω_cτ ≫ 1 時才能清楚觀測（此點為延伸知識，書中未寫）。Table 4 的 helicon 數據在 4 K 取得，正是極純金屬 ω_cτ 可達數百的溫區。在這個極限下，R_H 只數淨載子數（前面的強場推導），對 τ 的各向異性、速度相依、多種散射機制都不敏感，所以 Na、K 精確地給出「一個電子」，Al、In 精確地給出「一個電洞」。

三、傳統值是室溫、弱場。 室溫下 ω_cτ ~ 10⁻³，屬於弱場極限；此時只要載子不只一種，或費米面不是球、τ 隨位置而異，R_H 就會帶上遷移率加權的因子（兩載子公式、Hall 因子），偏離 −1/nec。Table 4 中 Na 的傳統值 −2.3 與 helicon 值 −2.619 相差 12%，書中沒有說明原因；弱場與強場的差別、以及室溫與 4 K 樣品條件的不同，都是可能的因素，但無法從書中材料斷定哪一個主導。

常見誤解我的判讀

誤解一：「Hall 場一定指向 j × B。」 書中的措辭是「沿 j × B 方向」，指的是那條軸。電子的 Hall 場確實平行於 j × B，但帶正電的載子會反過來。向量形式 E_H = R_H(B × j) 把正負號交給 R_H。

誤解二：「磁場讓電子偏轉，所以縱向電阻會變大。」 在單一載子、單一 τ 的模型中，Hall 場恰好抵銷側向磁力，j_x = σ₀E_x 與 B 無關——完全沒有橫向磁阻。第 8 章習題 5 明白指出這一點。真實金屬量到的磁阻來自多種載子、非球形費米面或開放軌道；若樣品幾何讓 Hall 場建立不起來，則會出現 ρ₀[1 + (ω_cτ)²] 形式的幾何磁阻。

誤解三：「(50) 裡的 v 是電子的速度。」 它是整顆費米球的平均速度，也就是漂移速度，在銅中約 10⁻⁴ m/s 量級；個別電子以 v_F ~ 10⁶ m/s 運動。Lorentz 力之所以只需要放漂移速度，是因為它對速度線性，個別的巨大速度兩兩抵消。

誤解四：「R_H 為正，代表有帶正電的粒子（例如離子）在移動。」 離子不參與傳導。正號來自幾乎填滿的能帶中缺少的電子，其整體行為等同於帶正電荷 e 的準粒子（第 8 章 p.218）。p.156 的措辭也很謹慎：「看似帶正號的載子」。

誤解五：「|R_H| 大表示導電好。」 恰好相反。|R_H| ∝ 1/n，Table 4 中 Bi 的 |R_H|（6000）約是 Cu（0.6）的一萬倍，原因是它的載子少了好幾個數量級，而不是它比較會導電。

誤解六：「(55) 裡的 n 就是價電子濃度。」 只有在單一種自由電子的情形下才是。有兩種載子時，弱場 R_H 是遷移率加權的組合（第 8 章習題 3），強場 R_H 則只數 n_e − n_h（第 8 章習題 5）；Table 4 的 Al、Be、As 都是反例。

誤解七：「Hall 係數與溫度、磁場無關。」 這是簡單模型的結論，也是它的限制。Table 4 同一個 Na 在室溫與 4 K 的值就不同；半導體的 R_H 更因為 n 隨溫度劇烈變化而強烈依賴溫度（第 8 章 Fig. 21）。R_H 隨 B 變化本身就是多載子的指紋。

誤解八：CGS 與 SI 混用。 表中的 10⁻²⁴ CGS 要乘 9×10¹³ 才是 m³/C；ω_c 在 CGS 是 eB/mc、在 SI 是 eB/m。用 SI 數值代入 CGS 公式（或反之）是本段最常見的算錯方式。

與元件熱特性研究（Cth）的接點延伸知識

本段本身沒有任何熱學內容，但它提供的「把 n 與 τ 分開」這個能力，在元件自熱（self-heating）與熱容萃取的工作中會以幾種方式出現。以下內容超出 Kittel 本段，屬於延伸。

一、電學溫度計的物理基礎。 量測元件自熱時，常把某個電阻（金屬閘極、金屬線、或通道本身）當溫度計：先在恆溫台上校正電阻對溫度的關係，再用它讀出工作中的溫升。這類溫度計為什麼可靠、在哪裡會失準，取決於電阻變化來自 n 還是 τ。對簡單金屬（如 Table 4 中以 helicon 法量得的 Na、K），n 與「每原子一個傳導電子」吻合；至於 n 由價電子數決定、不隨溫度變化，則是自由電子模型（簡併電子氣）的假設，不是 Table 4 直接量到的。因此金屬電阻的溫度相依主要來自 τ(T)——p.151 說在 Debye 溫度以上 ρ 正比於 T，Matthiessen 規則 (45)–(46) 則說明雜質貢獻一個不隨溫度變的常數項。這就是金屬電阻溫度計近似線性、且需要逐片校正殘餘電阻的原因。對半導體通道而言，n 與 μ 都隨溫度改變，要分開兩者就需要本段的 Hall 量測（或等價的方法）。

二、ω_cτ = μB 與磁阻遷移率萃取。 前面由磁導電張量得到：若樣品幾何讓 Hall 場建立不起來（又短又寬、電極短路側面），有效電阻率變成 ρ₀[1 + (μB)²]。短通道 MOSFET 與 FinFET 的遷移率萃取文獻中有一類「幾何磁阻」方法正是利用這個關係，直接從電阻對 B 的二次方項讀出 μ，不需要知道有效通道長度或載子數。以矽反轉層 μ 約數百 cm²/(V·s) 估計，1 T 下 μB 只有約 0.02–0.03，(μB)² ~ 10⁻³，所以這類量測需要數特斯拉的磁場與精密的電阻解析。遷移率的溫度相依又是電學熱量測的核心校正量，兩條線在這裡交會。

三、下一節的伏筆。 本段的關鍵技巧是「兩個都正比於 τ 的量相除，τ 就消失」。p.156 緊接著的 Wiedemann–Franz 定律 (57) 用的是同一個技巧：熱導率 K 與電導率 σ 都正比於 τ，相除後 K/σ = (π²/3)(k_B/e)²T 與 τ、n、m 都無關。這讓人能用量得到的電阻去估計金屬連線的電子熱導——在分析元件的熱路徑、估計熱阻與熱容時經常用到。

小結：一條從 δk 到電洞的推理鏈我的判讀

回頭看這一段，Kittel 用四頁完成了一個完整的「模型—預測—檢驗—失敗」循環。

模型：整顆費米球以 δk 平移，碰撞以 1/τ 的速率把它拉回，(48)。加上 Lorentz 力並以漂移速度改寫，(49)(50)；讓磁場沿 z，(51)；取穩態，(52)。迴旋頻率 ω_c = eB/mc 在此出現，ω_cτ 成為整段的控制參數。

預測：側面不准有電流，逼出一個 Hall 場 E_y = −ω_cτE_x，(53)；除掉實驗者控制的 j_x 與 B，定義 R_H，(54)；τ、m、B 全部消去，只剩 R_H = −1/nec，(55)。一個不依賴散射細節、只數載子並讀出電荷符號的量。

檢驗：Table 4 中 Na、K 的 helicon 值吻合到千分之幾；室溫傳統值則有約 5%–32% 的偏離。

失敗：Al、In 的符號與大小都錯，Be、As 也為正，As、Sb、Bi 的大小錯了幾個數量級。自由電子模型在此第一次遇到它無論如何都解釋不了的事實——一個正號。

這個失敗是有生產力的：它迫使我們引入電洞（Peierls 1928、Heisenberg 命名），並把答案交給第 7–9 章的能帶論。本講解另外補出了三個書中沒有寫、卻是理解 Table 4 的關鍵：Hall 幾何下沒有磁阻；兩種載子時弱場與強場的 R_H 不同；強場 R_H 只數 n_e − n_h，因此鋁「恰好」是一個電洞。

最後，「兩個都正比於 τ 的量相除，τ 就消失」這個技巧，在下一節的 Wiedemann–Franz 定律中會再出現一次——讀者可以把 R_H 與 K/σ 當成一對來記：前者數載子，後者量 (k_B/e)²。
